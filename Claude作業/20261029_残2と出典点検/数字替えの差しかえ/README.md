# 数字だけを替えた問題の差しかえ案（2026-10-29 Claude）

`../自己点検/near_dups_08.py`：Claude の6単元（solid2・spaceline・surface1・solidmake・spaceuse・solidreview）で、数字を伏せて似ている割合が 0.8〜0.9（検査の基準 0.9 より下）の組を53組拾い、すべて読んだ（`../自己点検/near_dups_08-result.json`）。

- ほとんどは、同じ図や同じ前置き（「図の正六角柱（A の真下が G …）で」など）を使った**別の問い**で、水増しではない。
- **数字だけを替えた同じ型が2組**あったので、新しくつくった側を差しかえた（`replace2.py`、`差しかえ表.json`）：
  - spaceuse-14（今回）：solid2-70 と同じ「円錐を床の上で転がす回転数」→「1周の最短のひもの長さは、底面の円周の何倍か」（答え 3/π 倍。中心角 60° の正三角形から、ひも ＝ 母線 12 cm、円周 4π cm）。
  - solid2-13（立体残7）：solidmake-1 と同じ「円柱の展開図の側面の横の長さ」→ 同じ展開図の図のまま「組み立てた円柱の体積」（答え 80π cm³）。立体残7 の `図の対応表_solid2.json` の answer の記録は古い答えのまま（図は変えていない）。
- 境界（同じ立体・同じ図で別の量をたずねる組）は残した：surface1-31／32（立方体を2個・3個つなぐ表面積）、solidmake-62／63（同じ台形の回転体の円柱部分・円錐部分の高さ）、solidmake-64／65、solidreview-43／44、65／66 など。削るかは判断が必要。
- 検査：答えの漏れ・書き方・似すぎ（全特訓・教科書問題）・本物のエンジンの採点・validateUnit → `replace2_1.log`（不合格0・exit 0）。変わったのは2問の prompt・answer・explanation だけ。
- 書き方ゆれ `probe.log`：3/π・3/π倍・80π・80π cm³・80πcm3 は○、π/3・3・0.95・40π・80 は×。
- 「3÷π」は×。`divide_probe.log`：分数の形の式の答え59問すべてで、「/」を「÷」にした入力は×。文字式の単元では「y÷x」を×にするのは教科書の「文字式の表し方（÷ を使わない）」どおりで、π をふくむ式も同じ書き方の決まりにしたがうので、**採点の制約ではなく決まりどおり**と判断した（変えたほうがよいかは判断が必要）。
