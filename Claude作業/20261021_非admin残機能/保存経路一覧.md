# 保存・同期の経路一覧（2026-10-21・実コードを読んで作成）

実データ・認証ストア・秘密値は読んでいない。正本はサーバー（Worker の `/save` と教材の記録API）。端末の localStorage には記録を置かない（`recordStorage` はメモリ）。

## 「今すぐ同期を確認」（設定）

未送信があれば先に送り（`cloudPush`）、送り終わってから取り込む（`cloudPull(true)`）。取り込みでは、未送信・保存中・競合中なら何もしない。空の応答では消さない。

## 未完成・判断待ち

- 日次・世代・暗号化・三重バックアップ（台帳44）：保存先・費用・保管期間・鍵の持ち主と復元の権限が決まっていない。決まるまで作らない（実データの複製や旧端末保存の再有効化で代わりにしない）。
- 「送れる前に閉じると消える」下書き：端末に残す（IndexedDB 等）かは、端末に記録を残さない今の方針（プライバシーポリシー6項）との関係で判断が要る。
