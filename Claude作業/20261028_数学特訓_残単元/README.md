## 見つけた既存の課題（変えていない・Codexへ）
- 採点エンジンは「およそ700回」のように「およそ」をつけた答えを × にする。確率の単元では「およそ何回」とたずねるので、書く生徒がいそう。今回の問題だけでなく、前からある確率の問題でも同じ（`およそ_既存問題での確認.log`：prob-1 で「およそ1140回」が ×）。エンジン側で「およそ」を読みとばすかどうかは判断が必要。
- 反比例の式の答えは「y=36/x」の形だけ ○。「xy=36」は ×（問題文が「y を x の式で」なので、いまの形でよいと判断）。
