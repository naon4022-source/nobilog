# 約分していない分数を○にしない（採点器の候補・未反映）
- 見つけた問題：数の答え（分数）434問で、9/30 のように約分していない形でも○になる。「約分しよう」と書いてある問題も3問ある。整数の答えに 6/2 と書いても○。
- 候補：`material-engine.candidate.js`（差分 `material-engine.diff`・数行）。分数の形で書かれていて、約分できる（または分母が1）ときは「約分しよう。」で×（0.5点）。小数の答えに 1/2 と書くのは○のまま。
- 確認：`node verify-reduce.cjs`（今のバンク全体で、模範解答の判定は変わらない・約分前は×・ほかの答えの種類は変わらない。20,473件）。
- 取り込み（Codex）：`教材整理/実装/material-engine.js` に差分を当て、`build-material-assets.py` で配る。学校で約分前を×にするかは先生の方針で変わるので、取り込む前にユーザーに確認するのがよい（今は候補だけ）。
