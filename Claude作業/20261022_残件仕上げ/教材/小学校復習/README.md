# 小学3〜6年・5教科の復習（候補・未反映）

- 教材：`elementary-review-bank.json`（20単元×50問＝1,000問、独自問題）。作り方 `build_{sansu,kokugo,rika,shakai,eigo}.py`。
  - 算数：分数・小数は Fraction で検算。分数で答える問題は約分した形（帯分数も可）だけを正解にする。
  - 国語：読み20・書き20・言葉10。文の漢字はその学年までに習う漢字だけ（小学校1026字の学年別の表で自動確認）。習っていない字はひらがな。
  - 理科・社会：言葉で説明する答えは記述用の採点（大事な言葉）。逆の意味の言い方は reject で×。
  - 英語：3・4年は単語と表現、5・6年は文。大文字小文字・最後のピリオドは問わない。
- 進め方：`elementary-review-model.js`。1周目は全問を順に、全部に1回答えたら、まちがえた問題だけをできるまでくり返す。本人ごと。保存の直前にも本人を確かめ、切りかえ後の遅い答えは保存しない。未回答は誤答に数えない。
- 確認：`node verify-elementary-review.cjs`（1,000問の模範解答が○・「わからない」が×・解説あり、進め方10件。合計3,011件）。
- 総数の矛盾：元の依頼の「3〜6年×5教科×50問」は1,000問で、同じ依頼の「1,500問」とは合わない。確定できる1,000問を作った（1,500問に足すなら、学年や問題数の決め方の指示が要る）。
- 古い問題の扱い（ユーザー指示「12500問削除」「英語の小学校の復習も削除」）：削除はしていない。取り込みの案：受験タブの小学生12,500問の入口を、この復習に差しかえる（`elementary-questions.json` と記録 `examDone`・`examMistakes` などは消さず、表示から外すだけ）。問題タブ英語の「小学校の復習」単元（`workbook-english-1-review`）は一覧から外す候補。どちらも index.html／問題バンクなので Codex が取り込む。
- 未実装：受験タブの画面（学年・教科を選ぶ→1問ずつ→結果）。採点は material-engine をそのまま使える。保存先は本人の記録（例 `ukey('elemReview')`）を想定。
