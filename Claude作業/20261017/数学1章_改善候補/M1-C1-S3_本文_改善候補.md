## M1-P065｜身近な導入・既習事項・今回のつながり

［絵 M1-C1-S3-INTRO（未生成。制作指示は画像選定.md）：通学路を歩く5人］

### ？ 5人の通学時間の平均、全部たさずに出せる？
5人の通学時間は、18分、23分、20分、17分、27分。
- ふつうは、全部たして 105分、5でわって 21分。
- でも、数が大きかったり多かったりすると、全部たすのは大変。
- 見ると「だいたい20分くらい」。この「20」を基準にすると、計算がぐっと楽になる。

### 使う、前に学んだこと
- 平均＝合計÷個数（小学校）
- 基準とのちがいを正の数・負の数で表す（1節 P012〜P015）
- 正の数・負の数の加法と除法（2節）

## M1-P066｜仮平均／しくみ　（教科書 p52〜53・ワーク p26 ポイント1-34）

［図 M1-C1-S3-FIG01：20分を基準にしたちがいの棒グラフ］

### 仮平均
平均を求めるときに、基準にする値を **仮平均** という。

### 図で見る（FIG01）
- 太い横線が **基準20分＝0**。
- 灰色の棒は基準より長い時間（B +3、E +7）、斜線の棒は短い時間（A −2、D −3）。C は 0。
- 点線は **ちがいの平均 +1** の高さ。出っぱった棒とへこんだ棒をならすと、この高さになる。

### なぜうまくいくの？
- 各値は「基準 ＋ ちがい」と書ける。18＝20+(−2)、23＝20+(+3)……
- 全部たすと、「基準×個数」と「ちがいの合計」に分かれる。
- 個数でわると、**平均＝仮平均＋（ちがいの合計÷個数）**。

### 仮平均はどの値でもよい
どの値を仮平均にしても、平均は同じになる。ちがいが小さくなる値を選ぶと、計算が楽。

**ひとことまとめ**：基準を決めて、ちがいだけを計算する。

## M1-P067｜仮平均／解き方

### どこを見る（仮平均の決め方）
- データの真ん中あたりにある、計算しやすい数を選ぶ。
- ちがいが小さくなるほど、計算が楽になる。

### 解く順番
1. 仮平均を決める。
2. 各値と仮平均のちがいを、正の数・負の数で書く（値が大きければ +、小さければ −、同じなら 0）。
3. ちがいの合計を出す（正の項・負の項に分けると楽）。
4. 個数でわって、ちがいの平均を出す。
5. 仮平均にたす。

### 確かめる
- 平均は、いちばん小さい値といちばん大きい値のあいだにあるか。
- 仮平均を別の値にしても、同じ答えになるか。
- ちがいの数が、データの個数と同じか（0 のちがいも1個に数える）。

## M1-P068｜仮平均／例題　〔参考：教科書p52〜53・ワークp26〜27 ポイント1-34〕

### 例題1-基本　通学時間 18、23、20、17、27（分）の平均を、20分を仮平均として求めなさい。
1. ちがい：−2、+3、0、−3、+7。
2. 合計：正の項 10、負の項 −5 → +5。
3. 5÷5＝1。
4. 20+1＝**21分**。
**確かめる**：17〜27 のあいだにある。直接 105÷5＝21 とも一致。

### 例題1-標準　6個のかぼちゃの重さ 2.4、2.1、2.7、2.2、2.6、1.8（kg）の平均を、仮平均を使って求めなさい。
1. 仮平均を 2.4kg にする。
2. ちがい：0、−0.3、+0.3、−0.2、+0.2、−0.6。
3. 合計 −0.6。
4. −0.6÷6＝−0.1。
5. 2.4+(−0.1)＝**2.3kg**。

### 例題1-応用　4人のジャンプの記録を、ある基準とのちがいで表しました。A +4cm、B −6cm、C +1cm、D は消えて読めません。4人の平均は基準より 1cm 長いことが分かっています。D のちがいを求めなさい。
1. ちがいの平均が +1 なので、ちがいの合計は 1×4＝4。
2. A、B、C の合計：4−6+1＝−1。
3. D＝4−(−1)＝**+5cm**。
**確かめる**：4−6+1+5＝4、4÷4＝1。

## M1-P069｜仮平均／つまずきと確認

### つまずきの比較
| まちがい | 正しい考え方 |
|---|---|
| ちがいの合計を、そのまま仮平均にたす | 合計を **個数でわってから** たす |
| ちがいの符号をつけ忘れる | 仮平均より小さい値は「−」 |
| 0 のちがいを個数に数えない | ちがいが 0 の値も1個として数える |

### 考え方付き確認

<details><summary>ヒント1</summary>ちがいは +3、−2、+10、+1。</details>
<details><summary>答えと解説</summary>63点。合計 12、12÷4＝3、60+3＝63。</details>

**確認1-2**　仮平均を 70 として、ちがいの合計が −15、データが5個のとき、平均はいくつですか。
<details><summary>答えと解説</summary>67。−15÷5＝−3、70+(−3)＝67。</details>

## M1-P070｜別の場面へ使う・立式や判断の根拠・検算

［絵 M1-C1-S3-APPLY（未生成。制作指示は画像選定.md）：高さのちがう積み木を、低いほうへ分けてならす手］

### 絵で見る：「ならす」と平均
- 絵の点線の高さを見よう。高い山から低い山へ積み木を移して、全部の高さをそろえると、そろった高さが平均。
- 仮平均は「とりあえずの高さ」。そこから、出っぱり（+）とへこみ（−）を合わせて調整する。

### 判断の根拠を言えるようにしよう
「ちがいの合計が 0 なら、平均は仮平均と同じ」になる理由を、1文で説明してみよう。
<details><summary>説明の例</summary>ちがいの平均が 0÷個数＝0 になり、仮平均に 0 をたしても変わらないから。</details>
