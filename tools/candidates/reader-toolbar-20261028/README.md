## 次の既存失敗の解消

full8は実行中に、kokugo-reading-20261027/main/checked-successor.cjsで「teaching main/candidate drift: 国語のかいわ.py」を検出した。今回の64ファイルを正しく反映したことで、過去の20ファイル更新を最新とする検証契約が古くなっている。実行中の固定入力を変えず終了まで待つ。

修正では今回の64ファイルと変更前保全・最終候補・全体検証前成功を厳密に照合したうえで、過去の検証を読み取り専用の変更前の見え方で実行する。古いアサーションの削除、判定緩和、失敗の握りつぶし、過去の完了証拠の書き換えはしない。古い国語の直接検査も、新規の実本体検査と過去の検査の両方を維持する。
