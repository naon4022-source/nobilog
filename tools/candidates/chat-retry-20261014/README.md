# AI相談の再読み込み後の再送候補

本体はまだこの候補を読み込まない。全体検証中の共有画面は変更していない。

- retryMarkerは送信内容のSHA-256と送信IDだけを保存する。本文や画像bytesは追加保存しない。
- 同じ相談の再送は保存済みID、本文/添付変更は新ID。破損・保存失敗時は有料通信を開始しない。
- 本体recordStorageはページメモリのみ。draftSetの1秒遅延だけでは再読み込み後のIDを保証できない。
- 統合時は本人のmessageDraftsへ本文/画像ID/markerを一緒に設定し、cloudPushの成功・本人変更なし・保存内容一致を確認してからAI POSTする。保存競合、同期待ち、オフライン、保存失敗ならPOSTしない。既存同期仕様や認証を迂回しない。
- S.ai.sendingはdigest/保存を待つ前に立てて同時クリックを防ぐ。保存後の本文変更・画像変更も再確認する。旧IDは送信結果の確認まで維持し、自動再送しない。
- 成功後はmarker/本文/画像IDをまとめて消し同期する。消去保存失敗なら古いmarkerが復帰してもサーバーでキャッシュ再生され追加課金しない。
- 必須画面検証：保存前の離脱、送信中再読み込み、応答喪失後再読み込み、別アカウント切替、保存409/401/タイムアウト、添付変更、同時クリック、成功後の再相談。

独立した合成ストア検査13件成功。これは本体の永続保存完成を意味しない。
