# AIの未送信予約を解放する修正候補

2026-10-17。文章相談・ヒント・長文／写真ノート・写真相談で、startOperationの後、生成や計数を送る前に止まった予約が残る経路を修正する候補。2026-10-18に本体へ適用済み。候補・本体とも352件成功。

- 生成・計数その他のリクエストを呼ぶ直前に、結果不明でも送信済みと扱う記録を置く。
- スタンドアロンの安全確認だけは無料のため、そこだけで拒否・通信失敗・本人権限変更が起きたときは、既存の原子的な未課金予約解放を使う。
- token計数は無料と推測しない。計数・生成を送った後の通信断、出力拒否、保存不明は予約を保持する。
- 同意失効・別端末・日次枠の競合が、開始記録直後に起きた場合も、外部送信0回を確認できる位置で予約解放する。
- プラン枠の返却・共有の日次試験回数・停止回数・認証条件は緩和しない。失敗後の再操作は同じIDで明示し、送信済み不明の処理は再実行しない。
