2026-10-18。実送信直前の最後の本人確認で停止したのに、生成送信済みと記録して50円の内部予約を維持する境界不具合の修正。前全体19259はノート認証テストの旧期待値1件で終了コード1を確認後、SHAを照合して本体へ適用。
