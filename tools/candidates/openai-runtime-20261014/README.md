# OpenAI接続の統合候補（2026-10-14）

このフォルダは本体へ接続する前の候補です。実API経路からは読み込まれておらず、実通信を有効化しません。

- openai-transport.mjs：部分応答の停止をAbortSignalで閉じる。料金予約・入出力モデレーション・64KiB上限・利用トークン検査。
- openai-receipts.mjs：同一送信IDの予算予約と開始チェックポイント。応答喪失・競合時に二重実行しない。結果不明の開始済み操作を自動再送しない。
- openai-tutor-service.mjs：サーバープラン・本人リース・運営側の利用承認・保護者同意・支払い準備を確認し、ヒント/解説を既存教材検証へ接続。AIで採点を変更しない。
- openai-chat-content.mjs：テキスト相談の入出力契約。画像を黙って無視せず、画像付きは別の視覚入力経路ができるまで拒否する。

検証はverify-*.mjsの6本。35+10+21+16+28+50=160件。偽API・隔離SQLiteのみ。

未完了：本体API/UIへの接続、利用承認レコードを確認する経路、支払い不足の表示、実チャット保存、視覚入力・ノート分析、料金予約を実使用量で精算する処理。保守的予約が残るため、表示プラン回数より先に予算上限に達することがある。

利用承認レコードは運営側で確認した情報だけから作る。クライアントのモデル指定や年齢申告だけで承認しない。13歳未満はこの候補では許可しない。store:falseはゼロデータ保持の承認ではない。

統合前にmanifest.jsonの参照元SHAを照合する。検証中の本体へ差し替えず、全体検証の終了を確認してから適用する。秘密値や実ユーザー記録は含めない。

### 画像入力の追加候補

根拠：https://developers.openai.com/api/docs/guides/images-vision 、https://developers.openai.com/api/docs/guides/token-counting 。
