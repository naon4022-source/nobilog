## M1-P146｜身近な導入・既習事項・今回のつながり

［絵 M1-C3-S2-INTRO（未生成。制作指示は画像選定.md）：文房具店のレジで、おつりを受け取る中学生］

### 値段が分からないノート
1000円を出して、同じノート4冊と150円の消しゴム1個を買ったら、おつりが90円だった。ノート1冊はいくら？
- 分かっていること：出したお金 1000円、消しゴム 150円、おつり 90円、ノートは4冊。
- 分からないこと：ノート1冊の値段 → これを x 円とおく。
- 「出したお金 − 代金の合計 ＝ おつり」から、1000−(4x+150)＝90。
- 1節で学んだ方法で解ける。答えは、この節の P149 で確かめる。

### 使う、前に学んだこと
- 数量を文字式で表す（2章1節）、一次方程式の解き方（3章1節）、比例式（3章1節）。

## M1-P147｜方程式の利用①（代金・〜倍・過不足）／しくみ　（教科書 p102〜105・ワーク p64〜65）

［図 M1-C3-S2-FIG01：折り紙の過不足を、2本の線分図で表す（6枚ずつ→15枚余り、8枚ずつ→9枚足りない）］

### 方程式を使って問題を解く3つの手順
1. **数量の関係を見つける**：問題の中の数量に注目して、等しい関係をことばの式にする。
2. **方程式をつくって解く**：分からない数量のうち、適当なものを x とおく。
3. **解を確かめる**：方程式の解が、問題に合っているか調べて、答えを書く。

### なぜ「解を確かめる」が必要なの？
- 方程式の解が、人数なのに分数になったり、負の数になったりすることがある。
- 問題の条件（人数は自然数、時間は0以上など）に合わなければ、答えにできない。

### 過不足の問題の見方（FIG01）
- 配り方を変えても、**はじめにある折り紙の枚数は変わらない**。
- 6枚ずつ配ると15枚余る → 枚数＝6×人数+15。
- 8枚ずつ配ると9枚足りない → 枚数＝8×人数−9。
- 2つが等しいので、方程式ができる。

## M1-P148｜方程式の利用①／解き方

### 等しい関係の見つけ方（よく出る形）
| 場面 | ことばの式 |
|---|---|
| 買い物 | 出したお金 − 代金の合計 ＝ おつり |
| 「○は□の4倍」 | ○ ＝ □ × 4 |
| 配る（過不足） | 配り方1でのもとの数 ＝ 配り方2でのもとの数 |
| 2人の残金 | （Aの残金）＝（Bの残金）× ○ |

### 何を x にする？
- 多くの場合、**求めるもの** を x にすると式が作りやすい。
- 過不足では、ふつう **人数** を x にする（もとの数は、配り方ごとに式で表せる）。

### 解く順番
1. 分かっていること・分からないことを書き出す。
2. ことばの式をつくる。
3. x を決めて、方程式にする。
4. 解く。
5. 問題に合うか確かめて、単位をつけて答える。

## M1-P149｜方程式の利用①／例題　〔参考：教科書p102〜105・ワークp64〜65 ポイント3-12・3-13〕

### 例題1-基本（P146 のノート）
1. ことばの式：出したお金−代金＝おつり。
2. ノート1冊を x 円：1000−(4x+150)＝90。
3. 1000−4x−150＝90、−4x＝90−850、−4x＝−760、x＝190。
4. 確かめ：代金 4×190+150＝910、1000−910＝90。合っている。
5. 答え **190円**。

### 例題1-標準（〜倍）　ペン3本と200円のノート1冊の代金は、ペン1本と40円の消しゴム1個の代金の4倍です。ペン1本の値段は？
1. ことばの式：（ペン3本とノート）＝（ペン1本と消しゴム）×4。
2. ペン1本を x 円：3x+200＝4(x+40)。
3. 3x+200＝4x+160、−x＝−40、x＝40。
4. 確かめ：左 120+200＝320、右 (40+40)×4＝320。
5. 答え **40円**。

### 例題1-応用（過不足・FIG01）　折り紙を何人かに配ります。1人6枚ずつだと15枚余り、8枚ずつだと9枚足りません。人数と折り紙の枚数は？
1. 人数を x 人とする。
2. 枚数を2通りで表す：6x+15、8x−9。
3. 6x+15＝8x−9、−2x＝−24、x＝12。
4. 枚数：6×12+15＝87。確かめ：8×12−9＝87。
5. 答え **12人、87枚**。

## M1-P150｜方程式の利用①／つまずきと確認

### つまずきの比較
| まちがい | 正しい考え方 |
|---|---|
| 過不足で「足りない」のに +9 とする | 足りない分は、配る数より少ない → −9 |
| x を求めたところで終わる（人数だけ答える） | 問われたもの（枚数も）を全部答える |
| 確かめをしない | 解が問題に合うか、元の文章で確かめる |

<details><summary>答えと解説</summary>300円。−5x＝200−1700、x＝300。確かめ：5×300+300＝1800、2000−1800＝200。</details>

## M1-P151｜方程式の利用②（速さ・割合）／しくみ　（教科書 p106〜108・ワーク p66〜67）

［図 M1-C3-S2-FIG02：妹（先に出発）と姉（15分後に出発）の進んだ道のりを、表と線分図で対応させる］

### 追いつく問題の見方
- 「追いついた」＝ **同じ地点にいる** ＝ 家から進んだ道のりが等しい。
- 道のり＝速さ×時間。2人の時間を、同じ x を使って表す。
  - 姉が出発してから x 分後 → 姉は x 分、妹は (15+x) 分歩いている。

### 割合の問題の見方
- 「Aは Bの80%より8人多い」→ A＝0.8B+8（または (80/100)B+8）。
- 合計が分かっていれば、Aを B の式で表して、合計の式をつくる。

## M1-P152｜方程式の利用②／解き方

### 速さの問題を解く順番
1. 2人（または2つの動き）の、速さ・時間・道のりを **表** にする。
2. 分からない時間を x とおき、もう一方の時間を x の式で表す。
3. 等しい道のりから、方程式をつくる。
4. 解いて、**問題に合うか**（道のりが目的地までの距離をこえていないか）を確かめる。

### 割合の問題を解く順番
1. もとにする量を x とおく。
2. 割合を小数か分数にして、もう一方の量を x の式で表す。
3. 合計などの等しい関係から方程式をつくる。

**確かめる**：単位（分と時間、m と km）がそろっているか。

## M1-P153｜方程式の利用②／例題　〔参考：教科書p106〜108・ワークp66〜67 ポイント3-14・3-15〕

### 例題2-基本（速さ）　妹が分速60mで家を出発しました。15分後に、姉が分速150mで同じ道を追いかけました。姉は出発してから何分後に追いつきますか。
| | 姉 | 妹 |
|---|---|---|
| 速さ（m/分） | 150 | 60 |
| 時間（分） | x | 15+x |
| 道のり（m） | 150x | 60(15+x) |
1. 150x＝60(15+x)。
2. 150x＝900+60x、90x＝900、x＝10。
3. 確かめ：姉 150×10＝1500m、妹 60×25＝1500m。
4. 答え **10分後**。

### 例題2-標準（解が問題に合うか）　例題2-基本で、駅が家から 1.2km のところにあり、妹は駅まで行きます。姉は、妹が駅に着く前に追いつけますか。
1. 追いつく地点は家から 1500m。
2. 駅は 1200m。1500m は駅より先。
3. 答え **追いつけない**（妹は先に駅に着く）。
- 方程式の解（x＝10）は計算として正しいが、**この問題の条件には合わない**。だから③の確かめが必要。

### 例題2-応用（割合）　ある中学校の1年生は170人です。男子の人数は、女子の人数の80%より8人多いです。女子は何人ですか。
1. 女子を x 人とすると、男子は 0.8x+8（人）。
2. x+(0.8x+8)＝170。
3. 1.8x＝162、x＝90。
4. 確かめ：男子 0.8×90+8＝80、90+80＝170。
5. 答え **90人**。

## M1-P154｜方程式の利用②／つまずきと確認

### つまずきの比較
| まちがい | 正しい考え方 |
|---|---|
| 妹の時間を x、姉を 15+x とする | 先に出たのは妹。妹のほうが長く歩いている |
| 単位をそろえない（km と m） | どちらかにそろえてから式にする |
| 解が出たら、すぐ答えにする | 道のりや人数が、問題の条件に合うか確かめる |

### 考え方付き確認
**確認2-1**　姉が分速80mで駅へ歩き出し、その12分後に、妹が同じ道を自転車で分速240mで追いかけました。妹は出発してから何分後に姉に追いつきますか。
<details><summary>ヒント1</summary>追いつく＝2人が家から同じ道のりの所にいる。妹が x 分走ったとき、姉は何分歩いている？</details>
<details><summary>ヒント2</summary>姉は (12+x) 分歩いている。240x＝80(12+x)。</details>
<details><summary>答えと解説</summary>6分後。240x＝960+80x、160x＝960、x＝6。確かめ：妹 240×6＝1440m、姉 80×(12+6)＝1440m で同じ。見方を変えると、妹は1分ごとに 240−80＝160m ずつ差をちぢめ、はじめの差は 80×12＝960m なので 960÷160＝6分。方程式と同じ答えになる。</details>

**確認2-2**　あるクラブの部員は 58人です。2年生の人数は、1年生の人数の 75% より 5人少ないです。1年生は何人ですか。
<details><summary>ヒント1</summary>1年生を x 人とすると、2年生は 0.75x−5。</details>
<details><summary>答えと解説</summary>36人。x+0.75x−5＝58、1.75x＝63、x＝36。確かめ：2年生 0.75×36−5＝22、36+22＝58。</details>

## M1-P155｜比例式の利用／しくみ　（教科書 p109・ワーク p68）

［図 M1-C3-S2-FIG03（追加提案）：白と青の絵の具を 2：7 で混ぜる帯グラフ（全体 180g）］

### 比が等しい関係を見つける
- 「同じ割合で混ぜる」「比が○：△になった」→ 比例式で表せる。
- 全体の量が分かっているときは、「一部：全体」の比も使える。2：7 で混ぜると、白：全体＝2：(2+7)＝2：9。

### 比例式の利用の手順
方程式の利用と同じ3つの手順。等しい関係が「比」のとき、比例式をつくる。

---

## M1-P156｜比例式の利用／解き方

### 解く順番
1. 比で表されている2つの量を見つける。
2. 分からない量を x とおく。もう一方を x の式で表す（全体−x など）。
3. 比例式をつくり、外側の積＝内側の積で解く。
4. 問題に合うか確かめる（量が負になっていないか、合計が合うか）。

### どこを見る
- 「それぞれに同じ量を加える」→ 両方に +x。
- 「Aから取り出してBに入れる」→ Aは −x、Bは +x（合計は変わらない）。

## M1-P157｜比例式の利用／例題　〔参考：教科書p109・ワークp68 ポイント3-16〕

### 例題3-基本　白と青の絵の具を 2：7 の割合で混ぜて、180g の水色を作ります。白は何 g 必要ですか。
1. 白を x g とすると、x：180＝2：9。
2. 9x＝360、x＝40。
3. 確かめ：青は 140g、40：140＝2：7。
4. 答え **40g**。

### 例題3-標準　箱Aに玉が30個、箱Bに18個あります。それぞれに同じ数ずつ玉を加えたら、AとBの個数の比が 5：4 になりました。何個ずつ加えましたか。
1. x 個ずつ加えたとする。(30+x)：(18+x)＝5：4。
2. 4(30+x)＝5(18+x)、120+4x＝90+5x、x＝30。
3. 確かめ：60：48＝5：4。
4. 答え **30個ずつ**。

### 例題3-応用　びんAに水が 500mL、びんBに 300mL 入っています。Aから何 mL かをBに移したら、AとBの量の比が 3：5 になりました。移した量は？
1. x mL 移したとする。A は 500−x、B は 300+x。
2. (500−x)：(300+x)＝3：5。
3. 5(500−x)＝3(300+x)、2500−5x＝900+3x、−8x＝−1600、x＝200。
4. 確かめ：A 300、B 500、300：500＝3：5。合計 800 は変わらない。
5. 答え **200mL**。

## M1-P158｜比例式の利用／つまずきと確認

### つまずきの比較
| まちがい | 正しい考え方 |
|---|---|
| 移したのに、Aにも +x とする | 取り出した方は −x、入れた方は +x |
| x：180＝2：7 とする | 180 は全体。全体の比は 2+7＝9 |

## M1-P159｜別の場面へ使う・立式や判断の根拠・検算

### 「解が問題に合わない」ことに気づく
- 方程式を正しく解いても、答えが **問題の条件** に合わないことがある。
- 例：人数が 7.5人、時間が −3分、追いつく地点が目的地より先。
- そのときは「この条件では起こらない」と答える。

### 根拠を言えるようにしよう
例題2-標準で「追いつけない」と言える理由を、1文で説明してみよう。
<details><summary>説明の例</summary>追いつくのは家から1500mの地点だが、妹は1200mの駅で止まるので、その前に追いつくことはないから。</details>
