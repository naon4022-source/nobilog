# 模擬検定（本番と同じ問題数）2026-10-22 Claude

| 検定 | 問題数 | 構成 | 合格のめやす |
|---|---|---|---|
| 漢検4級 | 120問・200点・60分 | 読み30・同音同訓異字15・漢字識別5・熟語の構成10・部首10・対義語類義語10・漢字と送りがな5・四字熟語10・誤字訂正5・書き取り20 | 140点（70％程度） |
| 数検5級・4級・3級 | 各50問 | 1次（計算技能）30問50分＋2次（数理技能）20問60分 | 1次70％・2次60％ |
| 理科検定5級 | 20問・50分 | 物理6・化学6・生物4・地学4 | 70％ |

- すべて独自問題。過去問・サンプルは形式とレベルの参考だけ（台帳 mode:'kentei'、source-0627〜0634）。
- 漢検は、使った漢字がすべて小学校1026字（`漢検/資料/小学校1026字.txt`）＋4級313字（`漢検/資料/4級漢字313字.txt`）＝累計1339字の中にあることを `build_kanken.py` が自動で確認（外れたら止まる）。小学校1026字は学年ごとの字数（80・160・200・202・193・191）が公式と一致し、公式PDFの文字認識結果750字とも一致。
- 数検の新しい問題の答えは `build_suken_rika.py` の中で分数計算で検算。√が答えになる問題は採点できないので入れていない。
- 作り方：`python3 build_kanken.py && python3 build_suken_rika.py && python3 integrate.py` → `教材整理/確認済み/kentei-*.json`。
- 検査：`教材整理/特訓下書き/検定原稿/check_kentei.cjs`（正答が○・崩した答えが×・出典SHA）、`.claude/verify/verify-kentei-browser.mjs`（画面）。
