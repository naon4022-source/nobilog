## M1-P027｜加法、減法①（2数の和）／しくみ　（教科書 p24〜27・ワーク p6〜7）

［図 M1-C1-S2-FIG01：加法を数直線の移動で表す4つの式］

### たし算を数直線で考える
- (−4)+6 は「−4 より 6 大きい数」。1節で、これは「−4 から右へ6」だと学んだ。
- たす数が負の数なら、反対の左へ進む。5+(−6) は「5 から左へ6」。

| 式 | 動き | 答え |
|---|---|---|
| (+2)+(+3) | 2 から右へ3 | +5 |
| (−2)+(−3) | −2 から左へ3 | −5 |
| (+2)+(−3) | 2 から左へ3 | −1 |
| (−2)+(+3) | −2 から右へ3 | +1 |

### 気づくこと（なぜ）
- 同じ符号どうしは、同じ向きに進むので遠くへ行く → 絶対値は **たし算**。
- ちがう符号どうしは、行って、もどる → 絶対値は **ひき算**。残るのは、遠くへ進んだほう（絶対値の大きいほう）の向き。

### 打ち消し合いで見る
+1 と −1 が1組で 0。(+2)+(−5) では、2組が消えて −1 が3つ残る → −3。

## M1-P028｜加法、減法①／解き方

### きまり
- **同じ符号の2数の和**：符号は2数と同じ。絶対値は、絶対値の **和**。
- **ちがう符号の2数の和**：符号は絶対値の **大きいほう**。絶対値は、大きいほうから小さいほうを **ひいた差**。
- 絶対値が等しく、符号がちがう2数の和は 0。ある数に 0 をたしても、元のまま。

### どこを見る・解く順番
1. 2数の符号は同じ？ ちがう？
2. **答えの符号を先に書く**。
3. 絶対値の和、または差を計算する。
4. 小数・分数のときは、位や分母をそろえてから。

**確かめる**：答えの符号が、絶対値の大きいほうの符号と合っているか。答えを数直線で「行って・もどって」想像して、向きが合うか。

## M1-P031｜加法、減法②（減法）／しくみ　（教科書 p28〜30・ワーク p8〜9）

［図 M1-C1-S2-FIG02：(+3)−(+5) と (+3)+(−5) が同じ動きになる数直線］

### なぜ「ひく」は「符号を変えてたす」になるの？
- 3−5 は「3 より 5 小さい数」→ 3 から左へ5 → −2。
- (+3)+(−5) も「3 から左へ5」→ −2。動きがまったく同じ（FIG02）。
- 「−(−4)」は「−4 小さい」＝「4 大きい」なので、+(+4) と同じ。

### きまり
**正の数・負の数をひくには、符号を変えた数をたせばよい。**

### 「+」を書かない式
正の数の「+」は省いてよい。(+5)−(+8) は 5−8、(−3)+(−4) は −3−4 と書ける。

## M1-P035｜加法、減法③（項・3数以上）／しくみ　（教科書 p30〜32・ワーク p10〜11）

［図 M1-C1-S2-FIG03：式の項を、正の項と負の項の2つの箱に分ける図］

### 項
- 加法だけの式に直したときの、1つ1つの数を **項** という。
- 正の数の項を **正の項**、負の数の項を **負の項** という。
- 例：7−12+5−3 ＝ (+7)+(−12)+(+5)+(−3)。正の項は 7、5。負の項は −12、−3。

### なぜ順番を入れかえてよいの？
加法では、**交換法則**（a＋b＝b＋a）と **結合法則**（(a＋b)＋c＝a＋(b＋c)）が、負の数があっても成り立つ。だから、正の項・負の項を別々に集めてから計算してよい（FIG03）。

### 解く順番
1. かっこがあれば外して、項のならびに直す（−(−9) → +9）。
2. 正の項の和、負の項の和を、それぞれ出す。
3. 最後に2つをたす。

- 小数・分数がまじるときは、小数どうし・分数どうしを先にまとめると楽。

**確かめる**：項の数が、最初の式と同じか（1つ落としていないか）。

## M1-P039｜乗法、除法①（乗法）／しくみ　（教科書 p33〜35・ワーク p12〜13）

［図 M1-C1-S2-FIG04：かける数を1ずつ減らすと積が規則正しく変わる表］

### 負の数×正の数
(−3)×2 は、(−3) を2つたすこと → (−3)+(−3)＝−6。

### なぜ「負×負」は正になるの？（FIG04）
- (−3)×3、(−3)×2、(−3)×1、(−3)×0 は −9、−6、−3、0。
- かける数が1減るたびに、積は **3ずつ増える**。
- このきまりを続けると、(−3)×(−1)＝3、(−3)×(−2)＝6。
- だから「負の数×負の数」は正の数になる。

### きまり
- 同じ符号の2数の積：符号は **+**、絶対値は絶対値の積。
- ちがう符号の2数の積：符号は **−**、絶対値は絶対値の積。
- どんな数に 0 をかけても、0。

## M1-P040｜乗法、除法①／解き方

### 解く順番
1. 2数の符号を見る：同じなら +、ちがえば −。
2. 絶対値どうしをかける。
3. 符号と絶対値を組み合わせる。

### □を求める（(−8)×□＝56 の形）

2. 絶対値は、積の絶対値 ÷ わかっている数の絶対値。

**確かめる**：答えを元の式に入れて、積になるか。

## M1-P043｜乗法、除法②（除法・小数分数）／しくみ　（教科書 p36〜37・ワーク p14〜15）

［図 M1-C1-S2-FIG05：かけ算とわり算の対応（□×(−4)＝−12 と −12÷(−4)＝□）］

### なぜわり算の符号のきまりは、かけ算と同じなの？
- わり算は、かけ算の逆。(−12)÷(−4) は「□×(−4)＝−12」の □ を求めること（FIG05）。
- □＝3 だから、(−12)÷(−4)＝3。同じ符号 → +。
- (−12)÷4 は「□×4＝−12」で □＝−3。ちがう符号 → −。

### 0 のわり算
- 0 を正の数・負の数でわると 0。
- **どんな数も 0 でわることはできない**（□×0＝5 になる □ はないから）。

### 小数・分数の乗除
符号の決め方は同じ。そのあと、小数・分数の計算をする。

## M1-P047｜乗法、除法③（逆数・3数以上）／しくみ　（教科書 p38〜41・ワーク p16〜17）

［図 M1-C1-S2-FIG06：負の符号の個数と、積の符号の表］

### 逆数
- 2つの数の積が 1 になるとき、一方を他方の **逆数** という。
- −5/8 の逆数は −8/5（(−5/8)×(−8/5)＝1）。**逆数の符号は元の数と同じ**（積が +1 になるには同じ符号が必要）。

### わり算をかけ算に直す
**正の数・負の数でわるには、その数の逆数をかければよい。**
5÷(−3/4)＝5×(−4/3)。

### 3つ以上の数の乗除
- かけ算だけの式の符号は、負の数が **偶数個なら +、奇数個なら −**（FIG06）。
- なぜ？：負の数を2つかけるたびに、符号が + にもどるから。
- 乗法でも、交換法則・結合法則が成り立つ。かけやすい組から計算してよい（例：25×4）。

## M1-P048｜乗法、除法③／解き方

### 解く順番（乗除の混じった式）
1. ÷ を × に直す（わる数を逆数にする）。
2. 負の数の個数を数えて、符号を決める。
3. 絶対値の積を、約分しながら計算する。

### どこを見る

## M1-P051｜いろいろな計算①（累乗・四則の順序）／しくみ　（教科書 p42〜43・ワーク p18〜19）

### 分配法則
(a＋b)×c＝a×c＋b×c、c×(a＋b)＝c×a＋c×b。

## M1-P059｜数の世界のひろがり（数の集合と四則）／しくみ　（教科書 p46〜47・ワーク p24）

［図 M1-C1-S2-FIG07（追加提案）：自然数・整数・数全体の集合の包含図］

### 計算はいつでもできる？
- 自然数どうしのたし算・かけ算は、答えがいつも自然数になる。
- でも、ひき算は自然数にならないことがある（2−5＝−3）。わり算も（2÷5＝2/5）。
- 負の数まで広げて **整数** にすると、ひき算はいつでもできる。
- 小数・分数までふくめた **数全体** にすると、わり算もいつでもできる（0 でわることは除く）。

### 集合
- 自然数全体の集まりを **自然数の集合**、整数全体の集まりを **整数の集合** という。
- 自然数 ⊂ 整数 ⊂ 数全体 の順に、外側ほど広い（FIG07）。

## 追加提案 M1-P062a｜素数と素因数分解／しくみ　（教科書 p48〜50・ワーク p24〜25）

［図 M1-C1-S2-FIG08（追加提案）：60 の素因数分解の木（2通りの分け方）］

### 素数
- 1 とその数のほかに約数がない自然数を **素数** という。2、3、5、7、11、13、……
- **1 は素数ではない**。2 は、ただ1つの偶数の素数。

### 素因数分解
- 自然数を素数だけの積で表すことを **素因数分解** という。60＝2²×3×5。
- **なぜ大事？**：分け方を変えても、最後にできる素数の組は同じ（FIG08）。だから、数の「つくり」がはっきり分かる。
- 素因数分解すると、約数や倍数、2乗になる数かどうかが分かる。

## 追加提案 M1-P062b｜素数と素因数分解／解き方

### 解く順番（素因数分解）
1. 小さい素数（2、3、5、7、……）で、われるだけわる。
2. 商が素数になったら終わり。
3. 同じ素数は累乗でまとめる。

### どこを見る（素数かどうか）
- 一の位が偶数 → 2 でわれる。
- 各位の数の和が 3 の倍数 → 3 でわれる。
- 一の位が 0 か 5 → 5 でわれる。
- 7 や 11 でわれるかも確かめる（49＝7²、77＝7×11）。

### 2乗の数・共通の約数
- ある自然数の2乗は、素因数分解すると **どの素数も指数が偶数**。
- 2つの数の共通の約数は、**両方に共通する素数** の積でつくる。

**確かめる**：かけ直して元の数になるか。最後の数が本当に素数か。

## M1-P064｜全体のつながり・自分の言葉で整理・解説付き振り返り

### まとめ
- 加法・減法は「数直線の動き」。ひき算は符号を変えてたす。
- 乗法・除法は「まず符号、次に絶対値」。符号は負の数の個数で決まる。
- 計算の順序は「累乗 → かっこ → 乗除 → 加減」。
- 素因数分解で、数を素数の積に分けられる。

### 振り返りの問題

**次につながる**：3節では、平均などの身近な計算を、負の数を使って楽にする。
