# 教材の再構成（作業中・未公開）

- ワークを初期モードとし、ドリルと別々に単元を管理する。
- 各単元・各モード100問を目標とする。問題数のために同じ問題を重複させない。
- 登録済みワーク画像は国語70枚、数学72枚、社会77枚（地理43枚・歴史34枚）。ユーザー指定で全ワークを中1として記録。ページ・単元は未確認。保健体育ワークと社会ドリルは未登録。
- ドリルは英語の1〜3年を印刷された学年表示から分類。不明なものは推測で公開しない。
- 原典の教科・ページ・大問・小問を記録。類題には「類題」と明示し、元の問題そのものと区別する。
- 問題・解答・図版の対応を確認してから公開する。OCRは下書きであり、正解の根拠として単独使用しない。
- 教材台帳を更新するときは `python3 教材整理/scripts/catalog.py --check` で先に差分を確認する。更新後は同スクリプトと `validate_catalog.py` でファイルの分類、SHA-256、OCRの元画像対応を照合する。
- 2026-09-27追加の数学・地理・歴史149枚は教材台帳に登録済み。学年はユーザー指定の中1、ページ・単元・問題対応は未確認。人手確認済みにはしない。
- 台帳生成は教科フォルダーを明示して分類し、不明な配置はエラーで止める。既存の出典IDと人手確認欄を引き継ぎ、原本の内容が変わった場合は前の確認を無効にする。OCR文字があっても `verified` にはしない。
- 教材を `ready` にするには、教科書の目標・要約・確認済み説明節、出典台帳で人が確認した `source ID + SHA-256 + モード + 教科 + 学年 + ページ`、入力式の練習100問、重複しない類題テストがそろう必要がある。IDや原本ハッシュ、ドリル／ワークの区分が合わない教材は表示しない。
- テストは基礎・標準・発展を混ぜ、学習問題の数字・条件を変更した別問にする。
- 入力式を基本とし、読む教材は読む操作にする。正解後は1問進む。保存失敗時に進捗を失ったまま先へ進めない。
- 数値や重要語は必須条件として判定する。記述は必要要素の70％以上を満たし、核心の否定・矛盾がない場合だけ正解とする。単純な文字列類似率70％で採点しない。
- 独自の教科書はワークの単元に対応させ、導入・具体例・図解・練習・振り返りを用意する。
- 旧問題は置き換え対象。過去の答案・成績・ログイン情報は削除対象外。
- 写真への書き込みを無視する指示の意味は確認中。
