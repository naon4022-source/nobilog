# 原稿受入基準

392ページは初期配分で、必要な説明を省く上限ではない。枠や画像だけで完成扱いにしない。

- 各説明ページは主要な考え方を一つに絞り、意味・見る場所・判断・手順・理由・確かめ方を内容に応じて説明する。
- 問題を置くページにも考え方、段階的ヒント、初期状態で隠れた解答と解説を用意する。問題だけで埋めない。
- 基本・標準・応用は前の説明で解けることを照合する。応用に未習内容を混ぜない。
- 資料名と実ページを記録し、本文・例題・問題・解答・図の条件を相互に照合する。
- Claudeが本文と問題を執筆する。Codexは原稿を勝手に補完せず、表示変更と画像仕様の不足を連絡する。
- 11インチ相当の縦横とPCで文字・図・入力欄の読める大きさ、はみ出し、目次の移動、入力保持を隔離検証する。代表サイズの合格と実機確認を区別する。
- 計算検証と画面検証の合格だけで、全編の教材内容が確認済みとは扱わない。未確認はページと理由を明記する。
