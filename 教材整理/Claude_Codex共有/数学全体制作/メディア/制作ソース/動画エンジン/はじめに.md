# 動画エンジン（Claude作・2026-10-04）
ユーザーの指摘「カクカクで、よく分からない」を受けて作った、ナレーションつき動画の作り方。

## 作り方
1. `台本.json` を書く：`{"voice":"Kyoko","rate":180,"head":1.0,"tail":2.0,"gap":0.8,"steps":[{"say":"読み上げる文","cap":"字幕（省略可）","hold":0.5}]}`
   - 1文＝1ステップ。`say` は読み上げ用（記号は読みにくいので「ブイ イコール 3分の1」のように書く）。画面の字幕を変えたいときだけ `cap`。
   - `hold` は、読み終わったあとに動きを見せる・考える時間（秒）。
2. `場面.html` を書く：`<script src="動画エンジン/engine.js">` を読み、`window.SCENE={draw({i,p,t}){...}}` で、ステップ番号 i と進み p（0〜1）から絵を描く。
   - 部品：`header(題, 右上の札)`、`text`、`frac`（分数）、`rbox`、`ring`（印の丸）、`arrow`、`seg(p,a,b)`（ステップの一部分で動かす）。字幕は自動。
3. `python3 動画エンジン/make_video.py 場面.html 台本.json メディア/<ID>.mp4 [コマ保存フォルダ]`
   - 読み上げ（macOS の say）→ 長さに合わせた時間割 → 30コマ/秒で録画 → 音声を重ねて H.264/AAC の mp4。
   - ffmpeg は環境変数 `FFMPEG`（省略時 /tmp/nobilog-media-tools/... を使う）。

## 点検
- コマ保存フォルダを付けると1.5秒ごとのコマが残る。一覧画像にして全部目で見る（はみ出し・重なり・字幕に隠れる・かくすもの）。
- 見本：`制作ソース/M1-C6-S2-V01.html` と `.json`（円錐3杯で円柱いっぱい）。
