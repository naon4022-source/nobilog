## M1-P333｜1章 正の数・負の数／例題

［図 M1-APP2-FIG01：数直線の上で、＋3 は右へ3、−5 は左へ5 進む矢印をつなぎ、(+3)＋(−5)＝−2 を示した図］

### 解き方の整理
| 場面 | 手順 |
|---|---|
| 加法・減法 | ひく数は符号を変えてたす。正の項・負の項をまとめる |
| 乗法・除法 | 符号を先に決める（負の数が奇数個→−、偶数個→＋） |
| 四則の混じった計算 | 累乗・かっこ → 乗除 → 加減 |
| 素因数分解 | 小さい素数から順にわる |

### 追加の問題
**問1**　★（−7）＋12−（−5）
<details><summary>答え</summary>10</details>

**問2**　★（−2）³×(−3)÷6
<details><summary>答え</summary>4（−8×(−3)＝24、24÷6）</details>

**問3**　−3²＋(−4)×(−2)
<details><summary>答え</summary>−1（−9＋8）</details>

**問4**　(−5/6)÷(10/9)×(−4)
<details><summary>答え</summary>3（−5/6×9/10＝−3/4、×(−4)＝3）</details>

**問5**　★ 180 を素因数分解しなさい。
<details><summary>答え</summary>2²×3²×5</details>

**問6**　絶対値が 4 以下の整数は、全部でいくつありますか。
<details><summary>答え</summary>9個（−4〜4）</details>

### チャレンジ
**問7**　ある数に −3 をかけるところを、まちがえて −3 をたしたので、答えが 5 になりました。正しい答えを求めなさい。
<details><summary>ヒント</summary>ある数＋(−3)＝5 から、ある数を出す。</details>
<details><summary>答え</summary>−24（ある数は 8。8×(−3)）</details>

## M1-P337｜2章 文字の式／例題

［図 M1-APP2-FIG02：3(2x−4) のかっこを外すとき、3 が 2x と −4 の両方にかかることを、2本の矢印で示した図］

### 解き方の整理
| 場面 | 手順 |
|---|---|
| 式の表し方 | ×をはぶく、数は文字の前、÷は分数 |
| 式の値 | 負の数はかっこをつけて代入 |
| 1次式の計算 | かっこを外す（分配法則）→ 同類項をまとめる |
| 数量の関係 | 等しい→等式、大小→不等式 |

### 追加の問題
**問1**　★ a×(−3)×b を、×をはぶいて書きなさい。
<details><summary>答え</summary>−3ab</details>

**問2**　★ x＝−2 のとき、5−x² の値を求めなさい。
<details><summary>答え</summary>1（5−4）</details>

**問3**　★ 4(3x−2)−3(2x−5)
<details><summary>答え</summary>6x＋7</details>

**問4**　(9a−6)÷(−3)
<details><summary>答え</summary>−3a＋2</details>

**問5**　(x−1)/2＋(2x＋1)/3
<details><summary>答え</summary>(7x−1)/6（3(x−1)＋2(2x＋1)＝7x−1）</details>

**問6**　1個 a 円のパン 3個と、1本 b 円の牛乳 2本の代金は 600円より安い。これを不等式で表しなさい。
<details><summary>答え</summary>3a＋2b＜600</details>

### チャレンジ
**問7**　1辺に n 個ずつ、正方形の形に石を並べます（4つのかどの石は1個ずつ）。全部で何個ですか。n＝10 のときの個数も答えなさい。
<details><summary>ヒント</summary>1辺 n 個を4本分で 4n。かどの石を2回ずつ数えている。</details>
<details><summary>答え</summary>4n−4 個。n＝10 のとき 36個。</details>

## M1-P341｜3章 方程式／例題

［図 M1-APP2-FIG03：天びんの両側から同じものを取りのぞいても、つり合いが変わらないことを示した図（x の箱と1の重り）］

### 解き方の整理
| 場面 | 手順 |
|---|---|
| 方程式を解く | かっこを外す → 小数・分数は係数を整数に → 移項 → ax＝b → 両辺を a でわる |
| 比例式 | a：b＝c：d なら ad＝bc |
| 文章題 | x を決める → 等しい関係を式に → 解く → 問題にもどして確かめる |

### 追加の問題
**問1**　★ 7x−4＝3x＋20
<details><summary>答え</summary>x＝6</details>

**問2**　★ 2(x−3)＝5x＋9
<details><summary>答え</summary>x＝−5</details>

**問3**　0.4x−1.2＝0.1x＋0.3
<details><summary>答え</summary>x＝5（10倍して 4x−12＝x＋3）</details>

**問4**　(x＋2)/3＝(x−1)/2
<details><summary>答え</summary>x＝7（2(x＋2)＝3(x−1)）</details>

**問5**　★ x：12＝5：4
<details><summary>答え</summary>x＝15</details>

**問6**　★ 1本 90円の鉛筆と 1本 120円のペンを合わせて 10本買うと、代金は 1020円でした。鉛筆は何本ですか。
<details><summary>答え</summary>6本（90x＋120(10−x)＝1020）</details>

### チャレンジ
**問7**　x についての方程式 3x−a＝2x＋5 の解が x＝4 のとき、a の値を求めなさい。
<details><summary>答え</summary>a＝−1（12−a＝13）</details>

## M1-P345｜4章 変化と対応／例題

［図 M1-APP2-FIG04：比例 y＝2x の直線と、反比例 y＝8/x の双曲線を同じ座標平面にかき、2つが交わる点 (2, 4) を示した図］

### 解き方の整理
| 場面 | 手順 |
|---|---|
| 比例 | y＝ax。a＝y÷x。グラフは原点を通る直線 |
| 反比例 | y＝a/x。a＝x×y。グラフは双曲線 |
| 座標 | (x 座標, y 座標)。右・上が正 |
| 利用 | 何が一定か → 比例か反比例か → 式 → 答えと確かめ |

### 追加の問題
**問1**　★ y は x に比例し、x＝−4 のとき y＝12 です。式を求めなさい。
<details><summary>答え</summary>y＝−3x</details>

**問2**　★ y は x に反比例し、x＝6 のとき y＝−2 です。x＝−3 のときの y を求めなさい。
<details><summary>答え</summary>4（y＝−12/x）</details>

**問3**　y＝(2/5)x のグラフが通る点で、x 座標が 10 の点の y 座標を答えなさい。
<details><summary>答え</summary>4</details>

**問4**　点 (3, −4) と x 軸について対称な点の座標を答えなさい。
<details><summary>答え</summary>(3, 4)</details>

**問5**　★ y＝2x と y＝8/x のグラフの交点のうち、x 座標が正のものを求めなさい。
<details><summary>ヒント</summary>2x＝8/x を満たす正の x。x×x＝4。</details>
<details><summary>答え</summary>(2, 4)</details>

**問6**　8人で 9日かかる仕事を、12人ですると何日かかりますか。
<details><summary>答え</summary>6日（8×9＝72）</details>

### チャレンジ
**問7**　y＝a/x のグラフ上に、2点 (2, 9) と (b, −6) があります。a と b の値を求めなさい。
<details><summary>答え</summary>a＝18、b＝−3</details>

## M1-P349｜5章 平面図形／例題

［図 M1-APP2-FIG05：半径 r、中心角 a° のおうぎ形に「弧＝2πr×a/360」「面積＝πr²×a/360」「面積＝(1/2)×弧×r」の3つの式を矢印でつけた図］

### 解き方の整理
| 場面 | 手順 |
|---|---|
| 移動 | 平行（ずらす）・回転（まわす）・対称（折り返す） |
| 作図 | 2点から等しい→垂直二等分線、2辺から等しい→角の二等分線、直角→垂線 |
| 円・おうぎ形 | 円全体を出して a/360 をかける。面積は (1/2)ℓr でも |

### 追加の問題
**問1**　★ 半径 6cm、中心角 60° のおうぎ形の弧の長さと面積を求めなさい。
<details><summary>答え</summary>弧 2π cm、面積 6π cm²</details>

**問2**　★ 半径 8cm、弧の長さ 6π cm のおうぎ形の中心角を求めなさい。
<details><summary>答え</summary>135°</details>

**問3**　半径 4cm、弧の長さ 5π cm のおうぎ形の面積を求めなさい。
<details><summary>答え</summary>10π cm²（(1/2)×5π×4）</details>

**問4**　点 O を中心に 90° 回転移動を2回続けると、何という移動と同じですか。
<details><summary>答え</summary>点対称移動（180° の回転移動）</details>

**問5**　★ 150° の角を作図するには、作図できるどの角を組み合わせればよいですか。1つ答えなさい。
<details><summary>答え</summary>例：90°＋60°（または 180°−30°）</details>

**問6**　円 O の外の点 P から引いた接線の接点を A とすると、∠AOP＝55° でした。∠APO を求めなさい。
<details><summary>答え</summary>35°</details>

### チャレンジ
**問7**　1辺 4cm の正方形の中に、1つの頂点を中心とする半径 4cm、中心角 90° のおうぎ形をかきました。正方形のうち、おうぎ形に入らない部分の面積を求めなさい。
<details><summary>答え</summary>16−4π（cm²）</details>

## M1-P357｜7章 データの活用／例題

［図 M1-APP2-FIG07：度数分布表の「階級値」「階級値×度数」「相対度数」「累積相対度数」の列を順に足していくようすを示した図（数値は入れない）］

### 解き方の整理
| 場面 | 手順 |
|---|---|
| 範囲 | 最大値−最小値 |
| 代表値 | 平均値・中央値（並べてまん中）・最頻値（度数分布表では階級値） |
| 相対度数 | 度数÷合計。個数のちがうデータは相対度数でくらべる |
| 確率 | 多数回の相対度数。予想≒確率×回数 |

### 追加の問題
**問1**　★ 8、14、5、11、9、17、6 の範囲と中央値を求めなさい。
<details><summary>答え</summary>範囲 12、中央値 9</details>

**問2**　★ 合計 60人のうち、ある階級の度数が 21人のとき、相対度数を求めなさい。
<details><summary>答え</summary>0.35</details>

**問3**　度数分布表 0 以上 10 未満：3、10〜20：6、20〜30：9、30〜40：2（合計20）から平均値を求めなさい。
<details><summary>答え</summary>20（(15＋90＋225＋70)÷20＝400÷20）</details>

**問4**　問3の表で、最頻値と、中央値がふくまれる階級を答えなさい。
<details><summary>答え</summary>最頻値 25、中央値は 20 以上 30 未満の階級（累積度数 3、9、18 → 10番目と11番目はどちらも 20〜30）</details>

**問5**　★ あることがらが 1500回中 390回起こりました。確率を求めなさい。
<details><summary>答え</summary>0.26</details>

**問6**　確率 0.26 のことがらを 200回くり返すと、およそ何回起こると予想されますか。
<details><summary>答え</summary>およそ 52回</details>

### チャレンジ
**問7**　5人の点数の平均値は 70点でした。6人目が加わると平均値は 72点になりました。6人目の点数を求めなさい。
<details><summary>答え</summary>82点（72×6−70×5＝432−350）</details>
