# M1-C4-S4　ポイントとかんたんにやる方法
## この節のポイント
- 身のまわりの問題は、**何が一定か** を見つけると、比例か反比例かが分かる。
- 単価・速さが一定 → 比例。全体の量（道のり・仕事・歯の数×回転数）が一定 → 反比例。
- 答えには単位をつけ、変域に合うかを確かめる。
## かんたんにやる方法
1. 「一方を2倍にしたら、もう一方は？」と自分に聞く。2倍なら比例、半分なら反比例。
2. 比例なら「1あたり」、反比例なら「全体の量」を先に求める。
3. グラフの2本の直線の縦の差は、同じ時間での差。
## よくあるミス
- 人数がふえると時間もふえると考える（仕事の量が一定なら減る）。
- 単位（分と時間、g と kg）をそろえない。
## 30秒チェック
**チェック1**　同じ本 20 冊の重さが 6kg。この本 x 冊の重さ y kg の式は？
<details><summary>答え</summary>y＝0.3x</details>

**チェック2**　ある道のりを時速 4km で 3 時間かかった。時速 6km なら何時間？
<details><summary>答え</summary>2時間（4×3＝12km、12÷6）</details>
