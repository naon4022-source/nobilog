# Claude原稿（中1数学）の書き方の約束

Claude Codeが書く原稿の置き場。Codexはここを読んでページへ組み込む。ここ以外（制作台帳.json・ページの枠・全体ページ構成.md・表示ファイル）はClaudeは編集しない。

## 単元フォルダ `<単元ID>/` の中身
| ファイル | 中身 |
|---|---|
| 本文.md | ページごとの本文・図の置き場所・例題・やってみよう（練習） |
| 確認問題.md | 単元の最後の「自力で確かめる」問題（入力式） |
| 解答と採点基準.md | 正答・根拠・許容表記・部分的正答・明確な誤答 |
| 図の仕様.json | 正確な図（SVG）の数学条件。4候補で変えてはいけない項目を含む |
| 画像選定.md | 場面イラストの候補比較・採用理由・未生成の場面の制作指示 |
| 点検.md | 原本の読み取り状態・対応・検算結果 |
| 未確認.md | 読めない・確認できない箇所と理由 |
| 引き継ぎ.md | Codexへの依頼・次の作業 |
| ページ構成提案.md | 枠の増減の提案（あるときだけ） |
| 検算.py | 答えの検算（あるときだけ。標準ライブラリだけ・読むだけ） |

## 本文.md の書き方
- ページの区切り：`## M1-P003｜役割`。新しく足したいページは `## 追加提案 M1-P006b｜役割` と書き、ページ構成提案.mdに理由を書く。
- 説明は、次の4つの見出しで段階に分ける（全部が必要なときだけ使う）。
  - **なぜ**（そうなる理由）
  - **どこを見る**（見分ける場所）
  - **解く順番**
  - **確かめる**（途中・最後に何をチェックするか）
- 図の置き場所：`［図 M1-C1-S1-FIG01］`。場面絵は `［絵 M1-C1-S1-INTRO］`。
- 問題には小さく出典を付ける：`〔参考：教科書p15・ワークp2 A2〕`。どれも独自の問題で、原本の問題をそのまま載せたものではない。
- ヒントと答えは、考える前に見えないように `<details>` で閉じておく。
  - 順番は「ヒント1 → ヒント2 → 答えと解説」。ヒントは答えを言わない。
  - アプリでは、押したときだけ開く表示にする。

## 数と記号
- 負の符号は「−」（U+2212）。分数は本文では「2/9」のように書く。アプリでは分数の表示にしてよい。
- 画像に数字・答え・文字を焼き込まない。数や文字が必要な図はSVG（図の仕様.json）。
