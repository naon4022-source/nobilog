## M1-P003｜生活から入る

［絵 M1-C1-S1-INTRO（未生成。制作指示は画像選定.md）：山の上と海の中。海面が「0」の場面］

### 海面より上と、海面より下
- 山の高さは「海面から何mか」で表す。では、海の中の深い所はどう表す？
- 海面を0と決める。そうすると、上と下を **同じものさし** で言える。
- 0より上は「+」、0より下は「−」を使う。
- 温度でも同じ。0℃より下の温度を「−」で表す。

### なぜ「−」を使うの？
「0より6低い」と書くと長い。ほかの数とならべてくらべることもしにくい。
「−6」と書けば、1つの数として、ほかの数とならべたり、くらべたりできる。

## M1-P004｜「−」のついた数と、数のなかま　（教科書 p14〜15・ワーク p2〜3）

［図 M1-C1-S1-FIG01：正の数と負の数の数直線］

### 1　0より小さい数の書き方・読み方
- 0℃より4℃低い温度は **−4℃**。「**マイナス**4度」と読む。
- 0より小さい数は、数の前に「−」をつける。
  - 0より6小さい数 → −6
  - 0より0.5小さい数 → −0.5
  - 0より1/3小さい数 → −1/3

### 2　正の数・負の数・0
- 0より小さい数を **負の数**、0より大きい数を **正の数** という。
- **0は、正の数でも負の数でもない**。0は、上と下の「さかい目」の数。
- 正の数には「+」をつけることもある。4 と +4 は同じ数で、+4 は「**プラス**4」と読む。
- この「+」を **正の符号**、「−」を **負の符号** という。

### 3　整数と自然数
- これからは、……、−3、−2、−1、0、1、2、3、…… をすべて **整数** という。
- そのうち 1、2、3、…… を **自然数**（正の整数）という。**0は自然数に入らない**。

**どこを見る**
1. 「−」がついているか → ついていれば負の数。
2. 値が整数になるか → 2.5 や −1/2 は整数ではない。+6/3 は 2 と同じなので整数。
3. 0 か → 整数には入る。正の数・負の数・自然数には入らない。

### やってみよう 1　〔参考：教科書p14〜15・ワークp2 A2〕
0より1.25小さい数を、符号をつけて書きなさい。
<details><summary>ヒント1</summary>「0より小さい」から、負の数になる。</details>
<details><summary>答えと解説</summary>−1.25。0から1.25だけ小さいので、「−」をつけて −1.25。</details>

### やってみよう 2　〔参考：教科書p15・ワークp3 B1〕
−3、0、+5 のうち、「整数だが、自然数ではない」ものをすべて答えなさい。
<details><summary>ヒント1</summary>3つとも整数かどうかを、先に確かめよう。</details>
<details><summary>ヒント2</summary>自然数は 1、2、3、…… だけ。0 と負の数は入らない。</details>
<details><summary>答えと解説</summary>−3 と 0。3つとも整数。+5 は自然数なので外す。0 を落とさないように。</details>

## M1-P005｜数直線に置く・数直線を読む　（教科書 p16・ワーク p2）

［図 M1-C1-S1-FIG02：1目盛り0.2の数直線と点P・Q］

### なぜ数直線を使うの？
数を「位置」で見られるから。0より右は正の数、0より左は負の数。**右にあるほど大きい**。

### 解く順番（目盛りを読むとき）
1. 0 と 1 のあいだが、いくつに区切られているかを数える。
2. 1目盛りの大きさを出す（5つに区切られていれば 1÷5＝0.2）。
3. 0から何目盛り、どちら向きかを数える。
4. 右なら「+」、左なら「−」をつける。

**確かめる**：1目盛りが1とはかぎらない。答えを出したら、1目盛りの大きさで数え直して確かめる。

### 例題1-応用　〔参考：教科書p16・ワークp2 A3〕
［図 M1-C1-S1-FIG02］の点P、点Qが表す数を答えなさい。
<details><summary>ヒント1</summary>0から1までが、いくつに区切られているかな。</details>
<details><summary>ヒント2</summary>1目盛りは 0.2。P は0の左、Q は0の右。</details>
<details><summary>答えと解説</summary>P は −0.6、Q は +0.4。P は0から左へ3目盛りなので 0.2×3＝0.6 小さい。Q は右へ2目盛りで 0.4。</details>

### やってみよう 3　〔参考：教科書p16・ワークp2 A4〕
1目盛りが0.5の数直線で、0から左へ9目盛りの点は、どんな数を表しますか。
<details><summary>ヒント1</summary>0.5 が9つ分で、いくつ？</details>
<details><summary>答えと解説</summary>−4.5。0.5×9＝4.5。左なので負の数。</details>

### 例題1-基本・標準　〔参考：教科書p14〜15・ワークp2〜3〕
**基本**　0℃より9℃低い温度を、「−」を使って表しなさい。
<details><summary>答えと解説</summary>−9℃。0℃より低いので負の数。0℃から9℃はなれている。</details>

**標準**　次の数の中から、（1）負の数、（2）整数、（3）自然数を、それぞれすべて選びなさい。
　−7、0.4、0、+3、−2/5、15、−1、1.2
<details><summary>ヒント1</summary>上の「どこを見る」の3つの順で、1つずつ調べよう。</details>
<details><summary>ヒント2</summary>0 はどこに入って、どこに入らないかな。</details>
<details><summary>答えと解説</summary>（1）−7、−2/5、−1　（2）−7、0、+3、15、−1　（3）+3、15。0 は負の数ではないが、整数には入る。−2/5 は負の数だが整数ではない。+3 は 3 と同じなので自然数。</details>

### まちがいの振り返り
| まちがい | 正しい考え方 |
|---|---|
| 0 を正の数に入れる | 0 は正でも負でもない |
| 0 を自然数に入れる | 自然数は 1 から |
| 目盛りを全部1と読む | 先に1目盛りの大きさを出す |

## M1-P006｜反対の意味の量・基準とのちがい　（教科書 p17〜18・ワーク p3）

### なぜ正の数・負の数で量を表せるの？
「東・西」「高い・低い」「多い・少ない」のように、反対の意味の組がある。
- 片方を「+」と決めると、もう片方は「−」で表せる。
- **はじめに、どちらを「+」にするかを決めておく**。決めないと、数だけでは意味が伝わらない。

### 基準とのちがい
［図 M1-C1-S1-FIG03：目標20ページとのちがい］
1. 目標などの数を **基準** にして、それを 0 とみる。
2. 基準より多ければ「+」、少なければ「−」、同じなら「0」。

### 1つのことばで言いかえる
- 「7本少ない」は「−7本多い」と言える。
- **言いかえるときは、ことばと符号の両方を反対にする**。

### 例題2　〔参考：教科書p17〜18・ワークp3 A5・B2〕
**基本**　東へ300m進むことを +300m と表すとき、西へ200m進むことはどう表せますか。
<details><summary>答えと解説</summary>−200m。西は東の反対なので、負の数。</details>

**標準**　1日の読書の目標を20ページとし、目標とのちがいを正の数・負の数で表します。月曜26ページ、火曜17ページ、水曜20ページ読みました。それぞれのちがいは？
<details><summary>ヒント1</summary>まず、目標の20ページより多いか少ないかを見よう。</details>
<details><summary>答えと解説</summary>月 +6、火 −3、水 0（ページ）。26は20より6多い。17は20より3少ない。20は同じなので0。図のように、多い日は上、少ない日は下になる。</details>

**応用**（1）「3日おそい」ことを、「早い」ということばを使って表しなさい。
<details><summary>ヒント1</summary>「おそい」の反対のことばは「早い」。</details>
<details><summary>答えと解説</summary>−3日早い。ことばを反対にしたので、符号も反対にする。</details>

**応用**（2）あるテストで、基準の50点とのちがいが「−8点」の人は、何点ですか。
<details><summary>答えと解説</summary>42点。−8点は「50点より8点少ない」という意味。50−8＝42。</details>

### やってみよう 4　〔参考：教科書p18・ワークp3 A5〕
「2kg重い」ことを +2kg と表すとき、「0.5kg軽い」ことはどう表せますか。
<details><summary>答えと解説</summary>−0.5kg。軽いは重いの反対なので、負の数。</details>

### やってみよう 5　〔参考：教科書p18・ワークp3 B2〕
基準を100点として、ちがいが +7点の人は何点ですか。
<details><summary>答えと解説</summary>107点。+7点は「100点より7点多い」。</details>

### まちがいの振り返り
- どちらを「+」にしたかを書かない。
- 言いかえで、ことばだけ反対にして、符号を変え忘れる（「7本少ない」を「7本多い」としてしまう）。
- 基準と同じとき、何も書かない。→「0」と書く。

## M1-P007｜絶対値と数の大小　（教科書 p19〜20・ワーク p4）

［図 M1-C1-S1-FIG04：−3 と 3 はどちらも0からきょり3］

### 符号を変えた数・絶対値
- +5 の符号を変えると −5。数直線では、0をはさんで反対がわの、同じ遠さの点。
- 0からの **きょり** を **絶対値** という。−3 も 3 も、絶対値は 3。0 の絶対値は 0。
- **なぜ「−」がつかない？** きょりはマイナスにならないから。

### 数の大小
**どこを見る**：数直線では、右にあるほど大きい。
1. 正の数は、負の数より大きい。
2. 正の数は、絶対値が大きいほど大きい。
3. 負の数は、**絶対値が大きいほど小さい**（0から左へ遠いほど小さい）。

［絵 M1-C1-S1-APPLY（未生成。制作指示は画像選定.md）：寒い朝の2つの町の温度計。数字はなし］
**別の見方**：気温で考えると、−8℃ は −2℃ より寒い。だから −8 は −2 より小さい。

### 不等号で書く
- 「<」「>」の口が開いているほうが大きい。例：−6 < −1。
- 3つ以上の数は、**向きをそろえて** 1本の式にする（−5 < −2 < 4）。
  - 「−5 < 4 > −2」のように、向きをまぜて書かない。

### 解く順番（大小をくらべるとき）
1. 正の数・0・負の数に分ける。
2. 負の数どうしは、絶対値の大きいほうが小さい。
3. 分数と小数がまじるときは、どちらかにそろえる。
4. 小さい順にならべて、不等号の向きをそろえる。

**確かめる**：答えの数を数直線に置いたとき、左から順にならんでいるか。

### 例題3　〔参考：教科書p19〜20・ワークp4 A1・A2・A3〕
**基本**　−11 の絶対値と、−11 の符号を変えた数を答えなさい。
<details><summary>答えと解説</summary>絶対値は 11、符号を変えた数は +11。絶対値には「−」をつけない。</details>

**標準**（1）−3.5 と −2 の大小を、不等号で表しなさい。
<details><summary>ヒント1</summary>どちらも負の数。絶対値はどちらが大きい？</details>
<details><summary>答えと解説</summary>−3.5 < −2。絶対値が大きい −3.5 のほうが小さい。</details>

**標準**（2）−1、−4/3、0.5 の大小を、1つの式で表しなさい。
<details><summary>ヒント1</summary>4/3 と 1 は、どちらが大きい？</details>
<details><summary>答えと解説</summary>−4/3 < −1 < 0.5。4/3 は 1 より大きいので、−4/3 は −1 より小さい。0.5 は正の数でいちばん大きい。</details>

### やってみよう 6　〔参考：教科書p19・ワークp4 A1〕
絶対値が 4 になる数を、すべて答えなさい。
<details><summary>ヒント1</summary>0から右へ4、左へ4。</details>
<details><summary>答えと解説</summary>4 と −4（+4 でもよい）。0からのきょりが4の点は、右と左に1つずつある。</details>

### やってみよう 7　〔参考：教科書p20・ワークp5 B1〕
−0.7 と −0.08 の大小を、不等号で表しなさい。
<details><summary>ヒント1</summary>0.7 と 0.08 は、どちらが大きい？ けた数ではなく、位をそろえてくらべよう。</details>
<details><summary>答えと解説</summary>−0.7 < −0.08。0.7＝0.70 は 0.08 より大きい。絶対値が大きい −0.7 のほうが小さい。</details>

### まちがいの振り返り
| まちがい | 正しい考え方 |
|---|---|
| −8 の 8 が大きいから、−8 > −2 | 負の数は、絶対値が大きいほど小さい |
| −5 の絶対値を −5 とする | 絶対値はきょりなので「−」はつかない |
| 3つの数で不等号の向きをまぜる | 向きをそろえて、小さい順に書く |

## 追加提案 M1-P007b｜数直線で「〜より○大きい数」を求める　（教科書 p21〜22・ワーク p5）

［図 M1-C1-S1-FIG05：1から右へ3、1から左へ3］

### なぜ「−3大きい」は「3小さい」？
- 「3大きい」は、右へ3進むこと。
- 「−3大きい」は、その反対の向き、つまり左へ3進むこと。
- だから「1より−3大きい数」は「1より3小さい数」と同じで、−2。

### 解く順番
1. 「−○大きい」は「○小さい」に、「−○小さい」は「○大きい」に言いかえる。
2. 「大きい」なら右へ、「小さい」なら左へ、○目盛り進む。
3. 着いた点の数を読む。

**確かめる**：答えから、問題の言い方どおりに進んで、元の数にもどるか。

### 例題3-応用　〔参考：教科書p21〜22・ワークp5 A4・B3〕
（1）絶対値が3より小さい整数を、すべて答えなさい。
<details><summary>ヒント1</summary>0からのきょりが3より小さい整数を、右と左でさがそう。</details>
<details><summary>ヒント2</summary>3 と −3 は、きょりがちょうど3。入る？</details>
<details><summary>答えと解説</summary>−2、−1、0、1、2（5個）。3 と −3 は「3より小さい」に入らない。0 を落とさないように。</details>

（2）−2より−4大きい数を答えなさい。
<details><summary>ヒント1</summary>「−4大きい」を言いかえると？</details>
<details><summary>答えと解説</summary>−6。「−4大きい」は「4小さい」。−2から左へ4目盛り進む。</details>

（3）□より4大きい数は1です。□にあてはまる数を答えなさい。
<details><summary>ヒント1</summary>□から右へ4進むと1。逆に、1から左へ4もどると？</details>
<details><summary>答えと解説</summary>−3。確かめ：−3から右へ4進むと1になる。</details>

### やってみよう 8　〔参考：教科書p21・ワークp5 A4〕
−6より2大きい数を答えなさい。
<details><summary>答えと解説</summary>−4。−6から右へ2目盛り。</details>

### やってみよう 9　〔参考：教科書p22・ワークp5 A4〕
4より−6小さい数を答えなさい。
<details><summary>ヒント1</summary>「−6小さい」を言いかえると？</details>
<details><summary>答えと解説</summary>10。「−6小さい」は「6大きい」。4から右へ6目盛り。</details>

## M1-P008｜自力で確かめる・振り返る

［図 M1-C1-S1-FIG06：確認問題4の数直線］
- `確認問題.md` の12問に取り組む。答えは、全部入力してから表示する。
- 最後のまとめ：

| ことば | 意味 |
|---|---|
| 正の数・負の数 | 0より大きい数・0より小さい数。0はどちらでもない |
| 符号 | 正の符号「+」、負の符号「−」 |
| 自然数 | 正の整数 1、2、3、……。0は入らない |
| 絶対値 | 数直線で、0からのきょり |
| 不等号 | 「<」「>」。3つ以上は向きをそろえる |

**次につながる**：2節では、正の数・負の数のたし算を、数直線の「右へ・左へ」で考える。P007b の考え方がそのまま使える。
