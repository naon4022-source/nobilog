# M1-C1-S1　確認問題（12問・入力式）

- 試作の12問と同じ問題。ヒントを足した。
- 答えと採点基準は `解答と採点基準.md`。アプリでは、入力して「答え合わせ」を押すまで答えを出さない。
- 難しさ：基本4・標準5・応用3。2節の計算（正負の数のたし算・ひき算）は使わない。

**1**（基本）0℃より7℃低い温度を、「−」を使って表しなさい。　〔参考：教科書p14・ワークp2 A1〕
<details><summary>ヒント</summary>0℃より低い温度は、どんな符号？</details>

**2**（基本）0より 2/9 小さい数を、符号をつけて表しなさい。　〔参考：教科書p15・ワークp2 A2〕
<details><summary>ヒント</summary>「0より小さい」→ 負の符号。</details>

**3**（標準）次の数について答えなさい。　−6、2.5、0、+8、−1/2、13　〔参考：教科書p15・ワークp3 B1〕
（1）整数をすべて選びなさい。（2）自然数をすべて選びなさい。
<details><summary>ヒント1</summary>小数・分数で整数にならないものを、先に外そう。</details>
<details><summary>ヒント2</summary>0 は整数？ 自然数？</details>

**4**（標準）［図 M1-C1-S1-FIG06］の数直線で、点Aと点Bが表す数を答えなさい。　〔参考：教科書p16・ワークp2 A3〕
<details><summary>ヒント1</summary>0 と 1 のあいだは、いくつに区切られている？</details>
<details><summary>ヒント2</summary>1目盛りは 0.5。0から何目盛り、どちら向き？</details>

**5**（基本）午前9時を基準にして、午前11時を「+2時間」と表します。このとき、午前6時はどう表せますか。　〔参考：教科書p17・ワークp3 A5〕
<details><summary>ヒント</summary>午前6時は、基準の9時より前？ 後？ 何時間？</details>

**6**（標準）1日に歩く目標を8000歩とし、目標とのちがいを正の数・負の数で表します。7400歩歩いた日は、どう表せますか。　〔参考：教科書p18・ワークp3 B2〕
<details><summary>ヒント</summary>目標より多い？ 少ない？ どれだけ？</details>

**7**（標準）「40cm低い」ことを、「高い」ということばを使って表しなさい。　〔参考：教科書p18・ワークp3 A5〕
<details><summary>ヒント</summary>ことばを反対にしたら、符号は？</details>

**8**（基本）−4.2 の絶対値を答えなさい。　〔参考：教科書p19・ワークp4 A1〕
<details><summary>ヒント</summary>0からのきょり。</details>

**9**（応用）絶対値が2.5より小さい整数を、すべて答えなさい。　〔参考：教科書p22・ワークp5 B1〕
<details><summary>ヒント1</summary>右がわ（正）と左がわ（負）の両方をさがそう。</details>
<details><summary>ヒント2</summary>0 の絶対値はいくつ？ 3 は 2.5 より小さい？</details>

**10**（応用）−5/6 と −4/5 の大小を、不等号を使って表しなさい。　〔参考：教科書p20・ワークp5 B1〕
<details><summary>ヒント1</summary>まず絶対値 5/6 と 4/5 をくらべよう。分母をそろえるとくらべやすい。</details>
<details><summary>ヒント2</summary>負の数は、絶対値が大きいほど小さい。</details>

**11**（応用）次の数を、小さい順にならべなさい。　0.7、−1.6、−3/10、−2、0　〔参考：教科書p20・22・ワークp5 B2〕
<details><summary>ヒント1</summary>正の数・0・負の数に分けよう。</details>
<details><summary>ヒント2</summary>−3/10 を小数にすると？</details>

**12**（標準）2より−5大きい数を答えなさい。　〔参考：教科書p21〜22・ワークp5 A4〕
