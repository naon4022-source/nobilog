# M1-C1-S1　ポイントとかんたんにやる方法
## この節のポイント
- 0より大きい数を **正の数**（＋）、0より小さい数を **負の数**（−）という。0は正の数でも負の数でもない。
- 反対の向きや性質をもつ量は、基準を0にして ＋ と − で表せる（「3m 高い」⇔「−3m 低い」）。
- **絶対値** は、数直線で0からどれだけはなれているか。符号をとった数。
- 数直線では **右にある数ほど大きい**。負の数は、絶対値が大きいほど小さい。
## かんたんにやる方法
1. 大小で迷ったら、頭の中に数直線をかく。右にあるほうが大きい。
2. 負の数どうしは「借金」で考える。借金5円より借金2円のほうがまし → −5＜−2。
3. 3つ以上の数は、まず「正・0・負」の3グループに分けてから、グループの中で並べる。
4. 絶対値は「− をはずすだけ」。−7 の絶対値は 7。
5. 反対のことばに言いかえると、符号が変わる：「−2 kg 増える」＝「2 kg 減る」。
## よくあるミス
- −5 と −2 で、「5 のほうが大きいから −5＞−2」としてしまう。
- 0 を正の数や自然数に入れてしまう（自然数は 1、2、3、…）。
