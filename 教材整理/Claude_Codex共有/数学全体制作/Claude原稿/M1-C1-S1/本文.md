## M1-P003｜身近な導入・既習事項・今回のつながり

［絵 M1-C1-S1-INTRO（未生成。制作指示は画像選定.md）：山の上と海の中。海面が「0」の場面］

### 海面より上と、海面より下
- 山の高さは「海面から何mか」で表す。では、海の中の深い所はどう表す？
- 海面を **0** と決めると、上と下を **同じものさし** で言える。
- 0より上は「+」、0より下は「−」を使う。温度も同じで、0℃より下を「−」で表す。

### 小学校で学んだこと（使うもの）
- 数直線：0 から右へ、1、2、3、……と数がならぶ。
- 小数・分数も数直線の上に置ける。
- 大きさくらべ：数直線で右にあるほど大きい。

### この節でできるようになること
1. 0より小さい数を書き、読み、なかま分けできる。
2. 数直線で、0より左の数を読んだり置いたりできる。
3. 反対の意味の量を、+と−で表せる。
4. 絶対値を使って、数の大小をくらべられる。

## M1-P004｜正負の符号・数の分類・整数と自然数／しくみ　（教科書 p14〜15・ワーク p2〜3）

［図 M1-C1-S1-FIG01：正の数と負の数の数直線］

### 「−」は「0より小さい」のしるし
- 0℃より4℃低い温度は **−4℃** と書いて、「**マイナス**4度」と読む。
- 0より小さい数は、数の前に「−」をつける。0より6小さい数は −6、0より1/3小さい数は −1/3。

### なぜ「−」を使うと便利なの？
「0より6低い」とことばで書くと、ほかの数とならべてくらべにくい。「−6」と1つの数にすると、数直線に置けるし、計算もできるようになる（2節）。

### 正の数・負の数・0
| なかま | 意味 | 例 |
|---|---|---|
| 正の数 | 0より大きい数 | 4、0.5、1/3、+2 |
| 負の数 | 0より小さい数 | −4、−0.5、−1/3 |
| 0 | どちらでもない（さかい目） | 0 |

- 正の数には「+」をつけることもある。4 と +4 は同じ数。+4 は「**プラス**4」と読む。
- 「+」を **正の符号**、「−」を **負の符号** という。

### 整数と自然数
- これからは、……、−3、−2、−1、0、1、2、3、…… をすべて **整数** という。
- そのうち 1、2、3、…… を **自然数**（正の整数）という。

図で見ると（FIG01）、0 の右に正の数、左に負の数。整数は目盛りの上の数、自然数はそのうち 0 より右の目盛りの数。

## M1-P005｜正負の符号・数の分類・整数と自然数／解き方

### どこを見る
1. **符号**：「−」がついているか。ついていれば負の数。
2. **値が整数になるか**：2.5 や −1/2 は整数ではない。+6/3 は 2 と同じなので整数。
3. **0 かどうか**：0 は整数には入る。正の数・負の数・自然数には入らない。

## M1-P006｜正負の符号・数の分類・整数と自然数／例題　〔参考：教科書p14〜15・ワークp2〜3〕

### 例題1-基本　0℃より9℃低い温度を、「−」を使って表しなさい。
1. 「0℃より低い」→ 負の数。
2. 0℃から9℃はなれている → 9。
3. 答え：**−9℃**。
**確かめる**：数直線で 0 より左にあるか → ある。

### 例題1-標準　次の数の中から、（1）負の数、（2）整数、（3）自然数を、すべて選びなさい。
　−7、0.4、0、+3、−2/5、15、−1、1.2
1. 正・0・負に分ける：負は −7、−2/5、−1。0 は 0。残りは正。
2. 整数か調べる：−7、0、+3、15、−1 が整数。0.4、−2/5、1.2 は整数でない。
3. 答え：（1）**−7、−2/5、−1**　（2）**−7、0、+3、15、−1**　（3）**+3、15**
**確かめる**：0 は（2）だけに入っているか → 入っている。

### 例題1-応用　「0 より大きく、整数ではない負の数」はありますか。理由も答えなさい。
1. 「0 より大きい」数は、正の数。
2. 正の数は、負の数ではない。
3. 答え：**ない**。0 より大きい数は正の数なので、負の数になることはない。
（「条件が同時に成り立つか」を考える問題。条件を1つずつ確かめる。）

## M1-P008｜数直線と目盛りの読み方／しくみ　（教科書 p16・ワーク p2）

［図 M1-C1-S1-FIG02：1目盛り0.2の数直線と点P・Q］

### なぜ数直線を使うの？
数を「位置」で見られるから。
- 0 より右は正の数、0 より左は負の数。
- **右にあるほど大きい**。
- 0 から同じ遠さで右と左にある数（3 と −3 など）は、0 をはさんで向かい合う。

### 目盛りは「1」とはかぎらない
- 0 と 1 のあいだを5つに区切ると、1目盛りは 1÷5＝0.2。
- 点 P は 0 から左へ3目盛り → 0.2×3＝0.6 だけ小さい → −0.6。
- 点 Q は 0 から右へ2目盛り → +0.4。

## M1-P009｜数直線と目盛りの読み方／解き方

### 解く順番（目盛りを読む）
1. **1目盛りの大きさ** を出す：となりの2つの数のあいだが何等分されているかを数え、そのはばを等分の数でわる。
2. **0 からの目盛りの数** と **向き**（右・左）を数える。
3. 「1目盛り × 目盛りの数」で 0 からのはなれ方を出す。
4. 右なら「+」、左なら「−」をつける。

### 解く順番（数を置く）
1. 数が 0 より右か左かを決める。
2. 0 からのはなれ方 ÷ 1目盛り で、何目盛りか出す。
3. 割り切れないとき（例：1目盛り0.5 で 1.2）は、目盛りと目盛りのあいだに置く。

**確かめる**：置いた点を、もう一度「読む」手順で読み直して、元の数になるか。

## M1-P012｜反対の量・基準・言葉の言い換え／しくみ　（教科書 p17〜18・ワーク p3）

［図 M1-C1-S1-FIG03（追加提案）：目標20ページとのちがい］

### なぜ正の数・負の数で量を表せるの？
「東・西」「高い・低い」「多い・少ない」のように、反対の意味の組がある。
- 片方を「+」と決めると、もう片方は「−」で表せる。
- **はじめに、どちらを「+」にするかを決めておく**。決めないと、数だけでは意味が伝わらない。

### 基準とのちがい
- 目標などの数を **基準** にして、それを 0 とみる。
- 基準より多ければ「+」、少なければ「−」、同じなら「0」。
- 図（FIG03）では、上の棒が「多い」、下の斜線の棒が「少ない」を表す。

### 1つのことばで言いかえる
- 「7本少ない」は「−7本多い」と言える。
- ことばを反対にしたら、符号も反対にする。2つの反対が組になって、同じ意味にもどる。

## M1-P013｜反対の量・基準・言葉の言い換え／解き方

### 解く順番（反対の量）
1. どちらのことばを「+」にしたかを確かめる。
2. 問われたことばが同じなら「+」、反対なら「−」。
3. 数の大きさはそのまま。

### 解く順番（基準とのちがい）
1. 基準の数を書く。
2. 「実際の数 − 基準」を計算する（大きいほうから小さいほうをひいて、多いか少ないかで符号を決めてもよい）。
3. 多いなら「+」、少ないなら「−」、同じなら「0」。

### 解く順番（言いかえ）
1. ことばを反対にする（少ない→多い）。
2. 符号を反対にする（+→−）。
3. **確かめる**：言いかえた文を、もう一度元のことばにもどして、同じ意味になるか。

## M1-P014｜反対の量・基準・言葉の言い換え／例題　〔参考：教科書p17〜18・ワークp3 A5・B2〕

### 例題3-基本　東へ300m進むことを +300m と表すとき、西へ200m進むことはどう表せますか。
1. 「+」は東。西は反対。2. 答え：**−200m**。

## M1-P016｜符号を変えた数と絶対値／しくみ　（教科書 p19・ワーク p4）

［図 M1-C1-S1-FIG04（追加提案）：−3 と 3 はどちらも0からきょり3］

### 符号を変えた数
- +5 の符号を変えると −5。数直線では、0 をはさんで反対がわの、同じ遠さの点。

### 絶対値
- 数直線で、0 からその数までの **きょり** を **絶対値** という。
- −3 も 3 も、0 から3目盛り → 絶対値はどちらも 3。0 の絶対値は 0。
- **なぜ「−」がつかない？** きょり（長さ）はマイナスにならないから。
- 正の数・負の数から符号をとった数が、絶対値になる。

## M1-P017｜符号を変えた数と絶対値／解き方

### 解く順番（絶対値を答える）
1. 符号をとる。2. 残った数が絶対値。

### 解く順番（絶対値が○の数をさがす）
1. 0 から右へ○の点と、左へ○の点を考える。
2. 答えは2つ（○ と −○）。ただし ○ が 0 なら、0 の1つだけ。

### 解く順番（絶対値が○より小さい／○以下の整数）
1. 右がわ：0 から ○ のほうへ、整数を順にならべる。
2. 左がわも同じようにならべる。
3. 0 を入れる。
4. 「より小さい」はちょうど ○ をふくまない。「以下」はふくむ。

## M1-P020｜数の大小・不等号／しくみ　（教科書 p20・ワーク p4〜5）

### 数の大小
数直線では **右にあるほど大きい**。ここから、
1. 正の数は、負の数より大きい。
2. 正の数は、絶対値が大きいほど大きい。
3. 負の数は、**絶対値が大きいほど小さい**（0 から左へ遠いほど小さい）。

**別の見方**：気温で考えると、−8℃ は −2℃ より寒い。だから −8 は −2 より小さい。

### 不等号
- 「<」「>」の口が開いているほうが大きい。例：−6 < −1。
- 3つ以上の数は、向きをそろえて1本の式にする（−5 < −2 < 4）。

---

## M1-P021｜数の大小・不等号／解き方

### 解く順番（大小をくらべる）
1. 正の数・0・負の数に分ける。
2. 負の数どうしは、絶対値の大きいほうが小さい。
3. 分数と小数がまじるときは、どちらかにそろえる（分母をそろえる・小数にする）。
4. 小さい順にならべて、不等号の向きをそろえて書く。

**確かめる**：答えの数を数直線に置いたとき、左から順にならんでいるか。

## M1-P022｜数の大小・不等号／例題　〔参考：教科書p20・ワークp4〜5〕

### 例題5-基本　−3.5 と −2 の大小を、不等号で表しなさい。
1. どちらも負の数。2. 絶対値は 3.5 と 2 → 3.5 が大きい。3. 答え：**−3.5 < −2**。

### 例題5-標準　−1、−4/3、0.5 の大小を、1つの式で表しなさい。
1. 0.5 は正の数でいちばん大きい。
2. 負の数どうし：4/3 は 1 より大きい → −4/3 は −1 より小さい。
3. 答え：**−4/3 < −1 < 0.5**。

### 例題5-応用　−5/6 と −0.8 の大小を、不等号で表しなさい。
1. どちらも負の数。絶対値をくらべる。
2. 5/6 を小数にすると 0.833…。0.8 より大きい。
3. 絶対値が大きい −5/6 のほうが小さい。答え：**−5/6 < −0.8**。
**確かめる**：分数にそろえても、5/6＝25/30、0.8＝24/30 で同じ結果。

## 追加提案 M1-P023a｜数直線での移動／しくみ　（教科書 p21〜22・ワーク p5）

［図 M1-C1-S1-FIG05（追加提案）：1から右へ3、1から左へ3］

### 「〜より○大きい数」は、数直線の移動
- 「1より3大きい数」は、1 から右へ3 → 4。
- 「1より3小さい数」は、1 から左へ3 → −2。
- 「1より−3大きい数」は、「3大きい」の反対の向き → 左へ3 → −2。つまり「1より3小さい数」と同じ。
- 「−○大きい」は「○小さい」、「−○小さい」は「○大きい」。

### なぜこれが大事？
この「右へ・左へ」は、2節のたし算・ひき算そのものになる（1＋3＝4、1＋(−3)＝−2）。
