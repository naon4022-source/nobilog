## M1-P161｜解法のつながり・理由を解説しながら振り返る（1）方程式の地図と、解き方を選ぶ順番

### 3章の地図
| 1節 方程式 | → | 2節 方程式の利用 |
|---|---|---|
| 解とは何か → 等式の性質 → 移項 → かっこ・分数・小数をふくむ方程式 → 比例式 | | 求めたいものを x にする → 等しい関係を見つけて式にする → 解いて、答えが場面に合うか確かめる |

1節で身につけたのは「**どんな方程式も x＝○ の形まで運べる力**」。2節で身につけたのは「**文章の中から等しい関係を見つけて、方程式にする力**」。この2つがそろうと、わからない数を自分で求められる。

### なぜ解けるのか：全部「てんびんを水平に保つ操作」
- 両辺に同じ数をたす・ひく・かける・同じ数（0以外）でわる → てんびんはつりあったまま。
- 移項は「両辺に同じ数をたす（ひく）」を短く書いたもの。だから符号が変わる。
- 分数の係数を消すときに両辺に分母の最小公倍数をかけるのも、同じ「両辺に同じ数をかける」。

### 解き方を選ぶ順番（迷ったらこの順）
1. **分数がある** → 両辺に分母の最小公倍数をかける（**すべての項**にかける）。
2. **小数がある** → 両辺を10倍・100倍して整数にする（**すべての項**に）。
3. **かっこがある** → 分配法則でかっこを外す（−( ) は中の符号を全部変える）。
4. **移項**して、x の項を左、数の項を右に集める。
5. ax＝b の形にして、両辺を a でわる。
6. **確かめる**：もとの式に解を入れて、左辺と右辺が同じ値になるか。

> 1〜3は「式をすっきりさせる」、4〜5は「x を1つにする」、6は「自分の答えを自分で保証する」。6を飛ばさない人は、テストで失点が減る。

## M1-P162｜解法のつながり・理由を解説しながら振り返る（2）思い出す・答えの意味を考える・別の方法で確かめる

### 思い出しカード（答えを見る前に、自分で言ってみよう）
1. 「x＝−3 が方程式の解である」とは、どういうことか。
<details><summary>答え</summary>x に −3 を入れると、左辺と右辺が同じ値になること。</details>

2. 3x＝x+8 で、右辺の x を左辺に移すと、どうなるか。それはなぜか。
<details><summary>答え</summary>3x−x＝8。両辺から x をひいたのと同じだから、移した項の符号が変わる。</details>

3. (x−1)/2＝x/3 を解くとき、両辺に何をかける？　かけ忘れやすいのはどこ？
<details><summary>答え</summary>6（2と3の最小公倍数）。分数でない項があるときは、その項にもかけるのを忘れやすい。分子にかっこをつけて 3(x−1)＝2x とする。</details>

4. a：b＝c：d のとき、成り立つ式は？
<details><summary>答え</summary>ad＝bc（外側どうしの積＝内側どうしの積）。</details>

### 答えの意味を考える（解の吟味）
方程式の解は「式の上で正しい数」。でも、**場面に合っているとは限らない**。最後に必ず「この答えは場面に合うか」を確かめる。

**例1**　父は42歳、子は10歳です。
- 父の年齢が子の年齢の3倍になるのは何年後？ → x 年後とすると 42+x＝3(10+x)、2x＝12、x＝6。6年後（父48歳、子16歳。48＝3×16）。
- では、5倍になるのは何年後？ → 42+x＝5(10+x)、−4x＝8、**x＝−2**。
  - 「−2年後」は「2年前」のこと。2年前は父40歳、子8歳で、40＝5×8。**答えは「2年前」**。
  - 負の数を学んだから、マイナスの答えにも意味を読み取れる。

**例2**　生徒に鉛筆を配ります。4本ずつだと3本余り、6本ずつだと6本足りないとき、x＝4.5（人）になったら？
- 人数は整数なので、**この条件に合う人数はない**。問題の数字を読みまちがえていないか、式をもう一度確かめる。
- 「答えが出た＝終わり」ではなく、「答えが場面に合う＝終わり」。

### 別の方法で確かめる（文字の置き方を変える）
**例3**　家から図書館まで、行きは分速60m、帰りは分速90mで同じ道を歩くと、行きは帰りより10分多くかかりました。家から図書館までの道のりは？

［図 M1-C3-REVIEW-FIG01：行きは分速60m で (t＋10) 分、帰りは分速90m で t 分。家と図書館の間の同じ道のりを、2本の矢印で表した図］

- **方法1（道のりを x m とする）**：時間＝道のり÷速さ。x/60−x/90＝10。両辺に180をかけて 3x−2x＝1800、x＝1800。
- **方法2（帰りの時間を t 分とする）**：行きは (t+10) 分。道のりが同じなので 60(t+10)＝90t、30t＝600、t＝20。道のり＝90×20＝1800。
- 2つの方法で同じ 1800m になった → 答えが正しい見込みが高い。
- 何を x にするかで式の形は変わるが、**等しい関係（行きと帰りの道のりは同じ／時間の差は10分）は変わらない**。
