## M1-P091｜文字式の加法、減法①（項と係数・同じ文字の項をまとめる）／しくみ　（教科書 p70〜72・ワーク p38〜39）

［図 M1-C2-S2-FIG01：x 個入りの袋と、ばらのあめで表した 4x+2 と 3x+5］

### 項と係数
- 式 5x−3 は、5x と −3 の和とみる。このときの 5x、−3 を **項** という。
- 文字をふくむ項 5x の、数の部分 5 を **x の係数** という。
- x は 1×x なので係数は 1。−y は (−1)×y なので係数は −1。a/3 は (1/3)a なので係数は 1/3。
- 文字が1つだけの項（5x、−4y）を **1次の項**、1次の項だけ、または1次の項と数の項の和でできた式を **1次式** という。

### なぜ同じ文字の項はまとめられるの？（FIG01）
- 4x は「x 個入りの袋が4つ」、3x は「袋が3つ」。合わせると袋7つ → 7x。
- 5x−3x は、袋5つから3つを取って2つ → 2x。
- 式で書くと **mx＋nx＝(m＋n)x**（分配法則を逆に使っている）。
- 一方、4x と 2（ばらのあめ）は、ものがちがうのでまとめられない。

## M1-P092｜文字式の加法、減法①／解き方

### どこを見る
- **文字の部分がまったく同じか**：3x と 5x は同じ。3x と 3y、x と x² はちがう。
- 項の符号は、項といっしょに動かす（−4x は「−4x」のまま）。

### 解く順番
1. 項に分けて、文字の部分が同じ項に印をつける（下線など）。
2. 文字の項どうし、数の項どうしを集める（交換法則）。
3. 係数どうしを計算する（1章の計算）。
4. 文字の項 → 数の項 の順に書く。

**確かめる**：x に何か数（たとえば 2）を入れて、計算の前と後で値が同じか。

## M1-P095｜文字式の加法、減法②（かっこを外す・式の加減）／しくみ　（教科書 p72〜74・ワーク p40〜41）

［図 M1-C2-S2-FIG02：a から b と c を順にひく動きと、(b+c) をまとめてひく動きが同じになる数直線］

### かっこの外し方
- **+( ) はそのまま外す**：a+(b+c)＝a+b+c。
- **−( ) は、中の各項の符号を変えて外す**：a−(b+c)＝a−b−c、a−(b−c)＝a−b+c。

### なぜ −( ) は符号が全部変わるの？（FIG02）
- 「a から、b と c をまとめてひく」のと「a から b をひいて、さらに c をひく」のは、同じ所に着く。
- だから a−(b+c)＝a−b−c。かっこの中に「−c」があれば、それをひくことは「+c」になる（1章：負の数をひくと、たし算）。

### 式と式の加減
- 2つの式をたす・ひくときは、**それぞれの式にかっこをつけて** から計算する。
- (3x−8)−(−5x+2) のように、ひく式全体にかっこをつけるのが大切。

## M1-P096｜文字式の加法、減法②／解き方

### 解く順番
1. 式どうしの加減なら、それぞれにかっこをつけ、+ か − でつなぐ。
2. かっこの前の符号を見る：+ ならそのまま外す、− なら中の **すべての項** の符号を変えて外す。
3. 同じ文字の項・数の項をまとめる（P092）。

### どこを見る
- −( ) の中の **2つめ以降の項** の符号を変え忘れやすい。
- かっこを外した直後の式を1行書いてから、まとめる。

**確かめる**：x＝1 など簡単な数を入れて、計算の前と後の値をくらべる。

## M1-P099｜文字式と数の乗法、除法①／しくみ　（教科書 p75〜76・ワーク p42〜43）

［図 M1-C2-S2-FIG03：5(2x+3) を、たて5・横が 2x と 3 に分かれた長方形の面積で示す図］

### 文字式×数、文字式÷数
- −4a×6 は、(−4)×6×a（交換法則）→ −24a。
- 15y÷(−5) は、15y/(−5)＝−3y。
- 4x÷(2/3) は、逆数をかける：4x×(3/2)＝6x。

### 項が2つの式に数をかける（分配法則）
- 5(2x+3)＝5×2x+5×3＝10x+15。
- **なぜ？**（FIG03）：たて5、横 2x+3 の長方形は、横 2x の部分と横3の部分に分けられる。面積は 5×2x と 5×3 の和。

### 項が2つの式を数でわる
- (12a−20)÷4＝12a/4−20/4＝3a−5（**各項を** 4 でわる）。
- 分数でわるときは、逆数をかける：(9x−6)÷(−3/2)＝(9x−6)×(−2/3)。

## M1-P100｜文字式と数の乗法、除法①／解き方

### 解く順番
1. わり算は、かけ算（逆数をかける）か、分数の形に直す。
2. かっこの外の数を、中の **各項** にかける（符号ごと）。
3. 係数を計算する。約分を忘れない。

### どこを見る
- かける数が負なら、すべての項の符号が変わる。
- (ax+b)÷c では、b も c でわる（ax だけをわらない）。

**確かめる**：x＝2 などを入れて、計算の前と後の値をくらべる。

## M1-P103｜文字式と数の乗法、除法②（分数の形の式・かっこのある式）／しくみ　（教科書 p76〜77・ワーク p44〜45）

### 分数の形の式に数をかける
- (3x−1)/4×8：分母 4 と 8 で約分して、(3x−1)×2＝6x−2。
- **なぜ約分してよい？**：(3x−1)/4×8 は (3x−1)×8/4。8/4＝2 だから。

### かっこがある式の計算
- 2(3a+4)−5(a−1) は、それぞれ分配法則で外してから、同じ文字の項をまとめる。
- 2(3a+4)＝6a+8、−5(a−1)＝−5a+5。合わせて a+13。

## M1-P104｜文字式と数の乗法、除法②／解き方

### 解く順番（分数の形×数）
1. かける数と分母で約分する。
2. 残った数を、分子の **かっこ全体** にかける（分子にかっこをつける）。

### 解く順番（かっこがある式）
1. 1つめのかっこを分配法則で外す。
2. 2つめのかっこは、前の符号（−5 なら −5 ごと）をかける。
3. 同じ文字の項・数の項をまとめる。

**確かめる**：a＝1 など簡単な数で、計算の前と後をくらべる。

## M1-P107｜関係を表す式（等式・不等式）／しくみ　（教科書 p78〜81・ワーク p48〜49）

### 等式
- 等号「＝」で、2つの数量が **等しい** ことを表した式を **等式** という。
- 左がわを **左辺**、右がわを **右辺**、両方を **両辺** という。
- A＝B と B＝A は同じ関係。

### 不等式
- 不等号で、2つの数量の **大小** を表した式を **不等式** という。
- 「a は b より大きい」a>b、「a は b より小さい（未満）」a<b。
- 「a は b 以上」a≧b（a>b または a＝b）、「a は b 以下」a≦b。

### なぜ式で表すの？
ことばの関係を式にすると、短く正確に書ける。あとで方程式（3章）として解くことにもつながる。

---

## M1-P108｜関係を表す式／解き方

### 解く順番（関係を式に表す）
1. **等しい（または大小をくらべる）2つの数量** を見つける。
2. それぞれを文字式で表す。
3. 等号か不等号でつなぐ。

### どの記号を使うか
| ことば | 記号 |
|---|---|
| 等しい、〜になる | ＝ |
| より大きい、をこえる | > |
| より小さい、未満 | < |
| 以上 | ≧ |
| 以下 | ≦ |

### 式の意味を読む順番
1. 各文字・各項が何を表すか、ことばにする。
2. 記号（＝、>、≦ など）をことばにする。

**確かめる**：文字に具体的な数を入れて、ことばの関係どおりになるか。

## M1-P109｜関係を表す式／例題　〔参考：教科書p78〜81・ワークp48〜49 ポイント2-22〜2-24〕

### 例題5-基本　1本 x 円の鉛筆6本の代金は y 円です。この関係を等式に表しなさい。
1. 等しい2つの数量：代金 6x と y。2. **6x＝y**。

### 例題5-標準（1）長さ a cm のテープから、b cm ずつ7本切り取ると、残りは c cm です。
1. 残り＝a−7b。これが c。2. **a−7b＝c**。

### 例題5-標準（2）x 円のノート3冊と、y 円のペン1本の代金は、1000円以下です。
1. 代金 3x+y。2. 「以下」→ ≦。3. **3x+y≦1000**。

### 例題5-応用　大人1人 a 円、子ども1人 b 円の入場料について、a−2b≧500 はどんなことを表していますか。
1. 2b は子ども2人分。a−2b は「大人1人分 − 子ども2人分」。
2. ≧500 は「500円以上」。
3. 答え：**大人1人の料金は、子ども2人の料金より500円以上高い。**

### 2つの式が同じになる理由
正方形のタイルを、長いテープで囲むように横にならべる。タイルの数を n として、まわりのテープの長さ（1辺 1m）を、2人が別々に式にした。
- Aさん：上と下に n m ずつ、左右に 1m ずつ → n+n+1+1
- Bさん：2(n+1)
- 計算すると、どちらも **2n+2**。式がちがっても、同じ数量を表している。

### 根拠を言えるようにしよう
n＝5 のとき、2つの式の値を求めて、同じになることを確かめよう。
<details><summary>答えと解説</summary>どちらも 12。5+5+1+1＝12、2×(5+1)＝12。</details>

### まとめ
- 同じ文字の項は、係数どうしを計算してまとめる。文字の項と数の項はまとめない。

- 数をかける・わるときは、各項にかける・わる。わり算は逆数をかけてもよい。
- 等式・不等式：等しい2つの数量、大小をくらべる2つの数量を見つけて、記号でつなぐ。
