# M1-C2-S2　確認問題（14問・入力式）
答えは `解答と採点基準.md`。難しさ：基本4・標準6・応用4。

**1**（基本）9a−5a　〔参考：教科書p71・ワークp38 A2〕
<details><summary>ヒント</summary>係数どうしを計算。</details>

**2**（基本）−2x+7−6x+1　〔参考：教科書p72・ワークp39 A3〕
<details><summary>ヒント</summary>x の項どうし、数の項どうし。</details>

**3**（標準）(1/2)a−(3/4)a　〔参考：教科書p71・ワークp39 B1〕
<details><summary>ヒント</summary>係数を通分。</details>

**4**（基本）4x+(6−x)　〔参考：教科書p73・ワークp40 A1〕
<details><summary>ヒント</summary>+( ) はそのまま外す。</details>

**5**（標準）8y−(3y−5)　〔参考：教科書p73・ワークp40 A1〕
<details><summary>ヒント</summary>−( ) は中の符号をすべて変える。</details>

**6**（標準）7x−2 から −3x+4 をひいた差　〔参考：教科書p74・ワークp41 A3〕
<details><summary>ヒント</summary>(7x−2)−(−3x+4)。</details>

**7**（基本）6a×(−7)　〔参考：教科書p75・ワークp42 A1〕
<details><summary>ヒント</summary>数どうしをかける。</details>

**8**（標準）−4(2y−5)　〔参考：教科書p76・ワークp43 A2〕
<details><summary>ヒント</summary>−4 を各項にかける。</details>

**9**（標準）(18x−27)÷9　〔参考：教科書p76・ワークp43 A3〕
<details><summary>ヒント</summary>各項を9でわる。</details>

**10**（応用）(2x+3)/5×(−10)　〔参考：教科書p76・ワークp44 A1〕
<details><summary>ヒント</summary>−10 と 5 で約分。</details>

**11**（応用）4(2a−1)−3(a+2)　〔参考：教科書p77・ワークp44 A2〕
<details><summary>ヒント1</summary>それぞれのかっこを外してから。</details>
<details><summary>ヒント2</summary>−3×2＝−6。</details>

**12**（標準）1個 a g のボール5個を、b g の箱に入れたら、全体の重さは 800g でした。この関係を等式で表しなさい。　〔参考：教科書p78・ワークp48 A1〕
<details><summary>ヒント</summary>全体の重さ＝ボールの重さ＋箱の重さ。</details>

**13**（応用）x 本のペンを1人に3本ずつ y 人に配ったところ、まだ何本か余りました。この関係を不等式で表しなさい。　〔参考：教科書p79・ワークp49 B2〕
<details><summary>ヒント1</summary>配った本数は 3y。</details>
<details><summary>ヒント2</summary>余った → はじめの本数のほうが多い。ちょうど同じではない。</details>

**14**（応用）1冊 a 円のノートと、1本 b 円のペンがあります。2a+3b<1000 はどんなことを表していますか。　〔参考：教科書p80・ワークp49 B1〕
<details><summary>ヒント</summary>2a と 3b は、それぞれ何の代金？ < は？</details>
