# M1-C2-S2　ポイントとかんたんにやる方法
## この節のポイント
- 3x−5 の **項** は 3x と −5。3x の **係数** は 3。
- 文字の部分が同じ項は、係数どうしを計算してまとめられる：2x+5x＝7x。
- −( ) を外すときは、中の **すべての項の符号** を変える。
- 数×(式) は分配法則：3(x+2)＝3x+6。(式)÷数 は、各項を わる（または逆数をかける）。
- 数量の関係は、等式（＝）や不等式（＜、＞、≦、≧）で表せる。
## かんたんにやる方法
1. 「文字の項チーム」と「数の項チーム」に分けて、それぞれ集める。下線や丸で印をつけると見落とさない。
2. ひき算の式は、まずかっこを外して全部の符号を変えてから、たし算として計算する。
3. (6x+4)/2 のような分数の形は、分子のそれぞれを分母でわる：3x+2。
4. 不等号は、大きいほうに口を開く。「以上」「以下」は等号つき（≧、≦）、「未満」「より大きい」は等号なし。
## よくあるミス
- 3(x+2) を 3x+2 にする（2にもかける）。
- 2x+3 を 5x にする（文字の項と数の項はまとめられない）。
