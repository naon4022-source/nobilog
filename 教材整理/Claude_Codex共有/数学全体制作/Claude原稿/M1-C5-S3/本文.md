## M1-P229｜身近な導入・既習事項・今回のつながり

［絵 M1-C5-S3-INTRO（未生成）：公園で、じょうろを持った中学生が、池のふちに寄ってから花だんへ向かおうとしている（文字・数字なし）］

### 池で水をくんで、花だんへ
- 公園の水道がこわれていて、花だんに水をやるには、一度 **池のふち** で水をくんでから行くしかない。
- 池のふちのどこに寄れば、歩く道のりが **いちばん短く** なるだろう？
- 「とりあえず近そうな所」ではなく、**作図で1か所に決める** 方法がある。

### 使う、前に学んだこと
- 対称移動：対応する点を結ぶ線分は、軸と垂直に交わり2等分される（2節）
- 2点を結ぶ線のうち、いちばん短いのは線分（1節）
- 垂直二等分線・角の二等分線・垂線の作図（2節）

### この節でできるようになること
1. 対称移動を使って、「ある直線に寄ってから行く」いちばん短い道を作図できる。
2. 「2点から等しい」「2本の線から等しい」などの条件を、どの作図で表すか選べる。
3. 作図の結果が正しい理由を、移動や作図の性質で説明できる。

## M1-P230｜5章5 図形の移動と基本の作図の利用／しくみ　（教科書 p166〜168・ワーク p102〜103）

［図 M1-C5-S3-FIG01：直線 ℓ の同じ側に点 A、B。B を ℓ について対称移動した B′ をとり、線分 AB′ と ℓ の交点 P を示した図。AP＋PB と AP＋PB′ が等しいことを印で示す］

### 「折り返す」と、まっすぐになる
- 点 A から直線 ℓ 上の点 P に寄って、点 B へ行く道のり AP＋PB を考える。A と B は ℓ の同じ側にある。
- B を ℓ について **対称移動** した点を B′ とする。ℓ は BB′ の垂直二等分線なので、ℓ 上のどの点 P でも **PB＝PB′**。
- だから AP＋PB＝AP＋PB′。これがいちばん短くなるのは、A、P、B′ が **一直線上に並ぶ** とき。
- つまり、**線分 AB′ と ℓ の交点** が、いちばん短くなる点 P。

### 条件と作図の対応
| 条件 | 使う作図 |
|---|---|
| 2点 A、B から等しい距離 | 線分 AB の垂直二等分線 |
| 2本の直線（角の2辺）から等しい距離 | 角の二等分線 |
| ある点からある直線へいちばん短く | 垂線 |
| 直線に寄って2点を結ぶいちばん短い道 | 対称移動 → 線分 |

## M1-P231｜5章5 図形の移動と基本の作図の利用／解き方

### いちばん短い道の作図
1. 寄る直線 ℓ について、片方の点（B）を **対称移動** した点 B′ をとる（B から ℓ に垂線をひき、反対側に同じ長さをとる）。
2. もう一方の点 A と B′ を **線分** で結ぶ。
3. 線分 AB′ と ℓ の交点を P とする。A→P→B が、いちばん短い道。

### 条件が2つあるとき
1. 条件を1つずつ「どの作図か」に置きかえる。
2. それぞれの作図をして、**線どうしの交点** をさがす。交点が、両方の条件を満たす点。

**確かめる**：ℓ 上の別の点 Q をとり、AQ＋QB の方が長くなるか（AQ＋QB′ が折れ線になるか）を見る。

## M1-P232｜5章5 図形の移動と基本の作図の利用／例題　〔参考：教科書p166〜168・ワークp102〜103〕

### 例題1-基本　方眼の上で、直線 ℓ を横の線とします。A は ℓ から上へ 2ます、B は ℓ から上へ 4ます で、A から B へは右へ 9ます です。ℓ に寄って A から B へ行くいちばん短い道で、寄る点 P は、A の真下の点から右へ何ます の所ですか。
1. B を ℓ について対称移動すると、B′ は ℓ から **下へ 4ます**。
2. A から B′ へは「右へ 9ます、下へ 6ます」。3ます進むごとに 2ます下がるまっすぐな線。
3. A（ℓ から上へ 2ます）が ℓ に着くのは、2ます下がったとき → 右へ 3ます。
4. 答え **右へ 3ます**。確かめ：(右へ3, 下へ2) をくり返すと、ちょうど B′ に着く。

### 例題1-標準　まっすぐな道 ℓ と、ℓ の上にない2つの家 P、Q があります。P、Q から等しい距離にあり、しかも **道 ℓ 上にある** 地点 R を作図で求めます。手順を答えなさい。
1. P、Q から等しい距離 → 線分 PQ の **垂直二等分線**。
2. 道 ℓ 上 → ℓ との **交点**。
3. 答え **線分 PQ の垂直二等分線を作図し、ℓ との交点を R とする**。

### 例題1-応用　2本のまっすぐな道 OX、OY が点 O で交わっています。2本の道から等しい距離にあり、さらに **2つの家 A、B から等しい距離** にある地点 S を求めます。どの作図とどの作図の交点ですか。
1. 2本の道（角の2辺）から等しい距離 → ∠XOY の **二等分線**。
2. 家 A、B から等しい距離 → 線分 AB の **垂直二等分線**。
3. 答え **∠XOY の二等分線と、線分 AB の垂直二等分線の交点**。

## M1-P233｜5章5 図形の移動と基本の作図の利用／つまずきと確認

### つまずきの比較
| まちがい | 正しい考え方 |
|---|---|
| A と B を直接むすび、ℓ との交点を P とする | A、B が ℓ の同じ側なら交わらない。片方を対称移動してから結ぶ |
| B′ を「ℓ から同じ距離」の適当な場所にとる | B から ℓ に **垂線** をひき、その延長上にとる |
| 「2点から等しい」に角の二等分線を使う | 2点なら垂直二等分線、2本の線なら角の二等分線 |

### 考え方付き確認
**確認5-1**　方眼で、直線 ℓ から上へ 3ます の点 A と、上へ 3ます の点 B があり、A から B へは右へ 8ます です。ℓ に寄って A から B へ行くいちばん短い道で、寄る点は A の真下から右へ何ます ですか。
<details><summary>ヒント1</summary>B′ は ℓ から下へ 3ます。A と B′ の高さの差は 6ます。</details>
<details><summary>答えと解説</summary>右へ 4ます。A と B が ℓ から同じ距離なので、まん中（8÷2＝4）で寄るのがいちばん短い。</details>

**確認5-2**　三角形の形をした公園の3つの入口 A、B、C から等しい距離に、案内板を立てます。案内板の位置を求める作図を答えなさい。
<details><summary>答えと解説</summary>線分 AB と線分 BC（など2本）の垂直二等分線を作図し、その交点に立てる。</details>

## M1-P234｜別の場面へ使う・立式や判断の根拠・検算

［図 M1-C5-S3-FIG02：かべ ℓ でボールをはね返して的に当てる図。的を ℓ について対称移動した点と、ボールを打つ点を結ぶ線分が、はね返る点を通ることを示す］

### かべ当てで、まっすぐ的をねらう
- ボールをかべ ℓ ではね返して、的 T に当てたい。
- T を ℓ について対称移動した点 T′ をねらって、**まっすぐ** 打てばよい。かべに当たる点で折れ曲がった道は、T′ までのまっすぐな線と同じ長さ。
- ビリヤードやミニゴルフでも、同じ考え方が使える。

### 根拠を言えるようにしよう
- 「ℓ は BB′ の垂直二等分線だから、ℓ 上の点 P では PB＝PB′」。
- 「2点を結ぶ線の中で、いちばん短いのは線分」。

### 検算
- 作図した P と、ℓ 上の別の点 Q で、コンパスを使って AP＋PB と AQ＋QB の長さをくらべる。

## M1-P235｜全体のつながり・自分の言葉で整理・解説付き振り返り

### まとめ
- 「直線に寄って行くいちばん短い道」は、**片方の点を対称移動** して、もう一方と線分で結ぶ。
- 条件を作図に置きかえる：2点から等しい→垂直二等分線、2本の線から等しい→角の二等分線、いちばん近い→垂線。
- 条件が2つなら、2つの作図の **交点**。

### 自分のことばで説明しよう
いちばん短い道の作図で、B を対称移動する理由を、「PB＝PB′」ということばを使って説明しよう。

### 振り返りの問題
**振り返り1**　方眼で、直線 ℓ から上へ 1ます の点 A と、上へ 2ます の点 B があり、A から B へは右へ 6ます です。ℓ に寄って行くいちばん短い道で、寄る点は A の真下から右へ何ます ですか。
<details><summary>答え</summary>2ます（B′ は下へ 2ます。A から B′ へ「右へ 6、下へ 3」→ 2ます進むごとに 1ます下がる → 1ます下がって ℓ に着くのは右へ 2ます）。</details>

**振り返り2**　∠XOY の内側で、辺 OX、OY から等しい距離にある点は、どんな線の上にありますか。
<details><summary>答え</summary>∠XOY の二等分線の上。</details>
