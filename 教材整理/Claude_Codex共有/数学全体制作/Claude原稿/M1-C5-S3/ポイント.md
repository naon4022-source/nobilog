# M1-C5-S3　ポイントとかんたんにやる方法
## この節のポイント
- 直線 ℓ に寄って A から B へ行くいちばん短い道：**B を ℓ で対称移動して B′**、線分 AB′ と ℓ の交点 P。
- 理由：ℓ は BB′ の垂直二等分線だから **PB＝PB′**。2点を結ぶいちばん短い線は線分。
- 条件 → 作図：2点から等しい＝垂直二等分線、2本の線から等しい＝角の二等分線、いちばん近い＝垂線。
## かんたんにやる方法
1. 方眼なら、B′ の位置を「ℓ から同じます目だけ反対側」にとって、A とまっすぐ結ぶだけ。
2. A と B が ℓ から同じ距離なら、寄る点はちょうどまん中。
3. 条件が2つなら「作図2本 → 交点」と決めておく。
## よくあるミス
- A と B をそのまま結んでしまう（同じ側なら ℓ と交わらない）。
- 「2点から等しい」に角の二等分線を使う。
