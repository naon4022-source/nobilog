# M1-C1-S2　ポイントとかんたんにやる方法
## この節のポイント
- **加法**：同じ符号 → 絶対値の和に共通の符号。ちがう符号 → 絶対値の差に、絶対値が大きいほうの符号。
- **減法**：ひく数の符号を変えて、加法にする。
- **乗法・除法**：符号は **負の数の個数** で決まる（偶数個 → ＋、奇数個 → −）。絶対値は、かけたり わったりした値。
- わる数の **逆数をかける** と、わり算はかけ算になる。
- 計算の順序：累乗・かっこの中 → 乗法・除法 → 加法・減法。
- 1とその数自身しか約数がない数を **素数** という。自然数は素数の積に分けられる（**素因数分解**）。
## かんたんにやる方法
1. たし算・ひき算がならんだら、＋の数と−の数に分けてまとめる。5−8+3−6 ＝ (5+3)−(8+6) ＝ 8−14 ＝ −6。
2. かけ算・わり算は、**まず符号を決めて**から、数だけ計算する。
3. わり算が入っていたら全部「逆数のかけ算」に直す。最後にまとめて約分できる。
4. 分配法則で計算を楽にする：99×(−7) ＝ (100−1)×(−7) ＝ −700+7 ＝ −693。
5. 素因数分解は、小さい素数（2、3、5、7、…）から順にわっていく。
## よくあるミス
- −3² を 9 にする。−3² は −(3×3)＝−9、(−3)² は 9。
- 減法で、後ろの数の符号を変え忘れる：4−(−6) は 4+6＝10。
