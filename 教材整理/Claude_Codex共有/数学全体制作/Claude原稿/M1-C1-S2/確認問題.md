# M1-C1-S2　確認問題（16問・入力式）

答えと採点基準は `解答と採点基準.md`。入力して答え合わせを押すまで、答えは出さない。
難しさ：基本5・標準8・応用3。

**1**（基本）(−8)+(−17)　〔参考：教科書p26・ワークp6 A1〕
<details><summary>ヒント</summary>同じ符号の和。符号は？ 絶対値は？</details>

**2**（基本）(+12)+(−19)　〔参考：教科書p26・ワークp6 A2〕
<details><summary>ヒント</summary>絶対値の大きいほうの符号になる。</details>

**3**（標準）(−3.4)−(−1.9)　〔参考：教科書p29・ワークp9 B1〕
<details><summary>ヒント</summary>ひく数の符号を変えて、たし算にしよう。</details>

**4**（標準）(−2/5)+(3/10)　〔参考：教科書p27・ワークp7 A3〕
<details><summary>ヒント</summary>分母を10にそろえてから、絶対値をくらべよう。</details>

**5**（標準）9−14+(−6)−(−8)　〔参考：教科書p31・ワークp11 A4〕
<details><summary>ヒント1</summary>まず、かっこのない式（項のならび）に直そう。</details>
<details><summary>ヒント2</summary>正の項の和と、負の項の和を出そう。</details>

**6**（基本）(−9)×(−7)　〔参考：教科書p35・ワークp13 A3〕
<details><summary>ヒント</summary>同じ符号の積は？</details>

**7**（基本）(−65)÷13　〔参考：教科書p36・ワークp14 A1〕
<details><summary>ヒント</summary>ちがう符号の商は？</details>

**8**（基本）−3/7 の逆数を答えなさい。　〔参考：教科書p38・ワークp16 A1〕
<details><summary>ヒント</summary>かけて 1 になる数。符号はそのまま。</details>

**9**（標準）(−5/12)÷(−10/9)　〔参考：教科書p38・ワークp16 A2〕
<details><summary>ヒント1</summary>÷(−10/9) を、×(逆数) に直そう。</details>
<details><summary>ヒント2</summary>かける前に約分すると楽。</details>

**10**（標準）(−2)×(−3)×(−7)　〔参考：教科書p40・ワークp16 A3〕
<details><summary>ヒント</summary>負の数の個数で、符号を先に決めよう。</details>

**11**（標準）(−7)² と −7² を、それぞれ計算しなさい。　〔参考：教科書p42・ワークp18 A1〕
<details><summary>ヒント</summary>何を2回かけているかを、式で書き出そう。</details>

**12**（標準）6+(−18)÷3×2　〔参考：教科書p43・ワークp19 A3〕
<details><summary>ヒント</summary>乗除が先。乗除どうしは左から。</details>

**13**（応用）−3×{4−(6−11)}　〔参考：教科書p43・ワークp20 A1〕
<details><summary>ヒント1</summary>いちばん内側のかっこから。</details>
<details><summary>ヒント2</summary>4−(−5) は？</details>

**14**（応用）(2/3−5/6)×18　〔参考：教科書p44・ワークp21 A3〕
<details><summary>ヒント</summary>分配法則を使うと、通分しなくてよい。</details>

**15**（標準）196 を素因数分解しなさい。　〔参考：教科書p49・ワークp24 A3〕
<details><summary>ヒント</summary>2 でわれるだけわってみよう。</details>

**16**（応用）90 にできるだけ小さい自然数をかけて、ある自然数の2乗にします。何をかければよいですか。　〔参考：教科書p48〜50・章末p57〕
<details><summary>ヒント1</summary>90 を素因数分解しよう。</details>
<details><summary>ヒント2</summary>2乗の数は、どの素数の指数も偶数。</details>
