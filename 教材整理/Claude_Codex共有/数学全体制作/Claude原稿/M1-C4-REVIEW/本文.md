## M1-P204｜解法のつながり・理由を解説しながら振り返る（1）関数・比例・反比例の地図

### 4章の地図
| 1節 関数 | → | 2節 比例 | → | 3節 反比例 | → | 4節 利用 |
|---|---|---|---|---|---|---|
| x を決めると y が1つに決まる | | y＝ax・原点を通る直線 | | y＝a/x・双曲線 | | 何が一定かを見つける |

### 表・式・グラフは、1つの関係の3つの顔
- **表**：対応する x、y の値がすぐ分かる。
- **式**：表にない値も計算で求められる。
- **グラフ**：変化のようすが一目で分かる。
- どれか1つが分かれば、ほかの2つも作れる。比例なら y/x、反比例なら xy から比例定数を出すのが入口。

### 迷ったときの順番
1. 比例か反比例か：y/x が一定 → 比例、xy が一定 → 反比例。
2. 比例定数を求める：比例 a＝y/x、反比例 a＝xy。
3. 式に代入して、求めたい値を出す。単位と変域を確かめる。

## M1-P205｜解法のつながり・理由を解説しながら振り返る（2）思い出す・別の方法で確かめる

### 思い出しカード
1. y＝−2x のグラフは、右上がり？ 右下がり？
<details><summary>答え</summary>右下がり（a＜0）。</details>

2. 反比例のグラフが座標軸と交わらないのはなぜ？
<details><summary>答え</summary>x＝0 のときの y はなく、y が 0 になる x もないから。</details>

3. y が x に比例するとき、x が 3 倍になると y は何倍？ 反比例なら？
<details><summary>答え</summary>比例なら3倍、反比例なら 1/3 倍。</details>

### 別の方法で確かめる
**例**　y は x に反比例し、x＝4 のとき y＝9。x＝6 のときの y は？
- 方法1：a＝4×9＝36、y＝36/6＝6。
- 方法2：x が 4 から 6 へ 1.5 倍 → y は 1/1.5＝2/3 倍 → 9×2/3＝6。
- 2つの方法で同じ 6。
