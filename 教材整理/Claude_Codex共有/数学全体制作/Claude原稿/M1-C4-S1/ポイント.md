# M1-C4-S1　ポイントとかんたんにやる方法
## この節のポイント
- x を決めると y が **ただ1つ** に決まるとき、y は x の **関数**。
- 表にすると変化の量、グラフにすると変化の全体が見える。
- 変数のとる値の範囲が **変域**。以上・以下は ≦、より大きい・未満は ＜。
## かんたんにやる方法
1. 「関数か？」は、x に好きな数を1つ入れて、y が1つに決まるか試す。
2. 1つの x に y が2つ以上ありそうな例が見つかれば「関数ではない」。
3. 変域は数直線に ●（ふくむ）と ○（ふくまない）をかいてから不等号にする。
## よくあるミス
- 「y を決めると x が決まる」と逆向きに考える。
- 「未満」に等号をつけてしまう。
## 30秒チェック
**チェック1**　1辺 x cm の正方形の面積 y cm² は、x の関数ですか。
<details><summary>答え</summary>関数である（y＝x²）。</details>

**チェック2**　「−1 以上 4 未満」を不等号で表すと？
<details><summary>答え</summary>−1≦x＜4</details>
