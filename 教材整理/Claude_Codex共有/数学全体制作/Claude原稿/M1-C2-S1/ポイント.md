# M1-C2-S1　ポイントとかんたんにやる方法
## この節のポイント
- 数量は文字を使って式に表せる。1個 a 円のパン3個の代金は 3a 円。
- 書き方のきまり：× をはぶく／数は文字の前／1 ははぶく（1a → a）／同じ文字の積は累乗（a×a → a²）／÷ は分数の形。
- **式の値**：文字に数を入れて（代入して）計算した結果。負の数はかっこをつけて代入する。
## かんたんにやる方法
1. 「ことばの式」を先に作る：代金 ＝ 1個の値段 × 個数。そこに文字を入れる。
2. 単位をそろえてから式にする（m と cm、分と時間）。
3. a％ は a/100、a割 は a/10 と置きかえる。
4. 代入する前に、式をできるだけ簡単にしておくと計算ミスが減る。
## よくあるミス
- a×(−1) を −1a と書く（正しくは −a）。
- x÷3 を 3/x と書く（正しくは x/3）。
## 30秒チェック
**チェック1**　a×b×(−3)×a を、書き方のきまりにしたがって書きなさい。
<details><summary>答え</summary>−3a²b。</details>

**チェック2**　x＝−2 のとき、3x²−x の値を求めなさい。
<details><summary>答え</summary>14。3×(−2)²−(−2)＝12+2＝14。</details>
