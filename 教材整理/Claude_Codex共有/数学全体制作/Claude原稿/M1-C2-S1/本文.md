## M1-P076｜数量を文字で表すこと・文字式の表し方①／しくみ　（教科書 p60〜63・ワーク p32〜33）

［図 M1-C2-S1-FIG01：パン5個（x円の帯5つ）と牛乳120円の帯をつないだテープ図］

### なぜ文字を使うの？
- 値が決まっていない数（まだ分からない、または、いろいろ変わる数）も、まとめて1つの式で表せるから。
- 文字を使った式を **文字式** という。式 x×5+120 は、代金の **求め方** と、代金 **そのもの** の両方を表している。

### 書き方のきまり（積）
1. かけ算の記号 × をはぶく。　a×b → ab
2. 数と文字の積では、数を文字の前に書く。　x×5 → 5x
3. 同じ文字の積は、指数を使う。　a×a → a²、a×a×a → a³
4. 1 や −1 と文字の積は、1 を書かない。　1×a → a、(−1)×a → −a
5. 文字はふつうアルファベット順に書く。　b×a → ab
6. かっこのある式に数をかけるときは、数をかっこの前に書く。　(a+b)×3 → 3(a+b)

### 書き方のきまり（商）
- わり算は ÷ を使わず、**分数の形** で書く。　a÷5 → a/5、(x+y)÷3 → (x+y)/3
- a/5 は (1/5)a と書いてもよい（÷5 は ×1/5 と同じだから）。

### はぶけないもの
**+ と − の記号は、はぶけない**。　x×5+120 → 5x+120（+ は残す）

## M1-P077｜数量を文字で表すこと・文字式の表し方①／解き方

### 数量を文字式で表す順番
1. **ことばの式** を書く（代金＝1個の値段×個数、など）。
2. ことばの部分に、数や文字を入れる。
3. 書き方のきまりで整える。
4. 単位をつける（円、cm、g など）。

### 書き方を直す順番
1. まず、かけ算の部分ごとに、数と文字を集める（数は数どうしで先に計算する）。
2. 数 → 文字（アルファベット順）の順にならべ、同じ文字は指数にする。
3. わり算の部分は分数にする。
4. 最後に + − でつなぐ。

### どこを見る
- 「−1」をかけているか（符号は − だけ残る）。
- わり算の後ろに、かけ算が続いていないか（a÷b×c は (a/b)×c → ac/b）。

**確かめる**：書き直した式に、たとえば a＝2、b＝3 などを入れて、元の式と同じ値になるか。

## M1-P078｜数量を文字で表すこと・文字式の表し方①／例題　〔参考：教科書p60〜63・ワークp32〜33 ポイント2-1〜2-3〕

### 例題1-基本　1個 x 円のパンを5個と、120円の牛乳を1本買ったときの代金を、文字式で表しなさい。
1. ことばの式：（パンの代金）＋（牛乳の代金）。
2. パンの代金は x×5、牛乳は 120。
3. 書き方：x×5+120 → **5x+120（円）**。

### 例題1-標準　n×(−3)×m×n を、文字式の書き方にしたがって書きなさい。
1. 数どうし：(−3)。
2. 文字：m、n、n → アルファベット順、n は2つで n²。
3. 答え **−3mn²**。
**確かめる**：m＝1、n＝2 を入れると、元の式は 2×(−3)×1×2＝−12。−3mn²＝−3×1×4＝−12。同じ。

### 例題1-応用　2×a÷b×5 を、記号 ×、÷ を使わずに書きなさい。
1. ÷b は ×(1/b)。2×a×(1/b)×5。
2. 数どうし：2×5＝10。
3. 答え **10a/b**。
**確かめる**：a＝3、b＝2 で、元は 2×3÷2×5＝15。10a/b＝30/2＝15。

### 逆向き：3a²b を、記号 × を使って表しなさい。
- 答え：**3×a×a×b**。

## M1-P080｜文字式の表し方②（いろいろな数量）／しくみ　（教科書 p64〜65・ワーク p34〜35）

［図 M1-C2-S1-FIG02：道のり x km を4時間で歩く線分図（1時間ごとの区切り）］

### 代金とおつり
おつり＝出したお金−代金。2000円で1冊 a 円のノートを3冊買うと、おつりは **2000−3a（円）**。

### 速さ・時間・道のり
- 道のり＝速さ×時間、速さ＝道のり÷時間、時間＝道のり÷速さ。
- 時速 x km で4時間歩いた道のりは 4x km。
- y m を分速70mで歩いた時間は y/70 分。
- **単位に注意**：時速の「時間」と、問題の「分」がそろっているか。

### 割合
- 1% は 1/100、1割 は 1/10。
- a 円の 25% は (25/100)a＝(1/4)a 円。
- x 円の品物の2割引きの値段は、x の (1−2/10)＝8/10 → (4/5)x 円（0.8x 円）。

### 式の意味を読む
大人1人 a 円、子ども1人 b 円のとき、3a+2b（円）は「大人3人と子ども2人の料金の合計」。

## M1-P081｜文字式の表し方②／解き方

### 解く順番（数量を式にする）
1. ことばの式を書く（おつり＝出したお金−代金 など）。
2. 単位をそろえる（時間と分、m と km、g と kg）。
3. 文字・数を入れて、書き方のきまりで整える。

### 解く順番（割合）
1. 「もとにする量」を見つける（a 円の〜、x 人の〜）。
2. 割合を分数か小数にする（25% → 25/100、2割 → 2/10）。
3. 「〜引き」は 1 から割合をひく。「〜増し」は 1 にたす。

### 解く順番（式の意味を読む）
1. 文字が何を表しているかを確かめる。
2. 係数（文字の前の数）が何を表すかを考える（3a → a 円の3つ分＝3人分）。
3. +、−、×、÷ がどんな場面の計算かをことばにする。

**確かめる**：文字に分かりやすい数（a＝100 など）を入れて、式の答えが場面に合うか。

## M1-P082｜文字式の表し方②／例題　〔参考：教科書p64〜65・ワークp34〜35 ポイント2-4〜2-6〕

### 例題2-基本　2000円を出して、1冊 a 円のノートを3冊買ったときのおつり
1. おつり＝出したお金−代金。代金は 3a。
2. 答え **2000−3a（円）**。
**確かめる**：a＝100 なら 2000−300＝1700円。場面に合う。

### 例題2-標準（1）時速 x km で4時間歩いた道のり　（2）y m を分速70m で歩いたときにかかる時間
1. （1）道のり＝速さ×時間 → **4x（km）**。
2. （2）時間＝道のり÷速さ → y÷70 → **y/70（分）**。

### 例題2-応用（1）x 円の品物を2割5分引きで買ったときの値段
1. 2割5分＝0.25。引いたあとは 1−0.25＝0.75。
2. 答え **(3/4)x 円**（0.75x 円でもよい）。

### 例題2-応用（2）大人1人 a 円、子ども1人 b 円のとき、a−2b≧500 という式は、どんなことを表していますか。（関係の式は2節でくわしく学ぶ。ここでは a−2b の意味を読む。）
1. 2b は子ども2人分の料金。a−2b は「大人1人分と子ども2人分の差」。
2. 答え：**大人1人の料金は、子ども2人の料金より500円以上高い。**

## M1-P084｜式の値／しくみ　（教科書 p66〜68・ワーク p36〜37）

### 代入と式の値
- 式の中の文字を数におきかえることを **代入する** という。
- 代入する数を **文字の値**、代入して計算した結果を **式の値** という。
- 例：a＝28 のとき、a−18 の値は 28−18＝10。

### なぜかっこをつけるの？
- 負の数を代入するときは、**かっこをつけて** 入れる。
- x＝−3 のとき 5−2x は 5−2×(−3)。かっこがないと「5−2×−3」となり、記号が2つならんで、計算をまちがえやすい。
- a² に a＝−4 を入れると (−4)²＝16。かっこがないと −4²＝−16 になってしまう。

### −x の値
−x は (−1)×x。x＝−3 なら (−1)×(−3)＝3。

## M1-P085｜式の値／解き方

### 解く順番
1. かけ算の記号 × をもどして、式を書き直す（2x → 2×x、x² → x×x）。
2. 文字のところに、かっこつきで数を入れる。
3. 1章の計算の順序（累乗 → 乗除 → 加減）で計算する。

### どこを見る
- 分数の形 12/x は 12÷x。
- 文字が2つあるときは、どの文字にどの数を入れるか、取りちがえない。

**確かめる**：かっこを入れ忘れていないか、代入した数の符号をもう一度見る。
