# M1-C5-S2　ポイントとかんたんにやる方法
## この節のポイント
- **平行移動**：対応する点を結ぶ線分は平行で長さが等しい。
- **回転移動**：対応する点は中心から等しい距離、回転の角はすべて等しい。180° は **点対称移動**。
- **対称移動**：対応する点を結ぶ線分は、軸と垂直に交わり2等分される。
- 作図は **定規とコンパスだけ**。垂直二等分線・角の二等分線・垂線の3つが基本。
## かんたんにやる方法
1. 移動の見分け：裏返っている → 対称移動。向きが同じ → 平行移動。向きが変わる → 回転移動。
2. 3つの作図は、ぜんぶ「コンパスで同じ半径の円を2つかいて、交点を結ぶ」。
3. 作れる角：90°（垂線）→ 45°。60°（正三角形）→ 30° → 15°。たし算・ひき算で組み合わせる。
## よくあるミス
- 垂直二等分線で、両はしの円の半径を変えてしまう。
- 作図で、ものさしの目盛りや分度器を使う。
