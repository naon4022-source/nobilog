# M1-C5-S1　練習問題（これができれば授業は楽勝）

## M1-P211
**練習1**（基本）★　3点 A、B、C が一直線上にないとき、2点ずつを通る直線は何本ひけますか。
<details><summary>答え</summary>3本（直線 AB、BC、CA）。2点を通る直線は1本だけ。</details>

**練習2**（基本）　ひし形 ABCD の対角線 AC と BD の関係を、記号を使って表しなさい。
<details><summary>答え</summary>AC⊥BD</details>

**練習3**（標準）★　一直線上に点 A、O、B がこの順に並び、O から半直線 OC、OD をひきました。∠AOC＝40°、∠COD＝90° のとき、∠DOB の大きさを求めなさい。（OC、OD はこの順に、A の側から B の側へ並んでいます）
<details><summary>ヒント</summary>∠AOC＋∠COD＋∠DOB＝180°。</details>
<details><summary>答え</summary>50°（180°−40°−90°）</details>

**練習4**（発展）　平行な2直線 ℓ、m の間の距離が 5cm です。ℓ 上の点 A と m 上の点 B を結ぶ線分 AB の長さが 5cm になるのは、AB と ℓ がどんな関係のときですか。
<details><summary>答え</summary>AB⊥ℓ のとき（垂直のときだけ距離と同じ 5cm。ななめなら 5cm より長い）。</details>
