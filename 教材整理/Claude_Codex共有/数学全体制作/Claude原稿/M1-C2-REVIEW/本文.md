## M1-P121｜解法のつながり・理由を解説しながら振り返る（2）思い出す・別の方法で確かめる

### 思い出しカード
1. a×a と 2a のちがいは？
<details><summary>答え</summary>a×a は a²（a を2回かける）。2a は a+a（a を2つたす）。</details>

2. 6a−(4a−7) で、7 の符号はどうなる？
<details><summary>答え</summary>+7。−( ) は中のすべての項の符号を変える。</details>

3. 「以上」「未満」の記号は？
<details><summary>答え</summary>以上は ≧、未満は <。</details>

### 別の方法で確かめる
**例**　(1/3)(6x−9)−(1/2)(4x+2)＝−4
- 方法1：分配法則で計算する（2節 例題4-応用）。
- 方法2：x＝0 と x＝3 を入れて、どちらも −4 になるか調べる。
- 文字の項が消えて数だけ残る式は、どんな x を入れても同じ値になる。2つの値で同じなら、計算が合っている見込みが高い。

### 考え方付き確認
x＝−2 のとき、3(x+4)−2(x−1) の値を、（1）そのまま代入、（2）式を計算してから代入、の2つの方法で求め、同じになることを確かめなさい。
<details><summary>ヒント1</summary>（2）3x+12−2x+2＝x+14。</details>
<details><summary>答えと解説</summary>12。（1）3×2−2×(−3)＝6+6＝12。（2）x+14 に x＝−2 → 12。</details>
