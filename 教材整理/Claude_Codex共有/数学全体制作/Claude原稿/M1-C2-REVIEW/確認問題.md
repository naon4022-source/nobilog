# M1-C2-REVIEW　まとめの問題（8問・入力式）
答えは `解答と採点基準.md`。

**R1**　m×(−1)×n×m を、文字式の書き方にしたがって書きなさい。　〔参考：教科書p84 1〕
<details><summary>ヒント</summary>同じ文字は指数で。−1 は符号だけ残す。</details>

**R2**　分速 x m で 15分歩いたときの道のりを、式で表しなさい。　〔参考：教科書p84 3〕
<details><summary>ヒント</summary>道のり＝速さ×時間。</details>

**R3**　a＝−5 のとき、a²−4a の値　〔参考：教科書p84 4〕
<details><summary>ヒント</summary>(−5)² と −4×(−5)。</details>

**R4**　−7y+2−(3−5y)　〔参考：教科書p84 6・p86 5〕
<details><summary>ヒント</summary>−( ) の中の符号を全部変える。</details>

**R5**　(15x−10)÷(−5/3)　〔参考：教科書p85 8〕
<details><summary>ヒント</summary>逆数 −3/5 をかける。</details>

**R6**　A＝3x−2、B＝−x+5 のとき、2A−B を計算しなさい。　〔参考：教科書p87 6〕
<details><summary>ヒント1</summary>2(3x−2)−(−x+5)。</details>

**R7**　1本 a 円のジュース4本と、1個 b 円のパン2個を買ったら、代金は 1000円をこえました。この関係を不等式で表しなさい。　〔参考：教科書p85 9・ワークp51 4〕
<details><summary>ヒント</summary>「こえる」は「より大きい」。</details>

**R8**　横に正方形の板を n 枚、すき間なくならべて長方形を作ります。板1枚は1辺 2cm です。長方形のまわりの長さを、n を使った式で表しなさい。　〔参考：教科書p87 9・ワークp52 (5)〕
<details><summary>ヒント1</summary>横の長さは 2n cm、たての長さは 2cm。</details>
<details><summary>ヒント2</summary>まわり＝(横＋たて)×2。</details>
