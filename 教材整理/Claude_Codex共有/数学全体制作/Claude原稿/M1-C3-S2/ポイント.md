# M1-C3-S2　ポイントとかんたんにやる方法
## この節のポイント
- 方程式の利用の手順：① 求めたいものを x にする → ② 等しい関係を見つけて方程式をつくる → ③ 解く → ④ 答えが場面に合うか確かめる。
- 過不足の問題：配り方を変えても **全体の数は同じ**。
- 速さの問題：道のり ＝ 速さ × 時間。追いつく ＝ **進んだ道のりが等しい**。
- 比例式の利用：同じ割合で混ぜる・比が○：△になる → 比例式をつくる。
## かんたんにやる方法
1. 線分図や表に、分かっている数と x を書きこんでから式にする。
2. 「＝」の左右に置くものを、ことばで先に決める（例：「配り方Aの全体＝配り方Bの全体」）。
3. 追いつく問題は「はじめの差 ÷ 速さの差」でも答えが出る。方程式の答えと同じか確かめに使える。
4. 答えには単位をつけて、問題文にもどして確かめる。
## よくあるミス
- x を何にしたかを書かずに、途中でわからなくなる。
- 分と時間など、単位がそろっていない。
- 人数や個数が小数・負の数になったのに、そのまま答える。
## 30秒チェック
**チェック1**　あめを子どもに配ります。1人4個ずつだと6個余り、5個ずつだと3個足りません。子どもの人数は？
<details><summary>答え</summary>9人。4x+6＝5x−3、x＝9。あめは42個。</details>

**チェック2**　姉が分速50mで出発し、その10分後に弟が分速100mで追いかけます。弟は何分後に追いつきますか。
<details><summary>答え</summary>10分後。100x＝50(10+x)、50x＝500、x＝10。差500m÷速さの差50m＝10分でも同じ。</details>
