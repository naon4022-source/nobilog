# M1-C3-S2　確認問題（8問・入力式）
答えは `解答と採点基準.md`。単位をつけて答える（単位がなくても数が正しければ正解）。難しさ：基本2・標準3・応用3。

**1**（基本）1500円を出して、1本 x 円のジュース6本と、250円のお菓子1袋を買ったら、おつりは 50円でした。ジュース1本の値段を求めなさい。　〔参考：教科書p102・ワークp64 A1〕
<details><summary>ヒント</summary>1500−(6x+250)＝50。</details>

**2**（基本）ノート5冊と 90円の消しゴム1個の代金は、ノート1冊と 70円の鉛筆1本の代金の3倍です。ノート1冊の値段を求めなさい。　〔参考：教科書p104・ワークp64 A1〕
<details><summary>ヒント</summary>5x+90＝3(x+70)。</details>

**3**（標準）カードを何人かに配ります。1人5枚ずつだと 8枚余り、7枚ずつだと 12枚足りません。人数とカードの枚数を求めなさい。　〔参考：教科書p105・ワークp65 A3〕
<details><summary>ヒント1</summary>人数を x 人として、枚数を2通りで表す。</details>

**4**（標準）弟が分速 80m で家を出発し、9分後に兄が分速 200m で同じ道を追いかけました。兄は出発してから何分後に追いつきますか。　〔参考：教科書p106・ワークp66 A1〕
<details><summary>ヒント1</summary>表に、速さ・時間・道のりを書こう。</details>

**5**（標準）油と酢を 5：3 の割合で混ぜて、ドレッシングを 240mL 作ります。油は何 mL 必要ですか。　〔参考：教科書p109・ワークp68 A1〕
<details><summary>ヒント</summary>油：全体＝5：8。</details>

**6**（応用）ある店の土曜日と日曜日の来店者は合わせて 410人でした。日曜日の来店者は、土曜日の来店者の 120% より 30人少なかったです。土曜日の来店者は何人ですか。　〔参考：教科書p108・ワークp67 A2〕
<details><summary>ヒント1</summary>土曜日を x 人とすると、日曜日は 1.2x−30。</details>

**7**（応用）袋Aにビー玉が 40個、袋Bに 25個あります。Bから何個かを取り出してAに入れたら、AとBの個数の比が 4：1 になりました。取り出した個数を求めなさい。　〔参考：教科書p113 7・ワークp69 3〕
<details><summary>ヒント1</summary>A は 40+x、B は 25−x。</details>

**8**（応用）問題4で、兄弟の家から図書館までが 2km のとき、兄は弟が図書館に着く前に追いつけますか。「追いつける」か「追いつけない」と入力し、追いつく地点の家からの道のり（m）も答えなさい。　〔参考：教科書p107 深める例〕
<details><summary>ヒント</summary>問題4の答えから、兄が進んだ道のりを計算しよう。</details>
