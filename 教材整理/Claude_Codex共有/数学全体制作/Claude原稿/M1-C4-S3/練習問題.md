# M1-C4-S3　練習問題（これができれば授業は楽勝）

## M1-P190
**練習1**（基本）　60cm のリボンを x 等分したときの1本の長さを y cm とします。y を x の式で表しなさい。
<details><summary>答え</summary>y＝60/x</details>

**練習2**（標準）★　y は x に反比例し、x＝6 のとき y＝−4 です。x＝−8 のときの y の値を求めなさい。
<details><summary>答え</summary>3（y＝−24/x）</details>

**練習3**（標準）★　次の表で、y は x に反比例しています。□にあてはまる数を答えなさい。　x：2、3、□　／　y：15、10、−5
<details><summary>答え</summary>−6（a＝30、30÷(−5)＝−6）</details>

**練習4**（発展）　y が x に反比例するとき、x の値が 4 倍になると y の値は何倍になりますか。
<details><summary>答え</summary>1/4 倍</details>

## M1-P194
**練習1**（基本）　y＝6/x のグラフ上の点で、x 座標が −2 の点の座標を答えなさい。
<details><summary>答え</summary>(−2, −3)</details>

**練習2**（標準）★　反比例のグラフが点 (4, −5) を通ります。式を求めなさい。
<details><summary>答え</summary>y＝−20/x</details>

**練習3**（標準）★　y＝−16/x のグラフ上の点で、x 座標・y 座標がどちらも整数で、x 座標が正のものは何個ありますか。
<details><summary>答え</summary>5個（(1,−16)(2,−8)(4,−4)(8,−2)(16,−1)）</details>

**練習4**（発展）　次のうち、反比例のグラフについて正しいものをすべて選びなさい。（ア）原点を通る　（イ）x 軸と交わらない　（ウ）比例定数が負なら、左上と右下にある
<details><summary>答え</summary>（イ）（ウ）</details>
