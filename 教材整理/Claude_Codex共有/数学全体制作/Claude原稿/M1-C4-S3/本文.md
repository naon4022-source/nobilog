## M1-P186｜身近な導入・既習事項・今回のつながり

### クッキーを分けると、1人分は？
- クッキー24個を x 人で同じ数ずつ分けると、1人分は y 個。
- 2人なら12個、3人なら8個、4人なら6個、6人なら4個。
- 人数が2倍、3倍になると、1人分は 1/2倍、1/3倍になる。
- 1人分×人数＝24 はいつも同じ。だから **y＝24/x**。

2. 1組の x、y の値から、反比例の式を求める。
3. 反比例のグラフ（双曲線）をかき、特徴を説明する。

## M1-P187｜4章5 反比例の式／しくみ　（教科書 p131〜133・ワーク p82〜83）

［図 M1-C4-S3-FIG01：クッキー24個の分け方の表。人数 x が2倍・3倍になると1人分 y が 1/2倍・1/3倍になる矢印と、x×y がいつも24 になることを示した図］

### 反比例の式
- y が x の関数で、**y＝a/x**（a は決まった数）と表されるとき、「y は x に **反比例** する」という。a も **比例定数** という。
- クッキーの例では y＝24/x、比例定数は 24。

### 反比例の性質
- x の値が2倍、3倍、……になると、y の値は 1/2倍、1/3倍、……になる。
- 対応する x と y の **積 xy は一定** で、比例定数 a に等しい（xy＝a とも表せる）。

### 負の数にも広げる
- x や a が負の数でも、y＝a/x なら反比例という。
- x＝0 のときの y の値はない（0 でわることはできない）。

## M1-P188｜4章5 反比例の式／解き方

### 「y は x に反比例するか」を判断する順番
1. x と y の関係を、ことばの式にする（1人分＝全体÷人数 など）。
2. **y＝(決まった数)÷x** の形になれば反比例。
3. 表しか分からないときは、**x×y がいつも同じ値か** を調べる。

### 反比例の式を求める順番
1. y＝a/x とおく（または xy＝a）。
2. 分かっている x、y の値から a＝x×y を計算する。
3. y＝(求めた a)/x と書く。

**確かめる**：表の2組以上で x×y を計算して、同じ値になるか。

## M1-P189｜4章5 反比例の式／例題　〔参考：教科書p131〜133・ワークp82〜83 ポイント4-11・4-12〕

### 例題1-基本　面積が 18cm² の長方形の、横の長さを x cm、縦の長さを y cm とします。y を x の式で表し、反比例することを示しなさい。
1. 縦＝面積÷横 → y＝18/x。
2. y＝a/x の形なので **反比例する**。比例定数 18。

### 例題1-標準　y は x に反比例し、x＝3 のとき y＝−8 です。x と y の関係を式に表しなさい。
1. a＝x×y＝3×(−8)＝−24。
2. 答え **y＝−24/x**。

### 例題1-応用　例題1-標準の式で、x＝−6 のときの y の値を求めなさい。また、x の値が3倍になると、y の値は何倍になりますか。
1. y＝−24/(−6)＝4。
2. 反比例なので、x が3倍 → y は **1/3倍**。
3. 確かめ：x＝3 → y＝−8、x＝9 → y＝−24/9＝−8/3。−8 の 1/3。

## M1-P191｜4章6 反比例のグラフ／しくみ　（教科書 p134〜138・ワーク p84〜85）

［図 M1-C4-S3-FIG02：y＝12/x のグラフ（2本のなめらかな曲線）。(1,12)(2,6)(3,4)(4,3)(6,2)(12,1) と負の側の対応する点をとり、座標軸に近づくが交わらないことを示した図］

### 反比例のグラフは双曲線
- y＝12/x の点をたくさんとってなめらかにつなぐと、**2つの曲線** になる。この曲線を **双曲線** という。
- x の値の絶対値が大きくなるほど、y は 0 に近づく。x が 0 に近づくほど、y の絶対値は大きくなる。
- グラフは **座標軸には限りなく近づくが、交わらない**（x も y も 0 にはならないから）。

### a の符号と位置
- a＞0：右上と左下の2つの部分に曲線がある。
- a＜0：左上と右下の2つの部分に曲線がある。

## M1-P192｜4章6 反比例のグラフ／解き方

### 反比例のグラフをかく順番
1. x×y＝a になる **整数の組** をさがす（a＝12 なら (1,12)(2,6)(3,4)(4,3)(6,2)(12,1)）。
2. 負の側も同じようにさがす（(−1,−12)(−2,−6)……）。
3. 点をなめらかな曲線で結ぶ。折れ線にしない。座標軸にはつけない。

### グラフから式を読む順番
1. グラフ上で、座標が整数ではっきり読める点を1つ見つける。
2. a＝x×y を計算して、y＝a/x と書く。

**確かめる**：もう1つの点でも x×y が同じ a になるか。

## M1-P193｜4章6 反比例のグラフ／例題　〔参考：教科書p134〜138・ワークp84〜85 ポイント4-13・4-14〕

### 例題2-基本　y＝10/x のグラフ上の点で、x 座標・y 座標がどちらも正の整数である点を、すべて答えなさい。
1. x×y＝10 になる正の整数の組をさがす。
2. 答え **(1, 10)、(2, 5)、(5, 2)、(10, 1)**。

### 例題2-標準　y＝−8/x のグラフは、どの2つの部分にありますか。また、x＝4 のときの点の座標を答えなさい。
1. a＝−8＜0 なので、**左上と右下** の部分。
2. x＝4 のとき y＝−2 → **(4, −2)**（右下の部分にある）。

### 例題2-応用　ある反比例のグラフが点 (−3, −5) を通ります。このグラフの式と、x＝5 のときの y の値を求めなさい。
1. a＝(−3)×(−5)＝15 → y＝15/x。
2. x＝5 のとき y＝3。
3. 答え **y＝15/x、y＝3**。

## M1-P195｜別の場面へ使う・立式や判断の根拠・検算

［図 M1-C4-S3-FIG03：かみ合った2つの歯車。歯の数 24 の歯車と、歯の数 x の歯車（回転数 y）。同じ時間に動く歯の数が等しいことを示す図］

### 歯車の歯の数と回転数
- 歯の数が 24 の歯車 A が 1分間に 10 回転すると、1分間に動く歯の数は 24×10＝240。
- かみ合っている歯車 B（歯の数 x）も、1分間に動く歯の数は 240。B の回転数を y とすると **xy＝240**、つまり **y＝240/x**。
- 歯の数が少ない歯車ほど、たくさん回る。自転車のギアも同じしくみ。

### 根拠を言えるようにしよう
- 「x×y がいつも 240 だから反比例」。

### 検算
- x＝12 なら y＝20。12×20＝240 で合っている。

## M1-P196｜全体のつながり・自分の言葉で整理・解説付き振り返り

### まとめ
- **反比例**：y＝a/x。x が2倍・3倍になると y は 1/2倍・1/3倍、xy＝a。
- **式の求め方**：a＝x×y。
- **グラフ**：双曲線。座標軸とは交わらない。a＞0 は右上・左下、a＜0 は左上・右下。

### 比例と反比例をくらべよう
| | 比例 y＝ax | 反比例 y＝a/x |
|---|---|---|
| x が2倍になると | y も2倍 | y は 1/2倍 |
| 一定のもの | y/x＝a | xy＝a |
| グラフ | 原点を通る直線 | 双曲線（軸と交わらない） |

### 振り返りの問題
**振り返り1**　y は x に反比例し、x＝4 のとき y＝−6 です。x＝−3 のときの y の値を求めなさい。
<details><summary>答え</summary>8（y＝−24/x）</details>

**振り返り2**　y＝20/x のグラフ上の点で、座標がどちらも正の整数のものは何個ありますか。
<details><summary>答え</summary>6個（(1,20)(2,10)(4,5)(5,4)(10,2)(20,1)）</details>
