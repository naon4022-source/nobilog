# M1-C4-S2　ポイントとかんたんにやる方法
## この節のポイント
- **比例**：y＝ax（a は比例定数）。x が2倍・3倍 → y も2倍・3倍。y/x＝a。
- 1組の値が分かれば、y＝ax に代入して a が求められる。
- **座標** (x, y)：右・上が正、左・下が負。原点は (0, 0)。
- 比例のグラフは **原点を通る直線**。a＞0 右上がり、a＜0 右下がり。
## かんたんにやる方法
1. 比例定数は「y÷x」。表からも式からもすぐ出せる。
2. グラフは「原点＋整数になる点」の2点で引く。分数の比例定数は、x を分母の数にすると整数の点になる。
3. グラフから式を読むときは、格子点（方眼の交点）を1つ見つけて y÷x。
## よくあるミス
- 座標の x と y を逆に書く。
- 比例定数が負なのに右上がりの直線を引く。
## 30秒チェック
**チェック1**　y は x に比例し、x＝4 のとき y＝−12。比例定数は？
<details><summary>答え</summary>−3</details>

**チェック2**　y＝(2/5)x のグラフが通る、原点以外の整数の点を1つ答えなさい。
<details><summary>答え</summary>(5, 2)（ほかに (−5, −2) など）</details>
