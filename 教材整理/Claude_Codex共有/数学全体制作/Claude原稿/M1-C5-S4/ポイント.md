# M1-C5-S4　ポイントとかんたんにやる方法
## この節のポイント
- **弧**（円周の一部）・**弦**（弧の両はしを結ぶ線分）・**中心角**・**おうぎ形**。
- **接線は、接点を通る半径に垂直**。
- 円：**ℓ＝2πr、S＝πr²**。おうぎ形：円の **a/360** 倍。
## かんたんにやる方法
1. a/360 は先に約分：90°＝1/4、120°＝1/3、60°＝1/6、45°＝1/8、30°＝1/12。
2. おうぎ形の面積は **S＝(1/2)×弧×半径** でも出せる。中心角がいらない。
3. 中心角は「おうぎ形÷円全体×360」。
## よくあるミス
- 直径をそのまま r に入れる。
- おうぎ形のまわりの長さに、半径2本を足し忘れる。
