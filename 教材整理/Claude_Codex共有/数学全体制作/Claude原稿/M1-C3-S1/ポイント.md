# M1-C3-S1　ポイントとかんたんにやる方法
## この節のポイント
- 方程式を成り立たせる文字の値を **解** という。
- **等式の性質**：両辺に同じ数をたす・ひく・かける・同じ数（0以外）でわっても、等式は成り立つ。
- **移項**：項を反対の辺に移すと、符号が変わる。
- かっこ → 分配法則で外す。分数 → 分母の最小公倍数を両辺にかける。小数 → 両辺を10倍・100倍する。
- **比例式** a：b＝c：d では、ad＝bc。
## かんたんにやる方法
1. 「x の項は左へ、数の項は右へ」と決めて移項する。
2. 分数のある方程式は、最初に分母をはらう（**すべての項**にかける）。
3. 解いたら、もとの式に代入して確かめる。30秒でできる保険。
4. 比例式は「外側どうしの積＝内側どうしの積」（たすきがけ）。
## よくあるミス
- 移項したのに符号を変えない。
- 分母をはらうとき、分数でない項にかけ忘れる。
- −3x＝12 を x＝4 にする（正しくは x＝−4）。
