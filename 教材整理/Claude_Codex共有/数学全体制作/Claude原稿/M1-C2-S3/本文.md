## M1-P113｜身近な導入・既習事項・今回のつながり

［絵 M1-C2-S3-INTRO（未生成。制作指示は画像選定.md）：数あてをする2人の中学生］

### 数あてゲーム
ゆうきさんが、友だちにこう言った。
1. 好きな整数を1つ思いうかべて。
2. それを3倍して。
3. 6をたして。
4. 3でわって。
5. 最初に思いうかべた数をひいて。
「答えは、2 でしょう！」

- 5 で試すと：15 → 21 → 7 → 7−5＝2。−4 で試すと：−12 → −6 → −2 → −2−(−4)＝2。
- どんな数でも本当に 2 になるの？ 何回試しても、すべての数を試すことはできない。
- **文字を使うと、すべての数についての説明ができる**。これがこの節のテーマ。

### 使う、前に学んだこと
- 文字式の計算（2節）：かっこを外す、同じ文字の項をまとめる、各項をわる。

## M1-P114｜文字式の利用／しくみ　（教科書 p82〜83）

［図 M1-C2-S3-FIG01：数あての手順を、式の変化の表で示す（n → 3n → 3n+6 → n+2 → 2）］

### なぜ文字で説明できるの？
- 思いうかべた数を n とおく。n には、どんな整数も入る。
- 手順どおりに計算すると、
  - 3倍：3n
  - 6をたす：3n+6
  - 3でわる：(3n+6)/3＝n+2
  - n をひく：(n+2)−n＝**2**
- 最後の式に n が残らない。だから、n がどんな整数でも、答えはいつも 2。

### いくつか試すことと、文字で説明することのちがい
| | 数で試す | 文字で説明する |
|---|---|---|
| 分かること | 試した数で成り立つ | すべての数で成り立つ |
| 数の個数 | 試した分だけ | 1つの式で全部 |

## M1-P115｜文字式の利用／解き方

### 解く順番（「いつも○になる」ことの説明）
1. 決めた数を文字で表す（n とおく）。
2. 手順を1つずつ文字式にする（かっこを使って、前の式全体に計算する）。
3. 式を計算して、いちばん簡単な形にする。
4. 結果から、言いたいこと（いつも○、いつも〜の倍数など）を導く。

### 規則を式で表す順番（ならべる図形など）
1. 1番目、2番目、3番目……の数を表にする。
2. 1つ増えるごとに、いくつ増えるかを見る。
3. 「はじめの数 ＋ 増える数 ×（いくつ増えたか）」の形で、n を使って表す。

**確かめる**：できた式に n＝1、2、3 を入れて、表の数と一致するか。

## M1-P116｜文字式の利用／例題　〔参考：教科書p82〜83・p87 9・ワークp51 章のまとめ9〕

### 例題1-基本　P113 の数あてで、思いうかべた数が −4 のとき、答えが 2 になることを確かめなさい。
1. 3倍：−12。2. 6をたす：−6。3. 3でわる：−2。4. −4 をひく：−2−(−4)＝**2**。

### 例題1-標準　次の手順で計算すると、答えはいつも同じ数になります。その数を求め、そうなる理由を文字式で説明しなさい。
「整数を1つ決める → 4倍する → 8をひく → 4でわる → 決めた数をひく」
1. 決めた数を n とする。
2. 4n → 4n−8 → (4n−8)/4＝n−2 → (n−2)−n＝**−2**。
3. 説明：最後の式に n が残らないので、どんな整数を決めても −2 になる。

### 例題1-応用　正六角形を、辺を1本ずつ共有しながら横につなげていきます。正六角形を n 個つなげたときに使う棒の本数を、n を使った式で表しなさい。
1. 表をつくる：1個 6本、2個 11本、3個 16本。
2. 1個増えるごとに 5本増える（共有する1本の分だけ少ない）。
3. 1個目の 6本に、あと (n−1) 個 × 5本：6+5(n−1)＝**5n+1（本）**。
**確かめる**：n＝1 → 6、n＝2 → 11、n＝3 → 16。表と一致。

## M1-P117｜文字式の利用／つまずきと確認

### つまずきの比較
| まちがい | 正しい考え方 |
|---|---|
| いくつかの数で試して「いつも成り立つ」とする | 試した数でしか分からない。文字で説明する |
| 3でわるとき 3n+6/3 と書く | 前の式全体をわる：(3n+6)/3 |
| 規則の式を 6n とする（共有する辺を数えない） | n＝2 で確かめると 12 で、表の 11 と合わない |

### 考え方付き確認
**確認1-1**　「整数を決める → 2倍する → 10をたす → 2でわる → 決めた数をひく」の答えは、いつもいくつになりますか。
<details><summary>ヒント1</summary>決めた数を n として、手順どおりに式を変えていこう。</details>
<details><summary>答えと解説</summary>5。2n → 2n+10 → n+5 → 5。</details>

**確認1-2**　正方形を、辺を1本ずつ共有しながら横に n 個つなげるとき、使う棒の本数を n の式で表しなさい。
<details><summary>ヒント1</summary>1個 4本、2個 7本、3個 10本。</details>
<details><summary>答えと解説</summary>3n+1（本）。1個増えるごとに3本増える。4+3(n−1)＝3n+1。</details>

## M1-P118｜別の場面へ使う・立式や判断の根拠・検算

［絵 M1-C2-S3-APPLY（未生成。制作指示は画像選定.md）：自分で数あてゲームを作っている中学生のノート（数字なし）］

### 自分で数あてゲームを作る
- 最後に「決めた数をひく」と、n が消える。そのためには、とちゅうで n の係数を 1 にもどしておく。
- 例：「決めた数を5倍 → 15をたす → 5でわる → 決めた数をひく」→ 5n → 5n+15 → n+3 → **3**。

### 根拠を言えるようにしよう
答えがいつも 7 になる数あてを1つ作り、文字で確かめよう。
<details><summary>作り方の例</summary>2倍 → 14をたす → 2でわる → 決めた数をひく。2n+14 → n+7 → 7。（ほかにも、4倍 → 28をたす → 4でわる → ひく、など。最後に7が残る手順なら正しい。）</details>
