# M1-C2-S3　ポイントとかんたんにやる方法
## この節のポイント
- 並び方のきまりを文字で表すと、何番目でもすぐに求められる。
- 文字式を使うと、「いつでも成り立つ」ことを説明できる。
## かんたんにやる方法
1. 1番目、2番目、3番目を **表** にかいて、いくつずつ増えているかを見る。
2. 「増える数 × n ＋ 調整の数」の形を考える。n＝1 を入れて合うように調整の数を決める。
3. できた式に n＝2、3 を入れて、表と同じになるか確かめる。
## よくあるミス
- 1番目だけを見て式を作り、2番目以降で合わない。
- n番目と、n までの合計を取りちがえる。
## 30秒チェック
**チェック1**　マッチ棒で正方形を横に1列につなげていきます。正方形を n 個つくるのに必要なマッチ棒の本数を、n を使った式で表しなさい。
<details><summary>答え</summary>3n+1（本）。はじめの1本に、正方形1個ごとに3本ずつ増える。n＝4 なら13本。</details>
