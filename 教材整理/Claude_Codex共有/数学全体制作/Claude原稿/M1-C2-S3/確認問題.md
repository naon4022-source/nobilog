# M1-C2-S3　確認問題（5問・入力式）
答えは `解答と採点基準.md`。難しさ：基本1・標準2・応用2。

**1**（基本）整数 n を3倍して12をたし、3でわった式を、いちばん簡単な形で書きなさい。　〔参考：教科書p83〕
<details><summary>ヒント</summary>(3n+12)/3。各項を3でわる。</details>

**2**（標準）「整数を決める → 6倍する → 12をひく → 6でわる → 決めた数をひく」の答えは、いつもいくつですか。　〔参考：教科書p83〕
<details><summary>ヒント</summary>n とおいて、手順どおりに。</details>

**3**（標準）正五角形を、辺を1本ずつ共有しながら横に n 個つなげます。使う棒の本数を n の式で表しなさい。　〔参考：教科書p87 9・ワークp51 9 と同じ考え方〕
<details><summary>ヒント1</summary>1個 5本、2個 9本、3個 13本。</details>

**4**（応用）確認3で、正五角形を 20 個つなげるとき、棒は何本ですか。　〔参考：ワークp51 9(1) と同じ考え方〕
<details><summary>ヒント</summary>3の式に n＝30 を代入。</details>

**5**（応用）ある整数を決めて、「4倍する → □をたす → 4でわる → 決めた数をひく」と、答えがいつも 6 になりました。□にあてはまる数を求めなさい。
<details><summary>ヒント1</summary>4n+□ を4でわると n+□/4。</details>
<details><summary>ヒント2</summary>□/4＝6。</details>
