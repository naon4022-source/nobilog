# Codexへ：動画のつくり直しと分担（2026-10-04・Claude作成、ユーザー確認済みの方針）

## なぜ
ユーザーから「動画がカクカクで、見ても全然わからない」と指摘があった。今の動画は 12コマ/秒・音なし・短い字幕だけで、
「何をしているか」「なぜそうなるか」が伝わらない。文字も小さく、止まっている時間が長い。

## 新しいやり方（全部の動画に適用）
- `メディア/制作ソース/動画エンジン/` を使う（説明は同フォルダの はじめに.md）。見本は `制作ソース/M1-C6-S2-V01.html`・`.json`・`メディア/M1-C6-S2-V01.mp4`。
- 30コマ/秒・ナレーション（macOS の Kyoko）と同じ文の字幕・長さはナレーションに合わせる（目安40〜75秒）・1本4MB以内。
- わかりやすさの基準：
  1. 1文＝1ステップ。そのステップで動かすものは1つ。
  2. ナレーションで「何をしているか」と「なぜそうなるか」を言う。
  3. 主役の数・図を大きく中央に（数式48px以上、どの文字も32px以上）。
  4. 動いている所・大事な所はオレンジの丸や矢印で示す。
  5. ステップの終わりに少し止めて、考える間をとる。
  6. 最初は問いかけ、最後は「まとめ」で、いちばん大事なきまりを大きく残す。
  7. はみ出し・重なり・字幕に隠れる所をなくす。「かくすもの」（例題の答え）は言わない・見せない。
- 依頼書 `Codexへ_1件ずつの依頼プロンプト.md` の動画ブロックは、秒数の絵コンテから「台本（1文＝1ステップ）」に書きかえた。これに従う。

## 分担
- Claude：6章・7章の動画19本（M1-C6-*・M1-C7-* の V・VP・REVIEW-V01）。M1-C6-S2-V01 は新しいやり方で作成済み。
- Codex：それ以外の動画（1〜5章・巻末）と、全章の図・場面の絵。
- Codex がすでに作った動画（1・2章の34本）も、新しいやり方で作り直す。図（SVG）と場面の絵は、今のままでよい。

## 進め方
1. 作業前に `bash .claude/verify/run.sh` が全部通ることを確かめる。
2. 見本の動画を開いて、音声・字幕・動きのテンポを確認してから始める。
3. 1本作るごとに、1.5秒ごとのコマを並べた一覧画像を作って全コマを目で点検し、`メディア/作成記録.md` に「台本の文数・長さ・点検で直したこと」を書く。
4. `python3 教材整理/実装/build-textbook-book.py` で本に反映。最後に run.sh をもう一度。
5. 本番への公開は、ユーザーの指示があるまでしない。採用はClaudeが内容を見て決める。
