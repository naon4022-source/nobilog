# 1章1節 正の数・負の数　解答と採点基準（試作）

対象：`確認問題.md` の12問、`本文.md` の例題。

## 共通の入力ルール（案）
- 負の符号は「−」（U+2212）、半角「-」、全角「－」のどれでも同じものとして扱う。
  - 長音「ー」は、記号のまちがいか分からないので、自動で正解にはしない。「−を入れてね」と案内する（アプリでの扱いはCodexと相談）。
- 正の数の「+」は、あってもなくても正解。
- 分数は「2/9」のように「/」で入力する。帯分数は使わない。
- 同じ値の小数と分数は、同じものとして扱う。ただし、問題が書き方を指定しているときは別（下の各問に書く）。
- 数の区切りは、「、」「,」「，」と空白を同じものとして扱う。
- 単位は、問題の単位と同じならあってもなくてもよい。ちがう単位は誤答。

## 用語
- **正解**：点数になる。
- **部分的正答**：考え方の一部は合っているが、正解にはしない。誤答として記録し、足りない点を伝える。
- **明確な誤答**：意味がちがう答え。どこがまちがいかを伝える。

### 1　答え：−7℃
- 根拠：0℃より低い温度は負の数で表す（教 p14）。
- 許容：−7、−7℃、−7度
- 部分的正答：なし
- 明確な誤答：7、+7、7℃（符号がない、または逆）→「0℃より低いので−をつける」

### 2　答え：−2/9
- 根拠：0より小さい数は負の符号をつける（教 p14〜15）。
- 許容：−2/9、-2/9。2/9 は割り切れないので、小数の答えは受けつけない（−0.22 などは近い値で、同じ値ではない）。
- 部分的正答：なし
- 明確な誤答：2/9、+2/9（符号がない、または逆）、−9/2（分母と分子が逆）

### 3　答え：（1）−6、0、+8、13　（2）+8、13
- 根拠：整数は負の整数・0・正の整数。自然数は正の整数（教 p15）。
- 許容：+8 は 8 でもよい。順番は問わない。
- 部分的正答（どちらも正解にはしない）：
  - （1）で 0 だけが抜けている →「0も整数だよ」
  - （1）で −6 が抜けている →「負の整数も整数だよ」
- 明確な誤答：
  - （1）に 2.5 や −1/2 が入っている
  - （2）に 0 や −6 が入っている →「自然数は1、2、3、……」
- 採点：（1）と（2）は別々に採点する。それぞれ、ちょうどその数がそろったときだけ正解。

### 4　答え：A は −2.5、B は +1.5
- 根拠：−3から3まで、1目盛り0.5の数直線（教 p16）。A は0から左へ5目盛り、B は右へ3目盛り。
- 許容：A は −2.5 または −5/2。B は 1.5、+1.5、3/2。
- 部分的正答（正解にはしない）：A を 2.5 と答える（きょりは合っているが、符号がない）→「0より左は負の数」
- 明確な誤答：A を −5、B を 3 など、1目盛りを1と読んだもの →「1目盛りはいくつか、先に調べよう」
- 採点：A と B を別々に採点する。

### 5　答え：−3時間
- 根拠：基準の午前9時より後を「+」と決めたので、前は「−」（教 p17）。午前6時は9時の3時間前。
- 許容：−3、−3時間
- 部分的正答：なし
- 明確な誤答：
  - +3、3（後と前が逆）
  - −6（時刻の「6」をそのまま使った）→「基準の9時からどれだけ前か」

### 6　答え：−600歩
- 根拠：目標を0とみて、少ないときは負の数（教 p18）。8000−7400＝600 少ない。
- 許容：−600、−600歩
- 部分的正答：なし
- 明確な誤答：+600、600（符号の向き）、−7400（実際の歩数をそのまま書いた）

### 7　答え：−12m高い
- 根拠：反対のことばに言いかえるとき、符号も反対にする（教 p18）。
- 許容：−12m高い、−12メートル高い
- 部分的正答（正解にはしない）：「−12m」だけで「高い」がない →「ことばも入れて答えよう」
- 明確な誤答：12m高い、+12m高い（符号を変え忘れ）、−12m低い（ことばを変えていない）

### 8　答え：4.2
- 根拠：絶対値は0からのきょり（教 p19）。
- 許容：4.2、+4.2、21/5
- 部分的正答：なし
- 明確な誤答：−4.2 →「絶対値には−をつけない」

### 9　答え：−2、−1、0、1、2
- 根拠：0からのきょりが2.5より小さい整数（教 p19、練習 p22 と同じ考え方）。
- 許容：順番は問わない。+1、+2 も可。
- 部分的正答（正解にはしない）：
  - 0 だけが抜けている →「0の絶対値は0。2.5より小さい」
  - 負の数が抜けている（0、1、2 だけ）→「−1、−2も0からのきょりは2.5より小さい」
- 明確な誤答：
  - 3 や −3 が入っている（3は2.5より大きい）
  - 2.5 や 0.5 などの小数が入っている（整数ではない）
- 採点：ちょうど5つがそろったときだけ正解。

### 10　答え：−5/6 < −4/5
- 根拠：負の数は、絶対値が大きいほど小さい（教 p20）。5/6＝25/30、4/5＝24/30 なので、絶対値は 5/6 のほうが大きい。だから −5/6 のほうが小さい。
- 許容：−5/6 < −4/5、−4/5 > −5/6
- 部分的正答：なし
- 明確な誤答：−5/6 > −4/5、−4/5 < −5/6（向きが逆）→「負の数は、絶対値が大きいほど小さい」
- 採点：不等号の向きと、2つの数の位置の両方で判定する。

### 11　答え：−2、−1.6、−3/10、0、0.7
- 根拠：負の数は絶対値が大きいほど小さく、0より小さい。正の数は0より大きい（教 p20）。
- 許容：−3/10 は −0.3 でもよい。不等号を使った「−2 < −1.6 < −3/10 < 0 < 0.7」も可。
- 部分的正答（正解にはしない）：負の数の中の順番だけが逆（−3/10、−1.6、−2、0、0.7）→「負の数は、絶対値が大きいほど小さい」
- 明確な誤答：大きい順にならべた。5つの数のどれかが抜けている、または多い。
- 採点：順番が完全に合っているときだけ正解。

### 12　答え：−3
- 根拠：「−5大きい」は「5小さい」と同じ。2から左へ5目盛り（教 p21〜22）。
- 許容：−3
- 部分的正答：なし
- 明確な誤答：7（右へ進んだ）→「−○大きいは○小さい」。3（符号なし）。
