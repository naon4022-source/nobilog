# のびー（マスコット）の使い方

2026-10-06 Claude。ユーザー指示「のびー もうちょっとこだわってかわいく」「のびー 結構いろんなとこで使いたいから ちゃんと作っておいて」。

## 形（どこでも同じ顔にする）
- 芽のおもち：ぷにっとした緑の体（つや・影つき）、ぷっくりした葉っぱ2まい、大きなきらきらの目、ほっぺ、まるい手、小さな足。
- 正本は `nobi_kit.py`。ここの形を変えたら、下の3か所も同じにそろえる。

## ポーズ（7種類）
| ファイル | 意味 | 使う場面の例 |
|---|---|---|
| `/nobi-normal.svg` | ふつう | 説明・ひとこと |
| `/nobi-wave.svg` | 手をふる（口をあけて笑う） | あいさつ・「そう！」 |
| `/nobi-point.svg` | 指さす | 「まず〜」「たとえば〜」 |
| `/nobi-think.svg` | 考え中（？） | 問いかけ |
| `/nobi-surprise.svg` | びっくり（！） | ひっかけ・注意 |
| `/nobi-joy.svg` | やったね（きらきら） | 正解・ほめる |
| `/nobi-read.svg` | 本を読む | 読み上げ |

## 使い方
- 画面（HTML）：`<img src="/nobi-joy.svg" alt="のびー">`。ファイルは `site-assets/` にあり、公開時にそのまま配られる。
- 書き出し：`python3 教材整理/Claude_Codex共有/のびー/nobi_kit.py`（site-assets/nobi-*.svg を作り直す）。
- 図解（SVG）：`教科図解/svg.py` の `g.sprout(x, y, 大きさ, pose='normal')`。中身は nobi_kit を読みこむ。
- 動画（canvas）：`教科動画/template.js` の `nobi(x, y, 大きさ, {t, wave, point})`。はずむ・ときどきまばたき。
- 教科書の会話：`talk` の顔に `nobi-<ポーズ>` を書くと、その表情で出る（build-textbook-subject.py が言葉に合わせて自動で選ぶ）。
- 教科書の読み上げ：本文を読んでいる行の横を `nobi-read` が付いていく。

## 注意
- 色・形を勝手に変えない（動画・図解・教科書で顔がずれるため）。
- 画面で絵文字の 🌱 を「のびー」の顔として使わない（教科書は自動で絵に置きかえている）。
