# 広告の情報を考える 教科書 p106〜109 ― 写真 S__16359477（p106・107）、S__16359478（p108・109）を目視（2026-10-05 Claude）
- 目標：広告を作る要素を整理し、広告を見る観点を知る。広告の特徴について理解し、広告を作る。
- 広告は、多くの人に向けて、宣伝や情報、メッセージを広めたり、アピールしたりするためのもの。受け手に商品を買ったり内容に賛同したりしてもらうため、品質がよさそうだ、価格が手ごろだ、役に立ちそうだなど、商品や内容の特徴を印象づけたり、よいイメージをもたせたりするための言葉や画像を用いる。組み合わせの工夫や、より人の注意を引く表現の工夫で、受け手の気持ちを動かしたり、行動を促したりする。
- 広告を形づくる要素：キャッチコピー（商品などの特徴を伝える宣伝文〈言葉〉）、メインビジュアル（内容を想像させる画像）、タイトル（商品名など）。例：牛乳の広告。
- 広告の手法：商品を見せる／おいしそう、冷たそうなど感覚に訴える／商品の理想的な利用法を示す／実験や調査のデータを見せる／有名人などの人物を起用する／言葉で説明する。これらを組み合わせて使うこともある。
- メッセージを伝える広告：福島県NPO法人ポスター（キャッチコピーに「ふくしま」の文字、実際に働く人と職場の写真でメッセージ性を強めている、作業の様子の写真も載せ具体的なイメージを伝えている）。
- さまざまな広告を比べる：全国都道府県対抗女子駅伝競走大会のポスター、映画のポスター。広告を構成する要素（タイトル・メインビジュアル・キャッチコピー）がどのような効果を生んでいるか、観点（配置や構図／写真の撮り方や絵の描き方／タイトルやキャッチコピーの言葉／写真や絵と言葉の関係／各要素の関係）で考える。キャッチコピーは、取り扱う商品や内容を見る人に言葉で印象づける役割があり、商品名などを使う／商品などの外観や機能を取り上げる／見る人の立場や状況を考える／商品を買ったり内容に賛同したりすることで実現する生活の姿を示す／共感を呼ぶ、疑問を投げかける、言葉遊びを用いるなど表現方法を工夫する。実際の広告では、字の大きさや形、色なども工夫する。
- 広告を作る：五枚の写真から一枚を選び、商品やメッセージ（清涼飲料水・コンピューター・銀行・環境保護）を伝えるポスターを作る。
- 振り返り：広告に含まれる情報や広告どうしの比較をとおして広告を見るときの観点を理解しているか。目的に応じて言葉と画像を組み合わせ、広告を作ろうとしているか。
- 原稿で直すもの：「小さい文字で書かれた条件」「事実かどうか確かめる」は教科書の本文にない → 削り、広告を形づくる要素（キャッチコピー・メインビジュアル・タイトル）、広告の手法、キャッチコピーの工夫に直す。
