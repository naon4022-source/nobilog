# 写真で「事実」を表現する 教科書 p68〜71 ― 写真 S__16359456（p68・69）、S__16359457（p70・71）を目視（2026-10-05 Claude）
- 写真は、その瞬間の「事実」を「写す」もの。しかし写真に「写っているもの」は撮影者が選び取った人物や事物・場面で、写す角度や構図も撮影者が意図したもの。写真はいわば撮影者によって作られた「事実」。
- 写真は見る人によっても捉え方が異なる。「写っているもの」「写っていないもの」のどこに注目し、どう想像するか。言葉や文を読んで内容を考えるように、写真を見ることで考えられることもある。
- 写真を見る観点：人物（表情・動作・服装・姿勢など）／事物や背景／場所／時間・空間／構図（対象を捉えている角度、対象との距離、人物や事物の組み合わせなど）。例：遊園地の乗り物に乗った子ども二人の写真（周辺にも多くの人）。
- 何を切り取るか：同じ場面や同じ場所を撮影した二組の写真（猫に近づいて撮ったもの／人と猫を少し離れて撮ったもの、同じ線路を昼と夜に撮ったもの）。撮影者は、場面や場所・時間・対象となる物などから、何かを切り取っている。写真を撮るときには撮影者の意図や目的がある（何に興味をひかれたのか、誰に見せたいのか、写真を何に使うのか）。相手や目的に応じて撮り方は変わる。収められるのは場面全体の一部や、ある一瞬の時間だけ。撮った写真を意図や目的に応じて加工することもある。
- 写真の情報を整理する：観点を参考に写真に含まれる情報を読み、写っている人や物、話していること、注目したところを書き出し、写真の題名を考えて発表し、題名の言葉と写真の見え方の関係を話し合う。同じ写真でも題名が違うと見え方が変わる。
- 写真を組み合わせる順序を考える：A〜Dの四枚の写真から読み取れる情報を書き出し、自由に組み合わせて短い物語を考える。同じ写真でも、組み合わせ方を変えると全く違う物語ができる。写真に写っている「事実」も、そこでは違った見方をされていることになる。
- 振り返り：文章や画像などに表されている情報と情報の関係を捉えているか。写真に表されている情報を読み取り、それをもとに言葉や文章に表そうとしているか。編集という観点をもって身のまわりのさまざまな情報を捉えよう。
- 原稿で直すもの：「アップ・ロング」「キャプション」という言葉は本文になし → 写真を見る観点（人物・事物や背景・場所・時間空間・構図）、何を切り取るか、題名で見え方が変わる、組み合わせる順序で物語が変わる、に直す。
