## はじめに　「0より下」ってなんだろう？　（教科書 p12〜13）

〔イラスト img-01：冬の朝の温度計と、冷凍庫の中〕

- 冷凍庫の中は、だいたい「−18℃」。
- 冬の朝の天気予報で「最低気温 −3℃」と聞くことがある。
- どちらにも「−」という記号がついている。

これは、**0℃よりも低い**ということを表している。
この節では、「−」のついた数のしくみを学ぶ。

## 1　0より小さい数　（教科書 p14〜16・ワーク p2〜3）

### 1-1　「−」は「0より小さい」のしるし
- 0℃より4℃低い温度は **−4℃** と書いて、「**マイナス**4度」と読む。
- 0より小さい数は、数の前に「−」をつけて表す。
  - 0より6小さい数 → −6
  - 0より0.5小さい数 → −0.5
  - 0より1/3小さい数 → −1/3

### 1-2　正の数・負の数・0
- 0より小さい数を **負の数** という。（例：−4、−0.5、−1/3）
- 0より大きい数を **正の数** という。（例：4、0.5、1/3）
- **0は、正の数でも負の数でもない**。ここはまちがえやすいので、しっかり覚えよう。
- 正の数には「+」をつけることもある。+4 は「**プラス**4」と読む。4 と +4 は同じ数。
- このように使う「+」を **正の符号**、「−」を **負の符号** という。

### 1-3　整数と自然数
- これまで「整数」は 0、1、2、3、…… だった。
- これからは負の数もふくめて、……、−3、−2、−1、0、1、2、3、…… をすべて **整数** という。
- そのうち、1、2、3、…… のような正の整数を **自然数** という。
- **0は自然数ではない**（0は正の数ではないから）。

**見分け方**
1. 分数や小数で、値が整数にならないものは、整数ではない。
2. 「−」がついていたら負の数。だから自然数ではない。
3. 0 は「整数」の仲間に入る。でも「自然数」には入らない。

### 1-4　数直線にかく
〔図 fig1_数直線の基本.svg〕

- 数直線では、0より右に正の数、0より左に負の数がならぶ。
- −3 は、0から左へ3目盛りの点。
- **目盛りを読むときは、はじめに「1目盛りがいくつか」を調べる。**
  - 0と1のあいだが何等分されているかを数える。
  - 5等分なら、1目盛りは 1÷5＝0.2。
  - 1目盛りが1とはかぎらない。

### 例題1
**基本**　0℃より9℃低い温度を、「−」を使って表しなさい。
- 答え：−9℃
- 考え方：「0℃より低い」から負の数。0℃から9℃はなれている。

**標準**　次の数の中から、（1）負の数、（2）整数、（3）自然数を、それぞれすべて選びなさい。
　−7、0.4、0、+3、−2/5、15、−1、1.2
- 答え：（1）−7、−2/5、−1　（2）−7、0、+3、15、−1　（3）+3、15
- 考え方：
  - 0 は負の数に入れない。でも整数には入れる。
  - −2/5 は負の数だが、整数ではない。
  - +3 は 3 と同じなので、自然数に入る。

**応用**　〔図 fig2_目盛りの読み取り.svg〕　点P、点Qが表す数を答えなさい。
- 答え：P は −0.6、Q は +0.4（0.4 でもよい）
- 考え方：
  - 0から1までが5等分されているので、1目盛りは0.2。
  - P は0から左へ3目盛りなので、0.2×3＝0.6 小さい → −0.6。
  - Q は0から右へ2目盛りなので → +0.4。

### よくあるまちがい（1）
- 0 を正の数に入れてしまう。→ 0は正の数でも負の数でもない。
- 0 を自然数に入れてしまう。→ 自然数は1から始まる。
- 目盛りを全部「1」とみて読んでしまう。→ 先に「1目盛りがいくつか」を調べる。

## 2　正の数・負の数で量を表す　（教科書 p17〜18・ワーク p3）

### 2-1　反対の意味のことば
「高い・低い」「東・西」「後・前」のように、反対の意味をもつことばの組がある。
- 片方を正の数で表すと決めたら、もう片方は負の数で表せる。
- 例：東へ進むことを「+」とすると、西へ進むことは「−」になる。

〔イラスト img-02：反対の意味の2コマ〕

**大事なこと：どちらを「+」にするかを、はじめに決めておく。**
決めないまま書くと、意味が伝わらない。

### 2-2　「基準」とのちがい
- 目標や予定などの数を「基準」にして、それを0とみることがある。
- 基準より多いときは「+」、少ないときは「−」でちがいを表す。
- 基準と同じときは「0」。

〔図 fig3_基準とのちがい.svg〕

### 2-3　1つのことばで言いかえる
「多い」の反対は「少ない」。負の数を使うと、「多い」だけで両方を言える。
- 「7本少ない」は「−7本多い」と言える。
- 言いかえるときは、**数の符号と、ことばの両方を反対にする**。

### 例題2
**基本**　東へ300m進むことを +300m と表すとき、西へ200m進むことはどう表せますか。
- 答え：−200m
- 考え方：「西」は「東」の反対なので、負の数になる。

**標準**　1日の読書の目標を20ページとし、目標とのちがいを正の数・負の数で表します。月曜日は26ページ、火曜日は17ページ、水曜日は20ページ読みました。それぞれのちがいを答えなさい。
- 答え：月 +6ページ、火 −3ページ、水 0ページ
- 考え方：
  - 26は20より6多いので +6。
  - 17は20より3少ないので −3。
  - 20は目標と同じなので 0。

**応用**　（1）「3日おそい」ことを、「早い」ということばを使って表しなさい。
- 答え：−3日早い
- 考え方：「おそい」の反対は「早い」。ことばを反対にしたので、符号も反対にする。

（2）あるテストで、基準の50点とのちがいが「−8点」の人は、何点ですか。
- 答え：42点
- 考え方：−8点は「50点より8点少ない」という意味。50−8＝42。

### よくあるまちがい（2）
- どちらを「+」にしたかを決めずに書く。
- 言いかえで、ことばだけ反対にして、符号を変え忘れる（「7本少ない」を「7本多い」としてしまう）。
- 基準と同じときに、何も書かない。→「0」と書く。

## 3　絶対値と数の大小　（教科書 p19〜22・ワーク p4〜5）

### 3-1　符号を変えた数
- +5 の符号を変えると −5。−2.5 の符号を変えると +2.5。
- 数直線では、0をはさんで反対がわの、同じ遠さにある。

### 3-2　絶対値は「0からのきょり」
〔図 fig4_絶対値.svg〕

- 数直線で、0からその数までのきょりを **絶対値** という。
- −3 も 3 も、0から3目盛りはなれているので、絶対値はどちらも 3。
- 0 の絶対値は 0。
- **絶対値には「−」をつけない**（きょりだから）。

### 3-3　数の大小と不等号
数直線では、**右にあるほど大きい**。ここから、次のことが言える。
1. 正の数は、負の数より大きい。
2. 正の数は、0より大きい。絶対値が大きいほど大きい。
3. 負の数は、0より小さい。**絶対値が大きいほど小さい**。（−8 は −2 より小さい）

大小は不等号「<」「>」で表す。口の開いているほうが大きい。
- 例：−6 < −1、0 > −0.3
- 3つの数を1本の式にするときは、**不等号の向きをそろえて**小さい順（または大きい順）にならべる。
  - 例：−5 < −2 < 4
  - 「−5 < 4 > −2」のように、向きをまぜて書かない。

### 3-4　数直線で「〜より○大きい数」を求める
〔図 fig5_数直線で求める.svg〕

- 「1より3大きい数」は、1から右へ3目盛り → 4。
- 「1より3小さい数」は、1から左へ3目盛り → −2。
- 「1より−3大きい数」は、「1より3小さい数」と同じ意味なので → −2。
- 「−○大きい」は「○小さい」、「−○小さい」は「○大きい」と言いかえてから考える。

### 例題3
**基本**　−11 の絶対値と、−11 の符号を変えた数を答えなさい。
- 答え：絶対値は 11、符号を変えた数は +11（11 でもよい）

**標準**　（1）−3.5 と −2 の大小を、不等号を使って表しなさい。
- 答え：−3.5 < −2（−2 > −3.5 でもよい）
- 考え方：どちらも負の数。絶対値が大きい −3.5 のほうが小さい。

（2）−1、−4/3、0.5 の大小を、不等号を使って1つの式で表しなさい。
- 答え：−4/3 < −1 < 0.5（0.5 > −1 > −4/3 でもよい）
- 考え方：
  - 4/3 は 1 より大きい。だから −4/3 は −1 より小さい。
  - 0.5 は正の数なので、いちばん大きい。

**応用**　（1）絶対値が3より小さい整数を、すべて答えなさい。
- 答え：−2、−1、0、1、2（5個）
- 考え方：
  - 0からのきょりが3より小さい整数をさがす。
  - 3 と −3 は、きょりがちょうど3なので入らない。
  - 0 を入れ忘れないように。

（2）−2より−4大きい数を答えなさい。
- 答え：−6
- 考え方：「−4大きい」は「4小さい」と同じ。−2から左へ4目盛り進む。

（3）□より4大きい数は1です。□にあてはまる数を答えなさい。
- 答え：−3
- 考え方：
  - □から右へ4目盛り進むと1になる。
  - だから□は、1から左へ4目盛りもどった所 → −3。
  - 確かめ：−3から右へ4目盛り進むと、たしかに1になる。

### よくあるまちがい（3）
- 「−8 と −2 では、8のほうが大きいから −8 が大きい」と考える。→ 負の数は、絶対値が大きいほど小さい。
- 絶対値に「−」をつけてしまう（−5 の絶対値を「−5」と答える）。
- 3つの数で、不等号の向きをまぜて書く。
- 「−3大きい」で右へ進んでしまう。
- □を求める問題で、進む向きを逆にしない。最後に、答えから問題の向きに進んで確かめる。

|---|---|
| 正の数・負の数 | 0より大きい数・0より小さい数。0はどちらでもない |
| 符号 | 正の符号「+」、負の符号「−」 |
| 自然数 | 正の整数 1、2、3、……。0は入らない |
