## 3. 資料が足りないところ（完成扱いにしていない理由）

1. **漢検の級別配当漢字表がない**：使った漢字が「4級の範囲」に入るか確認できない。今回の漢検原稿は「4級の形式に慣れる練習」で、範囲をすべてふくむ問題集ではない。必要な資料：日本漢字能力検定協会の級別配当漢字表（4級・3級）。
2. **理科検定はサンプルが2ページずつだけ**：級ごとの出題範囲の一覧がない。5級は中学1年の4分野から作ったが、実際の出題範囲と合っているかは確認できない。必要な資料：理科検定の級別の出題範囲（公式の資料）。
3. **数検の証明・作図・説明を書く問題**：採点器で扱えないので、「条件を選ぶ」形だけにした。証明の全文・作図は手書きの練習が別に必要。
4. **平方根をふくむ答え**（2√3 など）：採点器で扱えないので、答えが整数・分数になる問題だけにした。
5. **ほかの級**：数検の他の級、漢検の4級以外、理科検定の5級以外は、まだ作っていない（中学1年の生徒にとって優先度が低いため。必要なら同じ方法で作れる）。
