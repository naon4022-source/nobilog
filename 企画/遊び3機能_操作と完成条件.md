## 共通の約束
- ゲームの数値（素材・能力値・ポイント）は**実際の成績や学力ではない**と画面に書く。成績・答案・学校の点数をゲームで変えない。
- 報酬は「はじめて正解した問題」だけから出す（同じ問題のくり返しや連打で増えない）。新教材ですでに使っている「初回正解」の記録をもとにする。
- 保存は本人のサーバー記録。時間の進み方は**サーバーの時刻**で計算し、端末を開きっぱなしにしなくてよい。
- 動きを減らす設定・スマホ・タブレット・パソコンに対応。音は設定に従う。

## 1. VS／CO-OP（なお・りらんが同じ問題を同時に）
- 操作：①「対戦／協力」を開く → ②相手（なお／りらん）と問題の範囲・問題数（5/10/15）を選ぶ → ③相手に招待が届き「参加」を押す → ④2人がそろったら3秒カウントで同時スタート → ⑤同じ問題を同じ順で解く → ⑥終わったら結果（正答数・速さ・合計点）。
- 対戦：正答数が多い方が勝ち。同じなら合計時間が短い方。協力：2人の正答数の合計で「ボス」の体力を減らす（全問正解でなくても、合計が目標に届けば勝ち）。
- 切断・遅れ：答えは1問ごとにサーバーへ送る。切れても再接続でその問題から続ける。60秒もどらなければ、その人はその時点の成績で終わる。時刻はサーバー基準で比べる。
- 見られるもの：相手の「正答数・時間」だけ。相手の答えの文章は見せない。
- 完成条件：2人分の偽のアカウントで、同時開始・切断と再接続・遅れ・二重送信・本人以外の結果を見られないことを隔離検証で確かめる。実機2台での確認はなおに依頼。

## 2. 3Dマイホーム／ワールド
- 素材：新教材で**はじめて正解**した問題1問＝素材1個（教科で種類が変わる：数学＝石、英語＝木、国語＝紙、理科＝ガラス、社会＝レンガ）。お金：政治と経済のゲーム内のお金で家具や土地を買える（使うと残高が減るだけ。お金の計算のしくみは変えない）。
- 操作：部屋（10×10のマス）を上から見る3D表示。①家具・ブロックを選ぶ ②マスを押して置く ③回す・どかす ④保存。島は部屋が5つできたら解放。
- 「24時間動く」：畑や工場は、置いた時刻とサーバーの今の時刻の差から、できた数を計算する（開きっぱなし不要）。上限あり（例：24時間ぶんまで）。
- 完成条件：置く・どかす・保存・再ログインで同じ形・別の端末で同じ形・素材の二重取りなし・お金の残高が正しく減る、を隔離検証。重い端末で動かない場合は2D表示に切り替える。

## 3. RPGスキルツリー
- 5教科の単元を「木」の形に並べる（例：数学 正負の数 → 文字式 → 方程式 …）。単元の★（70問の小単元の★1〜3）で枝が光る。
- 能力値：例「計算力」「英単語力」。単元の★が上がったときに1回だけ増える（くり返しでは増えない）。上限あり。
- 操作：木を見る → 単元を押す → その単元の問題（教科書・特訓）へ。
- 完成条件：★の変化と能力値の増え方が一致、くり返しで増えない、新しいアカウントで0から、表示がスマホで読める、を検証。
