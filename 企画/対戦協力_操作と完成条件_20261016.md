# 対戦・協力：見送り（ユーザー取消し）

2026-10-16。ユーザーが「これいらない」と回答したため、対戦・協力は作らない。未実装・未配信。以下は過去の提案として保存し、実装待ちとして扱わない。大型更新台帳の「操作と完成条件を文書で決め、確認してから作る」に対応する案。

## 何ができるようになるか

- **対戦**：同じ問題を同時に開始し、正解数を比べる。正解数が同じなら所要時間を比べ、両方同じなら引き分け。
- **協力**：同じ問題を2人で解き、2人の正解で画面の目標ゲージを進める。片方が間違えても相手を責める表示にせず、終了後に自分の間違いを振り返れる。
- AI相手は今回の最初の範囲に含めない。人間2人の通信・採点を完成させ、追加する場合はAI使用量と費用も別に確認する。
- 3Dマイホームは作らない。学習用の対戦結果からゲームのお金や通常の成績を増減させない。
- この機能だけの有料制限は新設しない。現在の教材の利用条件は維持する。

## 実際の操作

1. 「きろく・あそび」から「いっしょに学ぶ」を開く。
2. 対戦／協力、教科・学年・大単元・小単元を選ぶ。確認済みの問題から15・30・45・60問を選ぶ。必要な異なる問題数がなければ、その数は選べず理由が出る。
3. 部屋を作ると、期限つきの招待コードが出る。コピーして自分で相手に渡す。アプリが勝手にメールやLINEを送ることはない。
4. 相手は同じ画面でコードを入れる。参加前に「ニックネーム・今回の正解数・経過時間が相手に見える」と双方に説明する。主催者が参加する人を確認して受け入れる。過去の答案・学習履歴・日記・AI会話は相手へ渡さない。
5. 2人が「準備できた」を押すと、3秒のカウントダウン後に始まる。切替や演出は動きを減らす設定にも従う。
6. 1問ずつ入力する。対戦は同じ順の問題をそれぞれのペースで解く。協力は2人の回答またはその問題の制限時間で次へ進む。
7. 終了すると今回の正解数・時間・自分の解き直し入口が出る。相手の入力した文章は表示しない。通常の問題画面を勝手に開始しない。

## 時間と途中の切断

- 待合室は10分で期限切れ。期限を過ぎたコードでは入れない。
- 対戦は部屋を作るときに全体の制限時間を選ぶ案：15・30・45・60分。協力は1問60・90・120秒から選ぶ。問題数とともに双方が開始前に確認する。
- 開始時刻・残り時間・回答期限・結果の確定はサーバー時刻で決める。端末時計を変えても延長できない。
- 回答は保存の確認後に「送信済み」とする。失敗した入力は消さず、同じ回答IDで再送する。二重回答として点数を増やさない。
- 切断中もサーバーの期限は進む。再接続したら本人の保存済み状態から戻す。切断直前の未保存回答を受理済みと表示しない。
- 再ログインした同じ本人は続きへ戻れる。別の本人へ切り替えたら前の部屋の表示を閉じ、前の通信結果を新しい本人に適用しない。
- 主催者がいなくなっても、開始済みの部屋の採点・期限は主催者の端末に依存させない。待合室の中止と、開始後の退出は区別する。

## 保存と判定

- 部屋ID、参加する2人の内部ID、今回使う問題IDと順番、方式、時間、準備状態、サーバーの開始時刻、本人の回答と判定、送信ID、確定した結果を保存する。
- ニックネームは今回用の表示名。メール、パスワード、APIキーを部屋へ保存しない。
- サーバーが登録教材の問題と採点基準を使う。利用者が送った点数、他人のID、答えの基準は採用しない。AIで採点結果を書き換えない。
- 相手へ返す情報は今回の共有範囲に限る。自分の回答の確認と、相手の回答本文の閲覧を分ける。
- 招待コードは暗号学的な乱数で作り、サーバーには照合用のハッシュだけを保存する。認証トークンと招待コードをログへ出さない。URLへ認証値を入れない。
- 参加前の画面、他人の部屋ID、期限切れコード、総当たり、連打、同時の回答、古いログインからの書込みをサーバーで拒否・制御する。
- 静的教材を事前に調べる行為まで完全には防げない。「不正が絶対できない」とは案内しない。
- 期限切れ後は参加できなくするが、保存した答案や結果をこの機能の追加だけで削除しない。表示期間は現在のプラン方針に合わせ、保存期間の未決定事項は別途残す。

## 完了を判断する条件

1. 仮の2アカウントと実ブラウザ2画面で、作成→参加→受入→準備→同時開始→回答→終了→自分の解き直しまで動く。
2. 対戦と協力、正解・不正解・未回答、引き分け、途中退出、期限切れがサーバーの結果と一致する。
3. 問題が重複せず、教科・単元・出典・採点基準を既存教材と照合できる。通常の成績・報酬・過去答案を変更しない。
4. 二重送信、返事だけ届かない場合、同時回答、別端末からの同じ本人、ログイン変更、保存先の障害でも、他人への漏れと二重加点がない。
5. 参加者以外は部屋・今回の問題・答案へアクセスできず、参加者にも相手の回答本文や過去記録が返らない。
6. 390px・タブレット・PCで、入力、残り時間、保存状態、キーボード操作、文字拡大、動きを減らす設定を確認する。
7. 追加前後の全体検証が通り、変更箇所・未確認・配信範囲を連絡ファイルに記録している。
